# Records and storage workspace

The records workspace uses the shared locally bundled Material controls. File history keeps date and bounded regular-expression filtering, multiple selection, preview, comparison, export, restore and labels. Versions and Activity use keyboard-selectable tabs. Results and previews scroll inside bounded regions.

Documentation uses a searchable article navigator alongside a scrolling article. At narrow widths the grid stacks without requiring horizontal scrolling. Disposal invalidates asynchronous search results. Status retains its existing trusted-process state reporting. Update controls retain the existing admission, cancellation and restart boundaries.

Storage maintenance is a dedicated task panel with current-reference, history-only and temporary physical byte counts. A numeric MiB field defaults to 80 MiB, exactly 83,886,080 physical bytes, and rejects a target above 90,000,000 bytes. Pack current files queues the native operation. Refresh reads diagnostics and the operation registry. Active packing rows expose cancellation, byte progress, phase and error. Unknown totals use indeterminate progress.

The panel distinguishes queued files and active writers. Historical ciphertext remains retained while recorded versions reference it. Packing does not rewrite history or pad a short part. No deletion action is provided by this panel.

Source and synthetic tests are not built-surface evidence. Normal/minimum viewport, three language modes, both themes and 100/125/150/200 percent scale captures remain required at integration. No installation, installed update or removal is authorized by this specification.

Cancelling packing durably pauses the queue without discarding pending files. The panel displays the paused state and changes its primary action to Resume packing, which submits startPacking and clears the native pause.
