# 瀏覽器身份摘要嘅原生授權

原生瀏覽器主機只有一個受保護範圍：`local-profile`、`read-profile-summary`、`profile-summary`。呢個範圍只會回傳固定嘅已驗證及已授權摘要，唔會授予讀取登入資料、修改共享設定、學校模式控制、驗證器存取或者任意原生操作。

## 本機驗證

完整原生提示接駁安裝好之後，驗證會開啟主程序擁有嘅子視窗。使用者輸入桌面本機身份密碼，並明確選擇允許摘要。磁碟解鎖、下載配對同呈現程序嘅身份觀察，都唔係呢個範圍嘅驗證。

只有確實子視窗內容、確實主框架身份、預期本機 URL 同提示 nonce 先可以提交。主介面呈現程序同瀏覽器都唔可以代答。等候驗證之前、取消或者關閉時都會清除輸入。預載接駁只提供提示畫面、提交、取消同清除通知。密碼、驗證記錄同授權物件永遠唔會經瀏覽器回應傳出，亦唔會匯出、寫入歷史或者記錄日誌。

驗證使用現有存取服務內獨立嘅原生身份，並調用同桌面驗證相同嘅身份驗證及等候狀態協調器，所以失敗嘗試同等候期由身份目標共同管理。佢唔會冒充主介面呈現程序，亦唔會重用其授權。今次有界限提示只顯示共用等候期，唔會引入跳過等候嘅方法，亦唔會宣稱新畫面已完成完整等候階梯介面。

## 授權同取消

成功驗證會建立只留喺主機嘅不透明授權，綁定受保護身份嘅確實修訂、原生撤銷代數，同最多 60 秒有效期。替換修訂，包括內容一樣嘅替換，都會令授權失效。驗證會跨非同步邊界重新檢查受保護儲存。現有瀏覽器中介亦會將一次性授權綁定配對連線同確實固定範圍。

中斷連線、明確撤銷受保護授權、鎖定、退出或更新準備，以及原生助手停止，都會撤銷授權並取消提示。已取消或者銷毀嘅子視窗唔可以稍後產生授權。提示成功唔會授予主介面歷史存取。缺少原生提示接駁時，功能發現仍然顯示未可用；來源接駁唔代表已安裝驗證成功。

## 驗證狀態

來源包含集中測試，檢查獨立身份、共用等候、修訂變更、到期、撤銷、受保護讀取期間取消、確實子視窗及 nonce 路由、安全 IPC 回應，以及取消後延遲驗證。三個集中身份測試套件，加上現有受保護中介同本機存取整合回歸測試，已循序通過：34 項測試、零失敗、零略過。呢個係來源層面測試替身證據，唔係封裝或者原生執行驗收。實際封裝提示行為、鍵盤及讀屏驗收、主題及語言版面、等候階梯完整性，同瀏覽器往返驗收仍未驗證。

之後真實畫面驗證需要涵蓋已設定但輸入空白嘅提示、缺少身份、驗證失敗後輸入已清除、共用等候，以及取消或擁有者銷毀。要涵蓋英文、廣東話及雙語、淺色及深色、正常及最細客戶區，同支援顯示比例。永遠唔可以拍攝真實密碼或者授權。拍攝日期及來源與執行檔綁定必須來自實際收據。
