# 選取工作區指引

自選指引位於原有畫布、套用及清除操作、參考線控制項同範圍搜尋上方。狀態樣本提供具體解釋。唔開啟指引亦可以操作。最後一步執行原有 click 或 change 消費端，保留原有授權、驗證同歷史記錄路徑。

按鈕使用已註冊 Material Design 3 外框按鈕；欄位使用外框文字欄位。無障礙 SVG 保留指標繪畫同鍵盤方式：方向鍵移動一格，Shift 移動十格，空白鍵加點，Enter 套用，Escape 清除草稿。取消指標操作會捨棄未完成筆劃。清除草稿唔會清除已儲存圖層遮罩。

儲存消費端必須回傳或者完成為 `true`。缺少消費端、`false`、`undefined`、拒絕、目標不可用同過期實例，都唔會報告選取範圍已套用或者參考線已儲存。確認之前，候選參考線同已接受幾何分開。銷毀會移除所擁有監聽器、說明、指令選單項目、搜尋同預覽樣式表。等候中操作唔會重播。靜態樣本唔會複製原有操作、欄位值或者目標子項文字。

主機提供 `translate`、`getLanguage`、`isAvailable`、`attachSearch`、`registerHelp`、`registerCommands`、`openGuidanceHelp` 同 `guidanceHelpBase`。翻譯字典需要加入 `WORKBENCH_GUIDANCE_COPY`。可用性回呼檢查目前目標、圖層鎖同編輯器生命週期；原有修改仍然最終決定。現有範圍搜尋介面負責相鄰正則表達式建立器。缺少介面時搜尋停用，旁邊顯示原因。

## 驗證同待完成驗收

掛載元件檢查涵蓋自選位置、單次原有准入、等候結果、被拒絕消費端、過期實例處置、參考線驗證及回復、私人值省略同樣式表擁有權。合成 DOM 檢查只證明來源行為。產品建置、Material Design 3 顯示一致性、瀏覽器鍵盤無障礙、三種語言模式，以及桌面同網站畫面驗收仍待完成。呢個單元唔會修復獨立公開偏好設定主題及版面報告，亦唔代表完整圖像編輯器已完成。

## 控制項概念

### drawing

用指標筆劃或者鍵盤加點建立多邊形草稿。座標介乎零至一百，至少需要三個頂點。Escape 同取消指標操作只捨棄草稿，唔會改變已儲存遮罩。

### apply

透過原有圖層修改套用目前多邊形，最多儲存三十二個取樣點。只有明確確認先報告成功；被拒絕草稿會保留供修正。

### clear

只捨棄未完成繪畫，唔會移除已儲存選取範圍。修改等候期間唔可以清除。

### guide-x

喺百分之五十加入垂直吸附參考線。垂直同水平參考線共用二十條上限。可以復原或者移除參考線。

### guide-y

喺百分之五十加入水平吸附參考線。確認儲存之後改變對齊位置，唔會移動現有多邊形頂點。

### guide-edit

沿原有座標軸移動指定參考線。輸入零至一百嘅有限百分比，例如 33.3。空白或者過期列唔可以提交。被拒絕時保留先前儲存位置。

### guide-remove

原有消費端確認之後移除指定參考線。其他參考線同多邊形保持不變。可以重新加入或者復原儲存版本。

### tool-search

用主機範圍文字搜尋同相鄰正則表達式建立器尋找繪畫操作。搜尋唔會改變遮罩或者參考線。清除查詢還原完整工具位置。

### preview-search

尋找已命名靜態外觀樣本。搜尋只改變比較位置，唔會改變已儲存外觀。清除查詢重新比較全部提供狀態。

### preview

檢查提供嘅狀態快照。樣本唔代表真實互動或者操作完成，亦唔會複製私人輸入值。重新開啟比較取得新快照。
