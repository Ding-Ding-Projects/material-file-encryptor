# 瀏覽器保護狀態觀察

擴充功能選項嘅連線面板可重新讀取有明確類型嘅只讀原生保護狀態。瀏覽器連線、傳輸結果、原生身份驗證同共享模式各自顯示。下載配對只容許讀取呢條觀察通道，唔會授予瀏覽器身份權限或啟用個人用詞。

## 傳輸同權限

已配對原生要求只有 `type` 同 `session`，`type` 必須係 `protection-status`。通道要求經檢閱嘅擴充功能來源、有效記憶體配對、已解鎖桌面同可用准入。讀取後會再檢查配對同准入。未知欄位、到期、撤銷、鎖定同關閉都會被拒絕。

受信任主程序讀取現有原生身份驗證授權，唔會借桌面 IPC 來源身份畀瀏覽器，亦唔接受序列化輸入指定操作者。授權綁定實際目前桌面畫面、取消世代同受保護憑證版本。到期、版本改動、登出、畫面離開或更換、關閉，都唔會再回報有效身份驗證。身份記錄讀唔到就回報未知。獲准建立或移除身份記錄時，會喺寫入儲存前撤銷舊驗證世代，審核等候唔可以延長舊身份觀察。變更失敗仍會按自己嘅版本復原，復原憑證須重新明確驗證。

共享記錄會喺身份讀取前後檢查。啟用就回報啟用，無效、讀唔到或讀取期間改動就回報未知。記錄未建立時沿用現有未啟用預設值。呢個係重新讀取觀察，唔係即時訂閱，亦唔含共享憑證。佢唔係跨外部檔案寫入者嘅交易，唔可以攞嚟決定授權。

回應只有 `type`、`schemaVersion`、`profile`、`sharedMode` 同 `browserPermission`。版本係 1。身份可為 authenticated、locked、expired 或 unknown。共享模式可為 active、inactive 或 unknown。瀏覽器權限永遠係 unavailable。唔會序列化憑證、驗證資料、快取金鑰、私人替換、來源檔名或檔案路徑。

## 擴充功能行為

只有確切頂層彈出視窗同選項頁可以向背景工作程序要求讀取。每次原生回應都會驗證，只保留同一連線世代同配對嘅觀察，舊通道訊息同斷線事件會略過。配對同保護狀態只留喺記憶體，唔會進入瀏覽器同步、設定匯出或歷史。

選項面板有英文、廣東話同雙語觀察文案。保護讀取失敗或無效會清除嗰部分觀察，但保留獨立收到嘅連線狀態。重新讀取須主動操作。個人用詞同共享模式修改仍未可用，呢部分唔提供瀏覽器授權或另一套身份驗證。本機 CSP 同權限保持不變。

## 驗證界線

專用存取、原生通道、背景工作程序同選項測試涵蓋原生授權到期、版本改動、取消、讀取期間關閉或更換畫面、共享模式競態、確切要求同回應、偽造来源路徑、舊通道同本地化未可用狀態。現有原生主機同實際 IPC 畫面測試仍係獨立檢查。簽署、已安裝身份、登記、真實瀏覽器原生互動、執行中撤銷、視覺對照同顯示縮放仍須獨立執行證據。合成測試唔證明呢啲結果。
