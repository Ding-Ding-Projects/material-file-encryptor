# 現代介面同可清除欄位

桌面保留鼠尾草綠外觀，並加強導覽選取、內容框架、分組設定、分層歡迎同磁碟摘要、一致表格動作同有界對話框。仍支援淺色、深色、系統外觀、三種語言模式同減少動態效果。

每個可編輯文字欄位都有清除按鈕，包括啟動後插入嘅欄位。按鈕可用鍵盤操作，點擊目標至少 44 × 44 CSS px，並有標明欄位嘅本地化無障礙名稱。啟動後會清空值、移除自訂有效性、發出與輸入相同嘅 input/change 事件並恢復焦點，絕不提交表單。必填欄位清除後仍必填。停用或唯讀欄位嘅清除按鈕亦停用；隱藏欄位同按鈕一齊隱藏。

## 欄位清單

| 欄位 | 識別碼或位置 | 類型 |
| --- | --- | --- |
| 檔案搜尋 | `file-search` | 搜尋 |
| 既有分段大小 | `split-value` | 小數文字 |
| 私人版本庫 | `remote-repository` | 文字 |
| 儲存資料夾 | `storage-input` | 文字 |
| 快取資料夾 | `cache-input` | 文字 |
| 磁碟代號 | `drive-letter` | 文字組合框 |
| 密碼 | `password-input` | 密碼，可用既有控制顯示 |
| 確認 | `confirm-password` | 密碼 |
| 金鑰檔路徑 | `key-path` | 文字 |
| 建立分段大小 | `create-split-value` | 小數文字 |
| 自訂保留期 | `history-days` | 數字 |
| 歷史搜尋 | `history-search-host` | 動態搜尋 |
| 回收搜尋 | `recycle-search-host` | 動態搜尋 |

增強功能亦支援未來 textarea、電郵、URL 同電話欄位。目前產品冇 textarea。檔案選擇器、核取方塊、單選控制、滑桿、選擇清單同隱藏輸入唔係文字框，唔會加入清除控制。

## 保安同驗證

功能絕不將欄位值複製至無障礙名稱、屬性、日誌或偏好。密碼遮罩同明確 Show/Hide 控制保持原狀。清空路徑唔會刪除或修改檔案。清空保留期或分段大小唔會自動套用，仍由既有 Apply 或提交驗證決定有效性。

## 驗證邊界

`test/ui-renderer.test.js` 涵蓋鍵盤清除、全部固定對話框欄位組、44 px 目標、焦點恢復、防止意外建立、密碼遮罩、動態保留期／搜尋同唯讀控制。亦透過隔離渲染固定資料測試既有流程、本地化、窄版面同減少動態效果。原生加密、真實磁碟行為、封裝啟動同建置視覺驗收屬獨立證據。狀態清單同必需建置矩陣見 `design/modern-interface.md`。
