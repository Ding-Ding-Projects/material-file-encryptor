# 本機介面工作計時

桌面介面提供唯讀 `window.mfePerformance.snapshot()`，俾受控嘅本機量度使用。紀錄只包含固定階段同畫面識別碼、程序內序號、結果，以及單調時鐘嘅開始時間同耗時。預設保留 128 筆完成紀錄同最多 32 個未完成區段。資料唔會上傳或持久保存。查詢、檔案路徑、文章內容、憑證同原生回應內容都唔會進入紀錄。

首次鎖定磁碟就緒紀錄要求目前狀態仍然鎖定、建立同解鎖操作可用，以及內容已連接並顯示。歷史同回收筒導覽就緒會跟住目前封存請求、篩選列同控制項。文件就緒會等初始文章同篩選導覽完成。成功但空白嘅集合仍然就緒；不可用工作、worker 錯誤、被新請求取代同銷毀都有獨立結果。模組掛載同啟動完成只係階段，唔代表全部工作流程就緒。其他導覽明確標記為未量度。

就緒內容亦會等待實際觀察到嘅靜態樣式表載入、文件字型就緒承諾、目前自訂元素註冊，以及佢哋提供嘅初始更新完成訊號。呢啲唔證明像素正確、無障礙、每個巢狀 shadow 元件或之後操作。觀察同啟動並行，最多等五秒，唔會改排程器或原生操作。關閉頁面會中止觀察，並將未完成計時標記為已銷毀。

比較正常正式封裝時，要用相同隔離測試資料、建置設定、視窗尺寸、縮放、主題、語言、原生功能可用性同操作次序。另行記錄原始碼提交、封裝雜湊同原始快照。使用介面嘅單調時鐘耗時，排除工具連接、輪詢、截圖同驗證開銷。多次冷啟動同重複導覽分開比較。開發或驗證設定屬於另一組。呢項計時功能冇聲稱端到端速度改善，實際封裝執行量度仍然待做。

針對性合成測試涵蓋固定識別碼、有界保留、唯讀快照、過期導覽、銷毀、實際資源完成、逾時同錯誤、成功空白搜尋、正則 worker 錯誤同並行請求結果。呢啲測試唔代替封裝執行驗證。
