# 基礎介面覆蓋範圍同餘下工作

呢個係範圍有限嘅實作元件，唔代表所有介面功能已完成。`src/shared/surface/registry.js` 登記咗工作區分頁、範圍搜尋、命令面板、內容動作、通知中心同建置來源資料。Material Web 提供真正按鈕、分頁、文字欄位、開關、滑桿同對話框；已登記組合內仍有普通 DOM 元素負責文字同版面。

## 已實作並喺本機檢查

- 分頁生命週期、目前選取、最後分頁／釘選保護、有界關閉歷史、已關閉目的地持久儲存、命名群組建立／改名／移除／收合、分頁排序同有保護嘅批次關閉。
- 經清理嘅持久通知、有界歷史、已讀篩選、級別篩選、搜尋同 JSON／CSV 匯出序列化。
- Worker 協定支援 Unicode 群組、替換預覽、零寬匹配、擷取索引、測試案例預期結果、量度時間、無效模式／旗標同重複全域列匹配。
- 欄位獨立片段、明確選擇加入歷史、已驗證匯入／匯出、字面結構／風險診斷同目前引擎能力探測。
- 命令面板中繼資料／目前值搜尋，以及即時開關、核取方塊、範圍、數字、文字同可搜尋選擇控制。
- 本機固定版本 Material Web 瀏覽器套件，同所有新模組語法檢查。

以 `node --test test/surface-model.test.js test/surface-worker.test.js test/surface-workbench.test.js` 執行聚焦資料／協定檢查。呢啲檢查唔證明實際渲染無障礙、版面、主程式動作整合、本機擷取來源或執行時鍵盤行為。
