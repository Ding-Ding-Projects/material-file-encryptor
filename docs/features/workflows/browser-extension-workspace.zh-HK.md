# 瀏覽器擴充功能工作區

彈出視窗嘅「開啟工作區」會喺擴充功能自己嘅選項分頁開啟主頁。主頁取代咗以前成行分頁：係一個卡片格，連線、個人化、更新記錄、筆記、說明文件、支援、點心、模型同狀態各有一張，每張都有圖示、部分名稱同所選語言嘅一句說明。卡片係真正嘅按鈕，可以按格嘅次序用鍵盤逐個去到，用 Enter 或 Space 開啟，並有懸停、按下同清楚嘅焦點狀態。揀一張卡片就會全寬開啟嗰個部分，頂部係精簡應用程式列，只有「返回主頁」按鈕同部分標題，另外各處都有嘅搜尋同指令按鈕。主頁同各部分之間用短暫嘅共用軸滑動，要求減少動態嘅話就即時切換。窄螢幕上卡片會重排成一欄，唔會橫向捲動。開啟部分會新增一個帶 `#section` 片段嘅瀏覽器歷史記錄，所以瀏覽器嘅上一頁同下一頁可以喺主頁同各部分之間移動，而 `options.html#models` 會直接開啟模型；未知片段就開啟主頁。彈出視窗係迷你主頁：頂部保留配對狀態同「配對」、「中斷連線」按鈕，下面每個部分有一個小按鈕，可以直接喺嗰個部分開啟工作區，已有工作區分頁就會重用。畫面使用本機 Material 元件同已封裝正則搜尋，唔載入外部執行資產。

語言（英文、廣東話或雙語）、主題（跟隨系統、淺色或深色）同所選分頁使用有版本同大小限制嘅擴充功能本機儲存。唔使用瀏覽器同步、廣泛主機權限或新增儲存權限。無效或過大快取會退回預設值。寫入失敗會保留可用嘅頁面狀態，並清楚講明變更未儲存。重設只恢復瀏覽器本機預設值。雙語次要標籤另起一行。

連線同傳輸狀態分開顯示。配對唔會開始傳輸。連線中斷或回應無效會清除即時狀態，唔保留舊成功訊息。只有確切擴充功能彈出視窗同選項頁來源可用配對、狀態同斷線通道。原生傳輸仍須喺桌面確認。

配對唔等於本機身份驗證。個人用詞、共享模式、憑證、原生設定、伺服器管理、轉換器同桌面程式嘅模型控制要有經檢閱嘅已驗證原生通道先可用。英文同廣東話趣味程度各自有 1 至 5 滑桿，預設 5，並可獨立重設。彈出視窗狀態同選項通知用共用訊息翻譯器。表情符號預設關閉，只喺本機訊息預覽對話框加入一個輔助工具略過嘅裝飾，唔改按鈕標籤或事實。更多訊息覆蓋同執行驗證仍待完成。版本讀自擴充功能清單，組建來源同暫存時間就由暫存組件提供，詳見下文。Status Hub 登記未可用。

## 取得擴充功能

擴充功能冇上架瀏覽器商店，亦冇獨立下載檔。佢跟住桌面安裝程式一齊派發：喺[最新發行版](https://github.com/Ding-Ding-Projects/material-file-encryptor/releases/latest)下載 `MaterialFileEncryptor-Setup.exe` 再安裝。Squirrel.Windows 安裝程式會將程式放喺 `%LOCALAPPDATA%\MaterialFileEncryptor\app-<version>\`，擴充功能檔案就喺入面嘅 `resources\browser-extension` 資料夾。喺 Microsoft Edge 或 Google Chrome 打開擴充功能頁面，開啟開發人員模式，揀**載入未封裝項目**，再揀嗰個資料夾。每次桌面更新都會裝一個新嘅 `app-<version>` 資料夾，所以更新之後要重新載入。

狀態分頁嘅**檢查發行版本**搵到發行版之後，亦會提供嗰個發行版嘅桌面安裝程式，但只限 GitHub 回報確切嘅 `MaterialFileEncryptor-Setup.exe` 資產已上載、有檔案大小，而且喺預期嘅下載位址。草稿同預覽版一律唔會提供。安裝程式同擴充功能都冇簽署。呢頁冇驗證過實際安裝；上面嘅資料夾位置係根據 Squirrel.Windows 慣例，而唔係檢查過已安裝嘅副本。

## 更新記錄、組建來源同指令

更新記錄分頁唔使網絡連線都可以睇到版本更新記錄。暫存時會將儲存庫入面嘅更新記錄轉成已封裝模組，因為頁面政策唔准用 fetch 讀取擴充功能自己嘅檔案；篩選欄會喺本機收窄顯示嘅版本。廣東話模式顯示每個版本嘅廣東話摘要，雙語模式就同時顯示英文項目同摘要。

狀態分頁顯示擴充功能版本、封裝時所用嘅來源提交同暫存時間。如果暫存嗰陣受追蹤嘅擴充功能來源同嗰個提交唔同，提交會標示「另有未提交改動」。任何一項讀唔到，分頁會講明未可用，唔會靠估。

指令（Ctrl+K）會開啟一個 Material 對話框，列出工作區所有動作：開啟每個分頁、配對、中斷連線、重新讀取狀態、語言同主題選擇、訊息預覽同重設設定。輸入文字可以篩選清單，當刻做唔到嘅動作會顯示為停用。

## 匯出、設定說明、重設確認同快速鍵

「預覽匯出」會將目前篩選咗嘅更新記錄轉成 JSON、CSV 或 Markdown，儲存之前先顯示結果。匯出內容會先讀返一次核對：版本同改動數目要對得上，否則唔會提供檔案。CSV 儲存格如果以公式字元開頭，會喺前面加一個撇號，試算表就會顯示文字而唔會執行。匯出只包括版本說明，永遠唔會包括設定、配對資料或者個人用詞。

個人化入面嘅「設定說明」列出每個設定嘅目前數值、會改變乜嘢，同點樣恢復預設值。工作區搜尋可以搵到呢啲說明。

「重設瀏覽器設定」要經過刻意確認：開啟兩個確認開關，將滑桿拉到最右，然後揀「執行」。「緊急離開」會取消，乜都唔改。個別趣味程度重設仍然係一步完成，因為佢只改一個數值。

Alt+0 會開啟主頁，Alt+1 至 Alt+9 會開啟連線、個人化、更新記錄、筆記、說明文件、支援、點心、模型同狀態，Ctrl+K 會開啟指令面板，面板會喺指令隔籬列出呢啲快速鍵。Ctrl 加數字、Ctrl+T 同 Ctrl+W 呢類瀏覽器保留組合會留返俾瀏覽器處理。

## 名稱、強調色、最近改動同篩選

個人化入面嘅「名稱同強調色」可以令呢個瀏覽器用自己嘅產品名稱。名稱最多 60 個字元，唔可以有尖括號或者換行，會取代工作區標題、頁面標題、版本行、主頁導覽名稱同彈出視窗入面嘅 Material File Encryptor。留空就會恢復原本名稱。

強調色可以揀六個預設之一，或者輸入 #rrggbb 數值，再用透明度滑桿調校。透明度會同頁面底色混合，強調色上面嘅文字會自動揀白色或者黑色之中較易睇嗰個。工作區會講明對比度，要達到 4.5:1 先會提供「套用強調色」。「用預設強調色」會返回內置色盤。

「最近改動」列出最多 50 項語言、主題、趣味程度、表情符號、產品名稱同強調色嘅改動，附時間同還原舊數值嘅按鈕。切換分頁、配對狀態同任何秘密都唔會記錄。「清除記錄」用同全部重設一樣嘅刻意確認，而且唔會改動目前設定。

「篩選」按鈕可以收埋更新記錄嘅篩選同匯出控制。收埋之後篩選文字同效果都會保留，隱藏篩選仍然生效時按鈕會顯示「篩選（使用中）」。

由第 2 版工作區儲存嘅設定，第一次讀取時會加上空白嘅產品名稱同強調色，之前所有選擇都會保留。

## 圖示、標誌、專注模式同說明文件連結

擴充功能有自己嘅圖示，尺寸係 16、32、48 同 128 像素，用應用程式綠色嘅資料夾加鎖標記。暫存只接受 icons 資料夾入面嘅細 PNG 檔案。

個人化入面嘅「揀選標誌」接受 64 KB 以內嘅 PNG、JPEG 或 WebP 圖片，讀取檔案之前會先檢查類型同大小。標誌會保存喺自己嘅本機記錄，並顯示喺工作區標題隔籬同彈出視窗。「移除標誌」會返回內置標記。

「專注」有三個本機開關：「專注」會收埋說明文字；「減少刺激」會關閉動畫同表情符號裝飾；「引導注意」會為打開咗嘅面板加框。「關閉所有專注模式」會一次過關晒三個。呢啲開關只會改變呢個瀏覽器嘅顯示方式，唔會同桌面應用程式共用。

狀態分頁會連去說明文件網站嘅確切地址 https://ding-ding-projects.github.io/material-file-encryptor/，並以文字顯示地址。

## 筆記

筆記分頁（Alt+4）只會喺呢個瀏覽器保存最多 50 篇短筆記。「新筆記」會喺目前分頁上面打開一個側邊面板，下面打開緊嘅嘢會保持原樣。面板分三步：先寫標題，再喺一頁空白寫筆記內容，最後檢查一次。「下一步」會先檢查每一步先繼續，「返回」會返去上一步；「取消」或者 Escape 會保留草稿，下次撳「新筆記」會還原。關閉面板之後，焦點會返去打開佢嘅按鈕。

用核取方塊揀多篇筆記就可以一齊處理。「匯出所選」會儲存做一個 Markdown 檔案。「刪除所選」要經過同全部重設一樣嘅刻意確認，之後會報告刪除咗幾多篇、幾多篇刪除唔到（嗰啲仍然揀咗）同幾多篇早已唔喺度。

## 預定改動、個人用詞同字型

個人化入面嘅「預定改動」可以喺指定日期同時間改主題或者語言。呢部分會講明時間用邊個時區，例如 America/Toronto (UTC-04:00)。少過一分鐘之後嘅時間，同埋同一分鐘再改同一個設定，都會被拒絕。每個預定改動都可以取消。工作區開住期間到期嘅改動會喺 30 秒內套用；關閉期間錯過咗嘅改動，下次打開時會按次序套用，並講明錯過咗幾多個同最早應該幾時套用。

「個人用詞」會匯入格式係 {"schemaVersion":1,"entries":{"original":"replacement"}} 嘅 JSON 檔案，最多 200 個項目，每個都係 60 個字元以內嘅純文字。只要有一個項目無效，成個檔案都會被拒絕，乜都唔會改。用詞只會改介面文字，唔會改筆記、匯出內容或者傳去桌面嘅任何嘢。每個原本字眼只會換一次，所以一個項目嘅新字眼唔會俾另一個項目再改。「清除用詞」會恢復原本文字。

工作區同彈出視窗用擴充功能入面附帶嘅 Noto Sans 字型，暫存時會對照應用程式嘅字型收據核對。香港中文字型太大，所以中文用系統字型。字型同其他資源都唔會由擴充功能以外載入，用家要求載入點心目錄嗰陣除外。

## 離線說明文件

說明文件分頁（Alt+5）會讀取擴充功能附帶嘅完整說明文件，包括每篇功能文章同佢嘅廣東話版本，唔使網絡連線。搜尋會比對文章標題同內文。文章之間嘅連結會喺分頁入面打開，連去某個標題都得；連去外面網站嘅連結會喺新嘅瀏覽器分頁打開。廣東話模式下，有廣東話版本嘅文章會顯示廣東話版。顯示文章時唔會執行原文入面嘅任何 HTML 或者程式碼。只存在於儲存庫網上 wiki 嘅頁面冇附帶。

擴充功能只會經瀏覽器原生訊息同桌面溝通，冇 HTTP API，所以冇 Postman 集合。

筆記入面寫嘅連結，要用 https 而且冇用戶名或者密碼先會變成連結。佢會喺新分頁打開，唔會傳送來源網址，打開嘅網頁亦唔可以反過嚟控制工作區。其他地址，例如 http 或者 javascript，會保持純文字，並標明唔會打開。

狀態分頁亦直接講明價錢：Material File Encryptor 同呢個擴充功能都係免費，冇購買、冇訂閱、冇收費功能，工作區入面亦唔會問你要付款資料。

## 朗讀、支援個案同螢幕錄影

個人化入面嘅「朗讀」用瀏覽器自己嘅語音引擎。可以揀啱介面語言嘅聲音，同 0.5 至 2 嘅朗讀速度。「朗讀呢個分頁」（Alt+R）會讀出打開咗嘅分頁嘅標題、狀態同控制項，講明每個控制項嘅角色，用唔到嗰陣亦會講。「停止朗讀」、Escape 或者轉去另一個分頁都會停止。新一次朗讀一定會取代之前嗰次。瀏覽器冇語音引擎嘅話，工作區會講明並停用朗讀。

支援分頁（Alt+6）會將支援個案保存喺呢個瀏覽器。每個個案有標題、類別（問題、查詢或者建議）、描述同狀態（處理中、等待中或者已完成），之後可以再編輯。最多可以附加三個 200 KB 以內嘅 PNG、JPEG、WebP、文字或者 JSON 檔案。診斷資料（擴充功能版本、來源提交、介面語言、主題同瀏覽器）會顯示俾你檢查，要剔選核取方塊先會放入匯出嘅個案。筆記、用詞、標誌同憑證永遠唔會包括在內。唔會傳送任何嘢：「匯出」會將個案儲存做 JSON 檔案俾用家自己分享，「刪除」要經過刻意確認。

螢幕錄影要先用瀏覽器自己嘅選擇器揀分頁或者視窗先會開始。「停止錄影」或者喺瀏覽器停止分享就會結束。之後錄影會顯示出嚟俾你檢查，確認冇私人資料之前「儲存錄影」都用唔到。錄影只會儲存喺呢部電腦，「捨棄錄影」會移除佢。

## 點心目錄

點心分頁（Alt+7；模型係 Alt+8，狀態係 Alt+9）顯示公開嘅香港點心目錄，大約有 2,900 款菜式。目錄太大，冇辦法放入擴充功能，所以要揀「由 GitHub 載入目錄」先會由 GitHub 載入。載入之前，分頁會講明會聯絡邊啲主機：raw.githubusercontent.com 攞目錄，api.github.com 攞已發佈插圖清單，打開插圖時就聯絡 github.com。請求唔會帶 cookie 或者來源網址。擴充功能嘅頁面政策只容許連去頭兩個主機，目錄會保留一日，「重新載入目錄」會再攞一次。工作區其他功能都唔使網絡。

搜尋會比對英文同中文名、粵拼同菜式簡稱，類別篩選可以收窄清單。每款菜式會用介面語言顯示描述、材料、致敏原同飲食備註。目錄入面嘅圖片係生成插圖，發佈喺目錄正式版本嘅附件，並標明係插圖而唔係真實菜式相片。未有發佈插圖嘅菜式會直接講明，唔會用其他圖代替。「加入我嘅清單」可以喺呢個瀏覽器保存最多 200 款菜式，「顯示我嘅清單」只會顯示佢哋。

狀態分頁另有「發行代號」部分。「檢查發行版本」只會喺你揀嗰陣聯絡 GitHub，讀取已發佈版本清單（草稿同預覽版本會被忽略），再按版本標籤搵出對應呢個組建嘅發行版本；如果係乾淨嘅來源檢出，亦會按發行說明入面記錄嘅來源提交配對。配對到嘅版本會顯示標籤、中英文代號、菜式相片同發行頁面連結。代號來自已發佈發行說明入面嘅「Code name」一行，相片只會喺位址剛好係公開點心相片項目目錄發行版本入面嘅圖片檔案時先會顯示。冇版本對應就會清楚講明，並將最新已發佈版本標示為「最新已發佈」，絕不當作呢個組建。離線、被限流或者回應格式錯誤都會顯示易明訊息，亦唔會儲存任何資料。

狀態分頁另有「桌面」部分。揀咗**重新整理桌面狀態**之前，唔會請求任何嘢，而且唯一嘅網絡就係經原生訊息同已配對嘅桌面溝通（`read-lock-state` 同 `read-update-state`）。佢會顯示桌面鎖定狀態、桌面版本、更新階段，以及更新下載中或者已就緒時嘅 `md-linear-progress` 進度條（只有進度未知而且冇要求減少動態時，先會顯示不確定進度）。相容性一行會將桌面版本同組建時記錄喺暫存封裝來源資料入面嘅 `desktopVersion` 比較。如果兩者唔同，會講明擴充功能係用另一個桌面版本打包，並請你由目前桌面嘅 `app-<version>\resources\browser-extension` 資料夾重新載入擴充功能。未配對嘅瀏覽器只會見到「請先配對瀏覽器」，冇任何桌面數值。多咗欄位、類型錯誤或者超出範圍嘅答案會被丟棄，並顯示為簡單嘅「桌面冇回應」狀態。路徑、檔案名、網址或憑證都唔會顯示。呢啲檢查只用合成測試資料；冇已安裝嘅桌面或者真實瀏覽器登記參與，所以「桌面」部分未經端到端驗證。

連線分頁有「驗證器」部分，只有一個按鈕：**喺桌面開啟驗證器**。配對之前按鈕停用，你揀之前亦唔會傳送任何嘢。按鈕會要求已配對嘅桌面（`focus-authenticator`）將驗證器移到前面；你要喺桌面批准，預設係拒絕。頁面用淺白文字顯示結果：已顯示、已拒絕、忙碌（桌面已經喺度問緊另一條問題）、未可用（已鎖定、視窗隱藏或者正在關閉）或者請先配對。傳返嚟嘅只有固定嘅狀態字，所以驗證碼、帳戶名稱或機密永遠唔會出現喺瀏覽器。多咗欄位或者未知狀態嘅答案會被丟棄，並顯示簡單嘅「未完成」訊息。呢啲檢查只用合成測試資料；冇已安裝嘅桌面、真實瀏覽器登記或者已擷取嘅原生提示參與，所以呢個按鈕未經端到端驗證。

「進度同發佈」係第十張主頁卡片。佢冇 Alt 快速鍵（Alt+1 至 Alt+9 保持原有部分），亦冇桌面鎖，所以下面講嘅桌面提示就係佢嘅控制。使用者寫一則進度備註，揀目的地（`discussion-comment`、`project-item-status` 或者 `publication-draft`），可以加入最多五個 https 證據連結（每行一個），揀專案項目時再揀項目狀態。打字時已清理預覽會即時更新：移除本機路徑、用戶名稱、電郵地址同似秘密嘅字串，將個人用詞替換還原做原本嘅字，並講明移除咗幾多項。證據連結必須係 https、有公開主機名稱、冇帳密，地址亦唔可以見到秘密；有問題嘅連結會就地解釋。**傳送去桌面等待批准**要用剔選框確認檢閱過預覽先會啟用。呢頁永遠唔會連去代碼平台：只會經服務工作者將已清理嘅要求傳俾已配對嘅桌面（`publish-progress-request`，轉送做 `publish-progress`）。桌面會再驗證一次，顯示原生提示列出目的地、備註同連結（預設係拒絕；無人理會嘅提示 30 秒後撤回），然後回答一個固定狀態字。頁面用淺白文字顯示待處理、已批准、已拒絕、忙碌、不可用或者已逾時，配合 Material 顏色同短過渡，減少動態時會略過。桌面冇發佈途徑、冇可見視窗或者冇專案項目主機權限時，老實答案就係不可用。呢個組建冇接駁任何代碼平台途徑，所以送到桌面嘅要求而家全部答不可用，冇發佈任何嘢。呢啲檢查只用合成測試資料，冇已安裝桌面、真實代碼平台或者已擷取嘅原生提示參與，所以呢個部分未經端到端驗證。

連線分頁喺 **Pair browser** 上方有配對代碼區。已解鎖嘅桌面顯示一次性代碼（「配對瀏覽器」分頁，`begin-qr-pairing`）時，可以喺 **Pairing code (optional)** 輸入或貼上，大小寫、空格同連字號都會忽略。選擇 **Scan code** 只會喺撳嗰一下才開啟鏡頭，並用 `BarcodeDetector` 讀取二維碼圖像。如果瀏覽器冇 `BarcodeDetector`，此區會直接說明不支援掃描，可以改為輸入代碼。讀到代碼、撳 **Stop scanning**、滿 60 秒、出錯、切換分頁、分頁隱藏同頁面關閉時，鏡頭都會停止。代碼只會喺配對要求內送出一次，之後即刻清空欄位；代碼同鏡頭畫面都不會被儲存。格式錯誤嘅代碼會被說明，亦唔會送出任何嘢。代碼係可選：留空就同以前一樣配對，而無論有冇代碼，桌面批准提示都必須出現。配對後，此區顯示「已與呢部桌面配對」，並附上經 `read-update-state` 讀到嘅桌面版本。以上只用合成測試資料同假鏡頭驗證：冇已安裝嘅桌面，亦冇用真實鏡頭掃描真實二維碼，所以端到端路徑未驗證。

狀態分頁另有「學校模式」部分，位於「桌面」部分之下。擴充功能本身冇學校模式，所以呢部分只會顯示桌面嘅模式同要求更改。㩒按鈕之前唔會傳送任何嘢。**讀取學校模式**會詢問已配對嘅桌面（`read-school-mode`），並顯示模式名稱同是否已開啟。讀取之後，第二個按鈕會提供相反嘅更改（**開啟學校模式**或者**關閉學校模式**），並傳送 `set-school-mode`。你要喺桌面輸入保險庫密碼，永遠唔會喺瀏覽器輸入，亦唔使用 Windows Hello。頁面用淺白文字顯示結果：已開啟、已關閉、本身已開啟或已關閉、桌面冇確認、忙碌、未可用或者請先配對。多咗欄位、未知狀態、類型錯誤，或者名稱為空、超過 80 個字元或含有控制字元嘅答案會被丟棄，並顯示簡單嘅「未完成」或者「讀取唔到」訊息。名稱只會當作文字顯示，瀏覽器亦唔會儲存任何嘢。呢啲檢查只用合成測試資料；冇已安裝嘅桌面、真實瀏覽器登記或者已擷取嘅原生提示參與，所以呢部分未經端到端驗證。

狀態分頁另有「鎖」部分，位於其他內容之上。每一個鎖都由桌面擁有，擴充功能自己永遠唔會解鎖任何嘢。㩒按鈕之前唔會傳送任何嘢。**讀取鎖定**會詢問已配對嘅桌面（`read-element-locks`）鎖咗邊啲工作區分頁，並列出每個分頁，各有**鎖定**同**解鎖**按鈕。揀其中一個會為嗰個分頁傳送 `set-element-lock`，你要喺桌面輸入保險庫密碼，永遠唔會喺瀏覽器輸入，亦唔使用 Windows Hello。鎖定同解鎖都需要呢個檢查。被鎖住嘅部分會將卡片留喺主頁，但標示為停用，附有鎖頭標記同說明桌面已鎖定佢嘅無障礙名稱，揀佢會顯示簡短說明，而唔係顯示面板。狀態分頁載有呢啲控制項，所以唔可以喺瀏覽器鎖定；萬一桌面鎖咗佢，「鎖」部分仍然可以使用。聯絡唔到桌面時，頁面會保留最後讀取嘅清單，只喺該頁面使用期間存放喺記憶體，並提示可能已過時。多咗欄位、未知分頁或者類型錯誤嘅答案會被丟棄，並顯示簡單嘅「未完成」或者「讀取唔到」訊息，瀏覽器亦唔會儲存任何嘢。呢啲檢查只用合成測試資料；冇已安裝嘅桌面、真實瀏覽器登記或者已擷取嘅原生提示參與，所以呢部分未經端到端驗證。

狀態分頁另有「解鎖級別」部分，位於「鎖」之下。解鎖階梯、冷卻同每一個挑戰都由桌面擁有，擴充功能只負責讀取同提出要求。㩒按鈕之前唔會傳送任何嘢。**讀取級別**會向已配對嘅桌面查詢（`read-unlock-ladder`）佢喺有序級別之中嘅目前級別，本部分以文字顯示（例如「解鎖級別 3 / 8」），亦以 Material 線性進度條顯示階梯位置。桌面冷卻期間會顯示倒數（英文同粵語），而**要求下一步**按鈕保持停用，因為進行中嘅冷卻永遠唔會喺瀏覽器被跳過。同時亦會顯示桌面報告嘅復原狀態（`none`、`available` 或者 `required`）。**要求下一步**會傳送 `request-unlock-step`，你要喺桌面輸入保險庫密碼，永遠唔會喺瀏覽器輸入，亦唔使用 Windows Hello。頁面會用簡單文字顯示結果（`advanced`、`cooldown`、`complete`、`rejected`、`busy` 或者 `unavailable`），然後跟隨桌面報告嘅級別。擴充功能永遠睇唔到亦答唔到任何挑戰。聯絡唔到桌面時，頁面會保留最後一次讀數，只喺該頁面使用期間存放喺記憶體，並提示可能已過時。多咗欄位、未知級別或者類型錯誤嘅答案會被丟棄，並顯示簡單嘅「未完成」或者「讀取唔到」訊息，瀏覽器亦唔會儲存任何嘢。倒數只用一個計時器，而且只喺倒數顯示時運行，冇動畫；要求減少動態時，進度條亦冇動態。呢啲檢查只用合成測試資料；冇已安裝嘅桌面、真實瀏覽器登記或者已擷取嘅原生提示參與，所以本部分未經端到端驗證。

狀態分頁另有「功能涵蓋」部分。暫存時，組建會寫出功能清單入面每個擴充功能項目嘅紀錄，包括狀態、行為判定、證據判定、原因頭 240 個字元同擴充功能目標身份；如果有項目聲稱已實作，但冇證據檔案、冇已驗證嘅實機同視覺證據，或者行為判定並非「已有」，組建就會失敗。呢部分顯示按狀態嘅數量、搜尋欄同狀態篩選，並附固定說明：呢啲只係清單紀錄，並非已交付嘅證明。原因只有英文紀錄。

針對性測試涵蓋無效及過大快取、儲存失敗、持久儲存、鍵盤分頁、偽造來源路徑同本機 CSP。來源暫存為每個工作區檔案計算雜湊。簽署、已安裝身份、真實瀏覽器互動、視覺對照同顯示縮放仍未驗證。

## 訊息封裝大小量度

獨立共用訊息語氣入口令暫存語言封裝由 431,433 位元組降至 999 位元組。保留嘅暫存收據用 SHA-256 綁定兩個輸出。暫存助手喺 25 種獨立英文／廣東話程度組合都同來源助手一致，共用語言測試亦通過。呢個只量度封裝大小，唔證明瀏覽器啟動或繪畫速度。共用凍結語氣表保持不變，桌面翻譯器繼續重新匯出同一個表。
