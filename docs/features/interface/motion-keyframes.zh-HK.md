# 具型別關鍵影格檢查器

動畫同過渡分頁將關鍵影格編輯交畀已註冊嘅 Material Design 3 檢查器，經原有外觀修改、驗證、歷史同回復流程編輯所選軌道。標準化偏移、絕對毫秒同相對毫秒有明確模式，切換會移除互相衝突嘅座標。多影格移動超出範圍會被拒絕，唔會自動截短。

## 數值同能力界線

所選影格提供直接 CSS 值或者計算起點、可選數字同單位草稿、段落緩動、合成同保持。數字草稿要按套用數值先儲存。不支援嘅值保留喺可攜模型，顯示引擎接受語法唔代表已證明插值。完整動態路徑、多軌時間軸編輯、逐屬性過渡數值流程同完整畫面能力驗收仍然係另外未完成工作。

## 控制項說明

<a id="select"></a>
### 選擇關鍵影格

揀選檢查器編輯嘅影格，唔會修改已儲存動態。

<a id="multi"></a>
### 加入選取集合

將影格加入一次整體移動、複製或者移除嘅集合。

<a id="mode"></a>
### 關鍵影格時間模式

揀標準化偏移、絕對毫秒或者相對毫秒；改模式會移除互相衝突嘅時間欄位。

<a id="time"></a>
### 關鍵影格位置

設定所選時間座標，無效位置會被拒絕，唔會自動截短。

<a id="value"></a>
### 關鍵影格數值

設定屬性數值或者計算起點，顯示引擎拒絕時會保留已儲存影格。

<a id="unit"></a>
### 數值單位

為數字屬性揀明確 CSS 單位，按套用數值之前只係草稿。

<a id="apply"></a>
### 套用數值

透過原有外觀修改流程套用數字同單位一次。

<a id="easing"></a>
### 段落緩動

設定所選段落嘅時間函數，顯示引擎必須接受語法。

<a id="composition"></a>
### 關鍵影格合成

只為呢個影格揀 auto、replace、add 或者 accumulate。

<a id="hold"></a>
### 保持段落

揀離散保持段落，唔會冒充平滑插值。

<a id="add"></a>
### 新增關鍵影格

經原有歷史流程喺偏移一新增一個計算影格。

<a id="copy"></a>
### 複製關鍵影格

只將所選影格複製入呢個檢查器，保留可攜中繼資料。

<a id="paste"></a>
### 貼上關鍵影格

驗證完整結果軌道之後新增本機複製嘅影格。

<a id="remove"></a>
### 移除所選關鍵影格

以一次可復原嘅原有修改移除選取集合。

<a id="move"></a>
### 移動所選關鍵影格

一齊移動所選標準化偏移，具時間影格要用自己嘅時間控制。

<a id="reorder"></a>
### 將影格移前

改編寫清單次序，唔會暗中改時間座標。

<a id="later"></a>
### 將影格移後

將編寫影格移後一位，保留中繼資料。

<a id="reset"></a>
### 重設所選影格

將呢個影格重設為偏移零嘅計算值，唔會移除其他影格。

<a id="clear"></a>
### 清除數值草稿

清除未儲存數字草稿，留空唔會當零套用。

## 驗證界線

原始碼流程測試驗證有限時間、拒絕無效偏移、原有流程拒絕同卸載。實際動態、原生進度、鍵盤同螢幕閱讀器操作，以及完整視窗、語言、主題同顯示比例矩陣仍未驗證。靜態圖片或者儲存數值唔能夠證明動態。
