# 資訊圖示

每個有功能的控制項，緊接在前面都有自己的精簡資訊圖示，所以在閱讀和鍵盤次序上排在控制項之前，換行時亦會跟住自己的控制項。圖示是隨產品附帶的 Material 圖示按鈕，不需要網絡連線，在你開啟之前都會保持關閉。

## 圖示的作用

- 開啟專為該控制項撰寫的說明：用途、選項、預設值、影響、例子、驗證及復原方法。
- 提供有「上一步」和「下一步」的逐步指引。最後一步只會把鍵盤焦點移到真正的控制項，指引不會替你按下它。
- 顯示附有實例的獨立樣本。樣本使用固定的示範數值，只會在說明內運作，不會啟動任何真正的操作。
- 可以用鍵盤操作。按 Enter 或空白鍵開啟圖示，按 Esc 關閉並把焦點交還圖示。桌面程式和網站亦會在指令面板列出「指引」和「解釋」指令。
- 以目前使用的語言（英文、廣東話或兩者並列）說明它的目標。

## 私隱及安全界線

圖示不會讀取控制項的實際數值，不會複製密碼等私人文字，也不會啟動原有操作。停用的控制項仍然會解釋自己，只有「開啟逐步操作」會停用。憑證樣本只接受一段固定的公開示範文字，並且不儲存任何內容。

## 涵蓋範圍

以下清單涵蓋各頁面的靜態標記，以及頁面程式在啟動時建立的控制項。涵蓋檢查會把每個頁面當作文字讀取，只要有功能的控制項既沒有說明、也沒有列明原因，檢查就會失敗。

- 桌面程式（`src/renderer/index.html`）：65 項說明（其中 1 項涵蓋一組相關控制項），6 項列明的豁免。
- 網站（`docs/site/index.html`）：22 項說明（其中 0 項涵蓋一組相關控制項），7 項列明的豁免。
- 瀏覽器擴充功能彈出視窗（`browser-extension/popup.html`）：15 項說明（其中 1 項涵蓋一組相關控制項），0 項列明的豁免。
- 瀏覽器擴充功能工作區（`browser-extension/options.html`）：140 項說明（其中 3 項涵蓋一組相關控制項），3 項列明的豁免。

## 尚未涵蓋的控制項

功能模組在啟動後才建立的控制項，暫時還沒有這種圖示。這是部分涵蓋，並非完成。

- 桌面程式：檔案表格的列控制項、歷史及資源回收筒的列，以及存取、轉換工具、本機模型、伺服器管理、儲存維護、更新和狀態模組的控制項。設定及伺服器準備模組已有各自登記的指引。
- 網站：工作區頁面內的控制項，它們沿用設定指引。
- 瀏覽器擴充功能：筆記、支援單、模型、發佈、伺服器和轉換工具模組建立的列和面板。

## 控制項類型

同一類型的控制項共用選項、驗證、復原方法和逐步指引。下面每個控制項的部分會列出它自己的用途、影響、預設值和例子。

### kind-button

- 選項: 這個操作沒有選項，每按一次就執行一次。
- 驗證: 必要條件未齊備時，操作會保持無法使用，並由它自己的訊息指出缺少甚麼。
- 復原方法: 關閉操作開啟的對話框，先在控制項查看結果，再重新嘗試。
- 步驟: 找到這個圖示正下方的控制項。 / 閱讀它的用途，以及它會改變甚麼。 / 準備好後由你自己使用真正的控制項，這個指引不會替你操作。

### kind-toggle

- 選項: 開或關。
- 驗證: 開關沒有無效數值，若無法使用，旁邊的文字會說明原因。
- 復原方法: 把開關撥回原來位置，撥動後會立即生效。
- 步驟: 找到這個圖示正下方的控制項。 / 閱讀它的用途，以及它會改變甚麼。 / 準備好後由你自己使用真正的控制項，這個指引不會替你操作。

### kind-text

- 選項: 符合欄位長度限制的任何文字。
- 驗證: 文字過長、必填欄位空白或格式不對時，欄位旁邊會顯示錯誤。
- 復原方法: 修正文字，或清空欄位重新輸入；確認前不會儲存任何內容。
- 步驟: 找到這個圖示正下方的控制項。 / 先決定你要的數值，並用下方樣本了解欄位的運作。 / 使用後，請在控制項旁邊查看結果。

### kind-search

- 選項: 任何搜尋文字，輸入時清單會即時縮窄。
- 驗證: 空白搜尋會顯示全部內容；沒有符合項目時只會顯示空清單，不是錯誤。
- 復原方法: 清除搜尋文字即可重新看到所有項目。
- 步驟: 找到這個圖示正下方的控制項。 / 先決定你要的數值，並用下方樣本了解欄位的運作。 / 使用後，請在控制項旁邊查看結果。

### kind-number

- 選項: 控制項允許的最小至最大範圍內的數字。
- 驗證: 超出範圍或不是數字的數值會被拒絕，並在控制項旁顯示訊息。
- 復原方法: 輸入範圍內的數值，或使用提供的重設按鈕。
- 步驟: 找到這個圖示正下方的控制項。 / 先決定你要的數值，並用下方樣本了解欄位的運作。 / 使用後，請在控制項旁邊查看結果。

- 驗證: 只能選擇清單內的項目，所以選擇不會無效。

- 步驟: 找到這個圖示正下方的控制項。 / 先決定你要的項目，並用下方樣本查看結果。 / 使用後，請在控制項旁邊查看結果。

- 驗證: 機密內容只會在提交時檢查，錯誤或過短會被拒絕，而且不會透露任何內容提示。

- 驗證: 真正的控制項會先檢查所選路徑才使用，被拒絕的路徑會保留原有數值。

## 驗證

原始碼檢查會在文件測試環境中掛載每個圖示，並用鍵盤開啟。守衛測試會逐一移除圖示、目標綁定、鍵盤操作和情境面板，並要求每次移除都導致失敗。已建置程式的互動及畫面證據尚未記錄。
