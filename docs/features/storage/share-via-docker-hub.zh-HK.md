# 經 Docker Hub 分享檔案

由已解鎖嘅磁碟傳一個檔案俾其他人。程式會喺呢部電腦用一條新密鑰加密個檔案，將加密資料上載去你嘅公開 Docker Hub 儲存庫 `<account>/material-file-encryptor-shares`，再俾你一個指令。任何人有呢個指令同 Material File Encryptor，就可以下載同開啟個檔案；佢哋唔需要 Docker Hub 帳戶。

相關動作有 **經 Docker Hub 分享…**（磁碟指令列、喺檔案按右鍵，同指令面板）、**接收分享嘅檔案…** 同 **已分享嘅檔案**（指令面板，所以新分頁目錄都會列出，另外 Docker Hub 儲存頁面有一條 **已分享嘅檔案** 連結）。

## 分享檔案

1. 解鎖同掛載磁碟，再揀一個檔案。
2. 揀 **經 Docker Hub 分享…**。如果未登入 Docker Hub，就先登入；引導式登入只會開啟官方頁面。
3. 想嘅話可以開啟 **另外要求密碼短語**，輸入兩次（最少 8 個字元）。
4. 揀 **分享**。對話框會顯示每個階段：讀取檔案、檢查儲存庫、加密、上載，同埋將分享記低喺你嘅清單。**取消** 會停止；無論點都唔會上載任何可讀內容。
5. 複製指令、連結或者現成嘅命令列，再私下傳送。

每個分享最大 1 GiB。第一次使用時儲存庫會建立成公開儲存庫。佢同磁碟備份分開，而且分享用 `share-<random>` 做標籤，所以磁碟清單永遠唔會顯示佢哋。

## 收件人要做嘅嘢

以下任何一個方法都得：

- 將指令貼喺 **接收分享嘅檔案…**。
- 開啟連結。安裝程式時會為目前嘅 Windows 帳戶登記 `material-file-encryptor://` 連結處理程式，解除安裝就會移除。
- 執行命令列，佢用預設嘅每用戶安裝位置：

```
"%LOCALAPPDATA%\MaterialFileEncryptor\MaterialFileEncryptor.exe" --receive "mfe-share:v1:..."
```

程式會匿名下載分享、檢查 digest，再解密第一部份嚟顯示檔案名同大細。**另存為…** 可以揀加密儲存以外任何位置；**儲存到磁碟** 會用新名寫入已掛載嘅磁碟。寫入期間會再驗證成個檔案，先寫去目標旁邊一個臨時名，最後一次檢查通過先至改名。

密鑰錯誤、檔案被改過或者損壞、檔案被截短、由新版本程式整嘅分享，或者指令指去 Docker Hub 以外嘅地方，都會被拒絕，並顯示簡單訊息。訊息永遠唔會重複個指令。

## 指令

```
mfe-share:v1:registry-1.docker.io/<account>/material-file-encryptor-shares@sha256:<digest>#<key>
```

- `<digest>` 指明確實係邊個加密上載；儲存庫同程式都會驗證。
- `<key>` 係 32 位元組嘅分享密鑰。設定咗密碼短語嘅話，就係 `p:` 加上用你密碼短語包住嘅密鑰，所以淨係有指令乜都開唔到。
- 連結形式將密鑰放喺 `#` 後面，呢部份連結永遠唔會傳去伺服器。

## 已分享嘅檔案

**已分享嘅檔案** 會列出你喺呢部電腦分享過嘅嘢：名稱、大細、日期，同有冇密碼短語。**複製指令** 會再複製一次。**撤回** 會將佢由 Docker Hub 移除；**全部撤回** 會對所有有效分享咁做。**由清單移除** 會清走已撤回嘅項目。

撤回會刪除上載本身，唔止係標籤，因為 Docker Hub 會保留冇標籤嘅上載，仍然可以用 digest 下載。只有匿名檢查用標籤同 digest 都再搵唔到，分享先會標示為已撤回。如果 Docker Hub 未確認，分享會保持有效，可以再試 **撤回**。

## 安全說明

- 指令係持有人憑證。任何人有佢，而又未被撤回阻止，就開到檔案。請私下傳送，例如用私訊，唔好放喺公開頻道。
- 分享放喺公開儲存庫。任何人都可以列出標籤同下載加密資料，但只會睇到大細。冇指令就冇人睇得到內容。
- 檔案名、大細同修改時間都喺加密資料入面。上載本身冇附帶任何註解或者描述。
- 格式係 AES-256-GCM，每塊 1 MiB，每個分享用一條全新隨機密鑰。每塊都有由計數器同最後一塊標記組成嘅獨立 nonce，所以重新排序、重複或者截短都會令檢查失敗。
- 密碼短語會用 scrypt（N = 2^17、r = 8、p = 1）加強，永遠唔會上載亦唔會儲存。請用指令以外嘅途徑傳送。忘記咗密碼短語係救唔返嘅，請重新分享檔案。
- 你嘅分享清單會用 Windows 受保護儲存加密，因為每個項目都包含指令。受保護儲存唔可用時，清單只會保留到程式關閉，而且唔會寫入任何嘢。
- 撤回收唔返人哋已經下載咗嘅副本。Docker Hub 可能喺自己嘅儲存保留加密資料直至佢清理為止，但已經冇辦法透過指令搵到。
- 明文係由已掛載嘅磁碟讀取，喺記憶體入面加密，永遠唔會寫入臨時檔案。

## 驗證

自動測試涵蓋格式（喺分塊邊界嘅來回、錯誤密鑰、任何一塊入面翻轉一個位元、截短、重新排序同重複嘅分塊、nonce 唯一性、未知版本）、密碼短語包裝、包括惡意輸入在內嘅嚴格指令解析、加密嘅分享清單，同埋透過真正嘅 registry 用戶端對住假 registry 做完整嘅分享、接收同撤回。另外喺開發電腦用一個細小測試檔案經 Docker Hub 做過一次真正嘅分享同接收，之後撤回；實際涵蓋範圍請睇交接記錄。
