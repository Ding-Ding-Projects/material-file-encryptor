# Modern redesign boards

Design canvas for the next look of the desktop app, in pure Material Design 3: Material 3 color roles generated from a seed, the Material 3 type scale and shape scale, a navigation rail with a FAB, and standard Material 3 buttons, chips, lists, menus, dialogs, switches and progress indicators. Every button carries a Material Symbols icon, and every search has a regex button beside it.

`KIT.md` is the shared specification every board follows.

Boards (23), grouped by canvas page:

- Home and drives: Home, My drive, Right-click menu, Unlock a drive, New drive (name first), Icon and banner, Available offline, History, Recycle Bin.
- Backup and sharing: Docker Hub backup (built for many drives: pinned running strip, filter chips with counts, search, sort, rows that expand in place), Shared files, File hosting, Create a download link.
- Settings and tools: Settings with search and regex builder, Appearance with a motion editor, Local access, Updates with "Update coming soon", Local tools.
- Setup and help: Setup guide, Documentation, Changelog.
- Phone width: Home and My drive at 390 px.

Every board has seed color, theme and motion tweaks and a note beside it on the canvas. The app has not been rebuilt to these boards yet.
