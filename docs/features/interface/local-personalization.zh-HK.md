# 本機個人化設定

`mountPersonalization(container, services)` 掛載語言與語音、外觀、時間表同專注目的地，唔改加密引擎。須匯入 `personalization.css` 同 `appearance.css`。傳回值提供 `store`、`apply()`、`translate()`、`narrator`、`appearance`、`open(sectionId)` 同 `destroy()`。

設定使用有界版本 1 記錄。英語同廣東話訊息風格等級獨立，範圍 1 至 5，預設 5。語言可選英語、廣東話或雙語。表情圖示偏好影響對話框裝飾，唔影響無障礙標籤。只有 `isAuthenticated()` 準確傳回 `true` 後，翻譯器先可套用另外提供嘅個人用詞服務。

## 主程式整合

- `notify(message)` 回報非阻塞通知。
- `history(record)` 接收唔含憑證、圖片位元組或用詞負載嘅設定變更。正式主程式須提供持久受保護歷史；本模組唔聲稱自行建立 Git 歷史版本庫。
- `onChange(settings)` 接收既有渲染同訊息路徑嘅生效設定。語言、趣味等級、主題、密度、字型、動態、顯示名稱同專注值須喺各路徑一致套用。
- `sharedSettings.read()`、`write(record)` 同 `subscribe(callback)` 提供跨桌面程式共用本機學校模式記錄同即時變更。`setSharedCredential(value)` 同 `verifySharedCredential(value)` 須使用受保護本機憑證服務。瀏覽器後備只限同源，唔係通用跨程式儲存，介面須明確說明。
- `attachSearch(input, scope)` 為每個本機設定搜尋連接完整定位正則建立器；選擇器選單亦須提供。
- `fetchScheduleSource(source, constraints)` 喺特權邊界發外部請求，拒絕不安全目標同重新導向、限制位元組同時間，並從憑證保管庫取得憑證。設定記錄唔可含憑證。缺少此介面時外部規則不可用，本機規則繼續。
- `vocabulary.isAuthenticated()` 同 `vocabulary.replace(text)` 只提供本機已驗證渲染邊界。載入、加密快取持久化、清除同替換由獨立上載服務處理。

## 學校模式

所選模式名稱會取代出廠標籤。啟用後強制英語，並從此介面移除廣東話、雙語、趣味等級同表情圖示控制。原有偏好仍儲存，通過驗證停用後恢復；旁白改成英語。主程式須同時抑制所有相關路徑、結果、圖片、驚喜同其他介面，唔可以只改本面板。呢個係便利鎖，唔係加密，亦無法防止可重設本機程式記錄嘅人存取資料。

## 旁白同專注

旁白預設關閉。聲線列舉會訂閱平台延後更新。選擇聲線時儲存穩定 URI，保留暫缺選擇，並回報後備或不可用聲線。英語同廣東話各有選擇器；Both 依次朗讀。速度限制 0.1–3，音高 0–2。分類冷卻 2.5 秒，緊急事件可略過。主程式訊號會讓位畀運作中輔助技術。

Focus、Low stimulation、Time awareness、One thing at a time 同 Momentum 各自儲存，預設關閉。Low stimulation 停用非必要動態。Time awareness 顯示工作階段已過同閒置時間。所選下一步動作重新載入後保留。閒置 20 分鐘會提示，可忽略一小時。Focus 樣式須由主程式用 `data-focus-secondary` 標記次要內容，絕不移除內容。

## 時間表

規則有穩定 ID、標籤、啟用狀態、優先權、日期限制、星期、時區、本機值同可選外部來源。開始時間包含邊界，結束時間唔包含；相同時間代表全日。跨午夜時段用開始當日星期同日期。夏令時間重複本地時間兩次都符合，不存在時間唔會出現。較高數字優先，同優先權按 ID 字典序。排程覆蓋唔改已儲存基本值。

啟動驚喜工具最多評估一次，以 10% 機率抽選；排除首次執行、工作中、錯誤、更新、安靜模式同學校模式，並須有已驗證公開目錄介面。唔會內附或虛構圖片。

## 驗證同餘下工作

Private local history 分頁將密碼加密快照存入獨立有界本機記錄。密碼獨立於元素鎖同本機個人檔案。記錄具鏈式完整性雜湊同已驗證加密；快照遮蔽會排除憑證、驗證器秘密、個人用詞同自訂圖片。支援搜尋、日期／動作篩選、比較、只追加恢復同標籤、已遮蔽中繼資料匯出、保留期同明確確認後修剪。瀏覽器實作係加密日誌，唔係 Git 版本庫。桌面可提供 `historyManager` 同 `historyCredentialStore` 作原生儲存。自動設定記錄只喺歷史解鎖期間開始；鎖定時變更唔會被錯誤聲稱已記錄。完整原生 Git 歷史仍屬獨立整合要求。

`node --test test/local-personalization.test.js` 涵蓋儲存、不安全輸入、模式恢復、跨夜／日期邊界、優先權、外部世代競爭、語言邊界、順序旁白同啟動排除。呢啲係模組檢查，唔證明桌面或瀏覽器渲染。完整選擇器搜尋、全訊息本地化、受保護持久歷史、完整進階外觀、已驗證共用桌面記錄傳播、安全外部網絡同真實建置畫面，仍屬主程式整合或後續驗證。模組唔聲稱完整通用功能已完成。

## 廣東話概覽

個人設定包括語言及語音、外觀、時間表同專注設定。英文同廣東話趣味程度各自儲存，預設為 5。啟用學校模式後只用英文，原有語言同趣味設定保留，通過本機驗證關閉後恢復。呢個只係介面限制，唔係資料保安。

語音旁白預設關閉，按本機實際聲線顯示，兩種語言依次播放。時間表使用指定時區；跨午夜歸開始當日，臨時設定唔覆蓋基本設定。專注選項獨立開關，預設全關。桌面共用記錄、受保護歷史、外部來源同完整畫面驗證需要主程式整合，未驗證部分唔會當成完成。

### 漸進顯示投影

個人用詞以有界事件迴圈分段投影至適用顯示文字同無障礙屬性。唔會因文件總節點數超過固定上限就拒絕文件。每段預設最多 500 節點，可設定至 2,000；後續用計時器，讓輸入同繪製喺分段之間執行。普通變更記錄只重新處理已變子樹，包括發現嘅 shadow roots，唔重新掃描全文件。

`refresh()` 對小文件保留同步結果；仍有分段時傳回 `{ projected: false, reason: 'pending' }`。需要完成顯示嘅整合可等候 `whenSettled()`。撤銷啟用或銷毀檢視會取消待處理工作，立即恢復追蹤到嘅已修改顯示值。替換例外會恢復較早寫入，並以 `replacement-failed` 結束。標準程式資料、輸入、程式區塊、匯出同網絡請求唔會被改寫。投影係漸進式，因此進行中可能暫時同時顯示原文同個人化文字，唔係整份文件原子繪製。

聚焦驗證涵蓋超過 42,000 節點合成文件、有界排程、變更子樹更新、shadow-root 移除、取消、恢復，同較後分段例外後回復。單靠呢啲唔構成原生執行時或安裝器驗收。
