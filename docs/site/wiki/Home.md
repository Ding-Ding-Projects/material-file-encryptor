# Material File Encryptor wiki

Material File Encryptor provides an encrypted Windows Explorer drive, recoverable file history and a Recycle Bin. Use synthetic vaults for verification; existing vaults and installations are not test fixtures.

## Documentation

Complete categorized articles, this wiki and the reviewed historical capture gallery are hosted directly in the [documentation website](https://ding-ding-projects.github.io/material-file-encryptor/). The website documents the separate Windows application and cannot unlock a vault.
