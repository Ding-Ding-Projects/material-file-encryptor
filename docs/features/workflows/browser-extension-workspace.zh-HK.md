# 瀏覽器擴充功能工作區

彈出視窗嘅「開啟工作區」會開啟擴充功能自己嘅選項分頁。連線、個人化同狀態有獨立內部分頁，支援左右方向鍵同 Home/End。切換唔會重建有焦點嘅控制。畫面使用本機 Material 元件同已封裝正則搜尋，唔載入外部執行資產。

語言（英文、廣東話或雙語）、主題（跟隨系統、淺色或深色）同所選分頁使用有版本同大小限制嘅擴充功能本機儲存。唔使用瀏覽器同步、廣泛主機權限或新增儲存權限。無效或過大快取會退回預設值。寫入失敗會保留可用嘅頁面狀態，並清楚講明變更未儲存。重設只恢復瀏覽器本機預設值。雙語次要標籤另起一行。

連線同傳輸狀態分開顯示。配對唔會開始傳輸。連線中斷或回應無效會清除即時狀態，唔保留舊成功訊息。只有確切擴充功能彈出視窗同選項頁來源可用配對、狀態同斷線通道。原生傳輸仍須喺桌面確認。

配對唔等於本機身份驗證。個人用詞、共享模式、憑證、原生設定、伺服器管理、轉換器同模型控制要有經檢閱嘅已驗證原生通道先可用。呢個初始部分未實作幽默程度同對話框表情符號控制。版本讀自擴充功能清單，來源組建同更新時間證明未可用。Status Hub 登記未可用。

針對性測試涵蓋無效及過大快取、儲存失敗、持久儲存、鍵盤分頁、偽造來源路徑同本機 CSP。來源暫存為每個工作區檔案計算雜湊。簽署、已安裝身份、真實瀏覽器互動、視覺對照同顯示縮放仍未驗證。
