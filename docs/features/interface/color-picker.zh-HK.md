# 外觀色彩選擇器

字體檢查器使用已註冊嘅 Material Design 3 控制項。套用顏色會經原有外觀修改流程，保留目前目標同圖層定位、驗證、鎖定、歷史同回復機制。調色盤修改同共用彩虹速度亦經同一設定流程。

## 表示方式同儲存

具名顏色、HEX/HEX8、RGB/RGBA、HSL/HSLA、HSV/HSB、HWB、CIELAB/LCH、OKLab/OKLCH 同 CMYK 可以雙向轉換。儲存採用附透明度嘅 8 位元 sRGB。Lab/LCH 採用 D50 適應；OKLab/OKLCH 採用 D65。超出色域嘅草稿會喺裁切之前被拒絕。CMYK 只係無色彩描述檔嘅近似值，唔係經校準嘅印刷打稿。來回轉換量化可能令通道相差一個位元組。

連續色相同飽和度、亮度、透明度數值共用一份草稿。具名、最近同自訂靜態調色盤唔會收納彩虹。彩虹跟共用速度同減少動態效果設定。未能確認相關背景完全不透明時，對比度會顯示不可用。

## 平台能力

複製需要已接納嘅剪貼簿服務或者瀏覽器剪貼簿 API。螢幕取色需要瀏覽器 EyeDropper 同使用者操作。取色保留透明度，必須套用先儲存；取消、鎖定同卸載會令遲到結果失效。不支援嘅能力會明確顯示不可用，唔會聯絡外部色彩服務。

## 控制項說明

<a id="entry"></a>
### 顏色輸入

用已選色彩表示法輸入顏色。

只會改變草稿，要按套用顏色先會透過原有外觀操作儲存。

例子：可以試用 #6750a480 半透明紫色。

<a id="space"></a>
### 色彩空間

選擇輸入欄顯示嘅雙向色彩表示法。

轉換會保留目前八位元 sRGB 顏色同透明度。

例子：選擇 HSV 可以編輯色相、飽和度同明度。

<a id="hue"></a>
### 色相光譜

沿完整色相環連續調整。

更新草稿色相，同時保留飽和度、明度同透明度。

例子：色相 120 會選擇綠色區域。

<a id="saturation"></a>
### 飽和度

設定草稿由灰色至完全飽和色相嘅距離。

零會產生灰色，一百會保留完整色相。

例子：飽和度 50 可以令鮮色柔和一啲。

<a id="brightness"></a>
### 明度

設定 HSV 明度，由黑色至目前完整色相。

零係黑色，一百會保留最高色彩通道。

例子：明度 70 會令草稿變暗，唔會改變透明度。

<a id="alpha"></a>
### 透明度

獨立設定透明度，唔會改變色彩通道。

零係透明，一係不透明，已接受數值會用八位元透明度儲存。

例子：透明度 0.5 大約係半透明。

<a id="apply"></a>
### 套用顏色

將已檢查草稿儲存到呢個指定屬性同狀態。

一次原有修改會一齊儲存顏色同最近使用記錄。

例子：檢查對比度讀數之後，先套用有效草稿。

<a id="copy"></a>
### 複製表示法

只複製目前已轉換嘅顏色表示法。

使用獲准剪貼簿服務，唔會複製其他設定。

例子：要保留透明度時，請複製 HEX8。

<a id="eyedropper"></a>
### 選取畫面顏色

用戶明確操作之後，要求受支援瀏覽器取色器選擇一個像素。

只會將已選 sRGB 顏色載入草稿，唔會收集圖像或者連續畫面資料。

例子：取消瀏覽器取色器，就會保留之前草稿。

<a id="swatch"></a>
### 色板格

將靜態色板載入草稿。

選色板唔會儲存目標，要按套用顏色先會儲存。

例子：選擇最近用過嘅顏色，檢查之後先套用。

<a id="name"></a>
### 自訂顏色名稱

為本機可重用靜態顏色命名。

名稱只會標示色板項目，唔會改變目標或者應用程式名稱。

例子：可以將藍色色板命名為連結藍色。

<a id="save"></a>
### 儲存自訂顏色

將目前靜態草稿同名稱儲存到本機色板。

沿用原有色板修改同歷史記錄路徑。

例子：儲存已檢查嘅品牌顏色，方便重用。

<a id="remove"></a>
### 移除自訂顏色

移除已選自訂色板項目。

目標樣式同其他色板項目唔會改變。

例子：移除過時自訂色板，唔會改變文字。

<a id="rainbow"></a>
### 動畫彩虹

為呢個屬性使用顯示引擎認得嘅彩虹標記。

標記會以結構資料儲存，唔會變成色板顏色字串。

例子：可以為強調色選擇彩虹，減少動態時會停留喺一個色相。

<a id="speed"></a>
### 彩虹速度級別

改變全部目標共用嘅唯一彩虹速度級別。

沿用原有速度級別至時間對應。

例子：級別 10 會比級別 1 轉得快。

<a id="reset"></a>
### 重設顏色覆寫

移除已選圖層嘅明確顏色覆寫。

透過原有修改同歷史記錄路徑，令目前繼承嘅目標顏色生效。

例子：重設醒目提示覆寫，唔會刪除色板。

<a id="search"></a>
### 搜尋顏色

用可見名稱或者表示法篩選靜態色板項目。

搜尋唔會改變顏色，亦唔會授權改變樣式。

例子：搜尋 blue 可以搵到有名稱嘅藍色色板。

<a id="clear-entry"></a>
### 清除顏色輸入

清除未儲存表示法，唔會刪除已接受目標顏色。

輸入或者選擇有效顏色之前，唔可以套用。

例子：先清除輸入錯誤嘅 HEX8，再輸入替代值。

<a id="clear-hue"></a>
### 清除色相草稿

先清除數值色相草稿，再輸入新角度。

已接受顏色唔會改變，未完成草稿唔可以套用。

例子：先清除唔合用嘅色相角度，再輸入 120。

<a id="clear-saturation"></a>
### 清除飽和度草稿

清除飽和度百分比，唔會儲存灰色。

補回百分比之前，缺少數值會視為無效。

例子：清除飽和度輸入錯誤，再輸入 0 至 100 之間嘅數值。

<a id="clear-brightness"></a>
### 清除明度草稿

清除明度百分比，唔會儲存黑色。

缺少明度數值時，唔可以套用未完成顏色。

例子：先清除明度草稿，再輸入 70。

<a id="clear-alpha"></a>
### 清除透明度草稿

清除透明度草稿，唔會令目標變透明。

空白透明度係無效數值，唔係零。

例子：先清除透明度輸入錯誤，再輸入 0.5。

<a id="clear-speed"></a>
### 清除彩虹速度草稿

清除未儲存共用速度級別，唔會改變全域級別。

輸入有效整數之前，原有全域時間會繼續生效。

例子：先清除輸入錯誤，再輸入級別 5。

<a id="clear-name"></a>
### 清除自訂名稱

只清除未儲存自訂顏色名稱。

草稿顏色同現有自訂色板項目會保留。

例子：為新自訂色板命名之前，先清除舊標籤。

## 驗證界線

原始碼流程測試涵蓋轉換、無效草稿、原有流程拒絕、調色盤修改、複製同取色取消。瀏覽器解碼、實際剪貼簿同取色權限、原生橋接可用性、安裝後操作同畫面排版仍未驗證。完整視窗大小、語言、主題同顯示比例矩陣仍然待驗證。
