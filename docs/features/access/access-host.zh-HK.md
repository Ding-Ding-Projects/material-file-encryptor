# 特權存取主機整合

存取主機負責核實密碼、PIN 同 TOTP，保存錯誤次數、等待期限、一次性挑戰同每小時最多三次成功跳過等待嘅額度。畫面端唔可以指定操作者身分、學校模式或新期限。答啱挑戰只會結束等待，唔會登入設定檔或解鎖元素。

## 整合合約

主機建立一個 `createAccessHost({dataDirectory, credentials, getActor, getSchoolMode})`。`getActor` 必須來自已核實嘅主畫面傳送者；`getSchoolMode` 必須讀取受信任原生設定，兩者都唔可以取自畫面請求。橋接入口保留原有驗證，並呼叫 `validateAccessHostRequest`。

受保護儲存須提供 `get`、`set`、`delete`、`list` 同 `compareAndSet(key, expected, replacement)`。比較同寫入必須喺同一條儲存序列內完成；null 代表不存在或刪除，false 代表原值已改變。缺少原子操作時，歷史設定同修改會停止。

所有驗證器寫入同刪除經 `host.setCredential` 同 `host.deleteCredential`，保留原有識別碼限制。`lock:` 同 `profile:` 主機記錄唔可經畫面憑證 API 讀取。關閉時呼叫 `host.close()`。存取畫面使用 `services.accessHost`；顯示名稱透過 `displayNameSet`、`displayNameRead` 同 `onDisplayNameRestore` 同步，還原唔應額外產生另一筆修改。

## 加密本機歷史

歷史使用獨立密碼同綁定操作者嘅十分鐘權限。設定檔登入唔會自動開放歷史。AES-256-GCM 快照包含驗證器記錄同顯示名稱，應用程式資料目錄內嘅 Git 只保存密文同非敏感動作名稱。受保護尾端摘要檢查遺失或倒退嘅記錄。

修改使用原子比較寫入。記錄失敗只還原該次操作擁有嘅值；遇到其他寫入會保留新值並回報復原需要。還原會新增記錄，唔會改寫舊歷史。介面提供標籤、日期及動作篩選、隱去內容嘅比較與匯出、保留期限同雙重確認清理。

清理只喺管理介面隱藏過期記錄，唔會刪除歷史密文，亦唔保證安全抹除或釋放空間。忘記歷史密碼暫時冇復原或重設途徑。Git 保存後至尾端摘要保存前若中斷，歷史會停止並要求本機復原；兩個儲存介面唔會被描述為同一個原子交易。

## 可用性與驗證

需要受支援 Git 執行檔。缺少 Git 時會喺密碼設定保存前停止。安裝包供應同正式橋接接線仍須獨立驗證，瀏覽器模式無法提供呢個特權邊界。

`test/local-access-host.test.js` 使用合成資料同臨時 Git，檢查密文、匯出、重播、到期、操作者隔離、額度、取消、原子復原、並行寫入、缺少執行檔同獨立密碼到期，唔會存取真實保管庫。正式畫面、原生傳送者同封裝整合驗證仍待記錄。
