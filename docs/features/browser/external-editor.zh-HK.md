# 由瀏覽器要求開啟外部編輯器

配對後，喺連線分頁重新讀取狀態，檢查已安裝桌面主機有冇支援外部編輯器。「喺桌面揀檔案同編輯器」會開始一次有時間限制嘅原生要求。桌面先問你繼唔繼續，再用原生選擇器揀檔案同編輯器，最後顯示所選路徑並要求確認開啟。任何一步取消都唔會啟動編輯器。

瀏覽器唔會提供路徑、文件識別碼、執行檔、參數或者登入資料，只會用桌面揀選結果。現有編輯器服務只接受支援而且有 Microsoft 有效簽署嘅編輯器，啟動前會重新驗證檔案內容，亦唔會經 shell 執行。瀏覽器只收到 `opened` 或者 `cancelled`，唔會收到路徑或者檔案內容。`opened` 只代表程序發出咗啟動事件，唔代表編輯、返回或者儲存已驗證。

要求兩分鐘後到期。「取消要求同中斷連線」會撤銷連線。鎖定磁碟、替換配對、中斷連線或者關閉主機，都會令要求失效。每次非同步揀選之前同之後，以及啟動程序之前，都會重新檢查權限。取消後原生選擇器可能仍然開住，但之後嘅結果唔會啟動任何嘢；未完成嘅選擇器亦會阻止新要求。已確認並啟動嘅編輯器唔會因瀏覽器取消而關閉。

## 驗證同限制

`test/extension-editor-workflow.test.js` 檢查明確要求類型、配對替換、撤銷、期限、原生揀選同確認，以及簽署驗證期間取消會阻止啟動。`test/extension-editor-transport.test.js` 檢查原生訊息框架同擴充功能背景轉送，包括拒絕多餘欄位，以及唔轉送含路徑嘅原生回應。

以上檢查使用可重複嘅原生程序同選擇器測試替身。實際已簽署擴充功能安裝、原生對話框、編輯器啟動、返回同儲存仍未驗證。呢個流程唔會宣稱提供轉換、模型管理或者學校模式。
