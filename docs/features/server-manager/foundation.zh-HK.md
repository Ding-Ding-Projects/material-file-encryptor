# 伺服器管理基礎

呢個單元提供官方 Java 版本探索、指定版本嘅伺服器發佈中繼資料解析、綁定來源嘅設定描述、類型化設定控制項，同明確列出四種目標嘅能力清單。佢唔會安裝或執行伺服器、接受授權、聯絡 SSH 主機、接管程序或容器，亦唔會修改現有設定。

## 版本目錄及來源

`refreshJavaCatalogue` 會讀取 Mojang 完整官方版本清單，設十秒逾時、四 MiB 回應上限、HTTPS 來源限制，同拒絕重新導向。所有回傳版本都會保留，包括歷史渠道。重複身份、缺少最新版本項目同不可信中繼資料網址都會被拒絕。快照會記錄精確來源 SHA-256 同擷取時間。`catalogueState` 會分辨現行、過期、離線同不可用快照；離線唔等於現行。

`resolveJavaDistribution` 會先按版本清單嘅 SHA-1 驗證指定版本中繼資料，再讀取專用伺服器項目。缺少伺服器下載會明確標示不可用。如果官方中繼資料冇列出執行環境，歷史 Java 執行環境要求會保持未解析。已解析下載會記錄網址、SHA-1 同大小，但唔會聲稱已驗證下載位元組、已安裝、已驗證執行，或者已取得 EULA 同意。完整官方歷史 Bedrock 發佈目錄仍然不可用，現行下載頁填補唔到呢個缺口。

## 設定及目標界線

描述必須包含版本類別、精確版本、已驗證發佈 SHA-256、官方來源修訂、說明、權限、持久化使用者同即時或重新啟動語義。布林值對應開關、列舉對應可搜尋選擇器、數字對應有界數值控制項，文字對應文字控制項。呈現器由擁有者提供本地化文字同真實動作回呼。未知擴充設定會原封不動保留；編輯未知擴充內容需要真實描述。呢度冇提供通用 JSON 或 shell 編輯器。

本機程序、本機容器、SSH 程序同 SSH 容器分別列出身份同權限證明要求。所有執行目標轉接器目前都停用，並明確標示尚未實作。連線中斷絕對唔可以當成伺服器已停止。

## 整合交接

只可以將目錄模組匯入可信主機層，並提供明確更新同擁有者快取持久化。唔好向呈現器暴露任意擷取網址。啟用編輯之前，設定描述必須綁定實際已驗證發佈，同已生成或按版本審核嘅預設值。透過現有本地化介面掛載 `mountConfigurationControls`，並提供既定權限、確認、持久化同歷史動作。登記表及導覽、控制項上方自選引導、完整文件及說明、結構化集合控制項、原生 IPC、授權、執行生命週期、擴充套件同實際呈現驗收，仍然屬於整合或後續實作工作。呢個單元冇改動共用登記表或導覽檔案。

執行 `node --test test/server-manager.test.js`。呢啲測試證明來源行為同反向清單及設定檢查，唔代表已安裝伺服器或 GUI 驗收。
