# 本機模型套件

套件由有權限嘅桌面程序或者已驗證回送轉接器協調。渲染程序只會收到指定動作同事件，絕不會收到通用 HTTP 用戶端、執行檔啟動器或者任意端點設定。

- [操作、邊界同復原](./local-models.md)
- [廣東話操作及復原指引](./local-models.zh-HK.md)
- [原生主程序信任邊界](./native-host.md)
- [已審閱 Windows 發行來源](./release-provenance.md)

Ollama HTTP API 係外部本機服務 API；本功能冇引入公開 HTTP API，亦冇 Postman collection。

目錄紀錄保留每個變體自己嘅描述同能力。家族摘要另外以 `familyDescription` 同 `familyCapabilities` 公開；家族能力唔代表每個變體都支援。即使已列舉所有觀察到嘅連結頁面，整體目錄完整性仍然未知。
