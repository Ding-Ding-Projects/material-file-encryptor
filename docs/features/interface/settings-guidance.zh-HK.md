# 可選設定指引

可選的逐步指引及解釋入口會放在確切控制項正上方。指引只會在使用者要求時開啟。原有控制項繼續可用，並負責實際驗證、鎖定、身分驗證、確認、歷史及操作。上一步會保留目前草稿；取消只會停止指引，不會聲稱撤銷已完成修改。

## 交付範圍

目前證據包括設定來源整合及針對元件與處理程序的檢查。本機及瀏覽器實際互動、完整搜尋建立器指引、全部巢狀編輯器控制項、唯讀元素解釋及每次點擊畫面證據仍未驗證。這份清單不代表整個產品完成。
