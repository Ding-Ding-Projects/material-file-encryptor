# 唔使揀資料夾嘅 Docker Hub 磁碟

Docker Hub 磁碟會將加密檔案放喺程式自動建立嘅資料夾，再備份去 Docker Hub 儲存庫。你完全唔使揀儲存或者快取資料夾。兩個流程都由同一個儲存庫選擇器開始。

- **建立磁碟**會問你磁碟放喺**喺呢部電腦**（原有流程，冇改動）定係 **Docker Hub**。
- **由 Docker Hub 開啟磁碟**會搵出呢個程式已經備份過嘅磁碟，還原你揀嘅嗰部，再解鎖。

兩個都喺命令面板有，名為 **New Docker Hub drive** 同 **Open a drive from Docker Hub**，所以新分頁目錄都會列出。建立同解鎖對話框亦有 **Use Docker Hub, no folders** 或者 **Open from Docker Hub** 按鈕。

## 建立 Docker Hub 磁碟

1. 揀**建立磁碟**，再揀 **Docker Hub**。唔會出現資料夾選擇器。
2. 如果未登入 Docker Hub，請先登入。引導式登入會顯示一次性代碼並開啟官方頁面。密碼只會喺 `login.docker.com` 輸入，代碼亦唔會被儲存。
3. 喺選擇器揀一個儲存庫。帳戶自己嘅 `material-file-encryptor-storage` 會優先建議，而且選擇器會講明佢入面已經有幾部磁碟。如果儲存庫唔存在，會建立成公開儲存庫。
4. 輸入磁碟名稱、磁碟機代號同密碼，或者揀密鑰檔案。對話框會再提醒公開警告：任何人都可以下載加密檔案，而且 `vault.json` 可以離線估密碼，所以請用長密碼短語或者密鑰檔案。
5. 揀**建立磁碟**。每一步會按次序顯示：建立資料夾、建立並掛載磁碟、準備儲存庫、儲存目的地同每小時排程，以及首次加密同步。背景工作會維持關閉，直至你自己開啟。

如果磁碟本身建立唔到，未用過嘅資料夾會被移除，亦唔會保留任何嘢。如果之後嘅步驟失敗，磁碟會保持掛載，對話框會講明原因，而**重試**只會重做失敗嗰一步。

## 由 Docker Hub 開啟磁碟

1. 揀**由 Docker Hub 開啟磁碟**，或者喺解鎖對話框揀 **Open from Docker Hub**。
2. 揀一部磁碟。喺你儲存庫搵到嘅每部磁碟都係一張卡，撳一下就連同最新快照一齊揀咗。
3. 睇一睇快照清單。最新嗰個已經揀咗，而且還原唔會改動 Docker Hub。
4. 揀**還原**。快照會被下載，每個分段都會驗證，`vault.json` 最後先寫入。內容會還原到程式自己資料區入面嘅新資料夾；**進階：自己揀資料夾**就會改用系統資料夾選擇器。
5. 輸入密碼或者密鑰檔案，再揀**解鎖並掛載**。儲存庫會連結到磁碟，排程保持關閉。

## 儲存庫選擇器

- **搜尋**用共用搜尋控制項，旁邊有自己嘅正則表達式工具。儲存庫名稱、磁碟名稱同磁碟 id 都會被搜尋。
- **篩選**：全部、有磁碟、冇磁碟、公開同私人，每項都有數量。
- **每一行**顯示儲存庫名稱、公開或私人標籤、最後推送時間、Docker Hub 有提供嘅大小，以及搵到幾部磁碟。
- **磁碟卡**喺儲存庫下面顯示磁碟名稱（如果快照有帶）、簡短磁碟 id、最後備份時間、快照數量同大小。
- **鍵盤**：方向鍵、Home 同 End 可以喺儲存庫名稱同磁碟卡之間移動。
- **進度**：掃描時結果會逐步出現，**重新整理**會再掃描，讀唔到嘅儲存庫只會喺自己嗰行顯示訊息，唔會阻擋清單。

清單涵蓋你嘅帳戶同 Docker Hub 容許你讀取嘅組織。如果列唔到組織，選擇器會講明並只顯示你自己嘅帳戶。

## 磁碟點樣被偵測

程式會讀取儲存庫嘅標籤，將快照標籤（`mfe-<device id>-<revision>`）按裝置分組。每部裝置最新嘅快照會被取回並驗證，佢經過驗證嘅設定就講出係邊部磁碟。掃描喺頁數、儲存庫、標籤、裝置、並行數量同時間上都有上限，完成嘅結果會喺今次使用期間保留。新快照亦會將磁碟名稱寫成選填嘅 manifest 註解 `io.material-file-encryptor.drive-name`。名稱係使用者文字：任何人只要睇到公開儲存庫就睇到，所以唔好放私人內容。

## 檔案放喺邊度

本機加密副本放喺程式資料區入面每部磁碟專屬嘅資料夾，即 `Drives\<drive id>\storage` 同 `Drives\<drive id>\cache`。呢度係快取加本機儲存，只有密文會離開電腦。**顯示資料夾**會開啟佢。每個資料夾都係全新建立、從不重用、唔會經過連結，而且喺平台容許嘅情況下只限你嘅帳戶存取，亦同其他資料夾一樣遵守目的地規則。

## 失敗情況

- **未登入或者離線**：選擇器會講明係邊種，並提供引導式登入。
- **帳戶唔可以建立或者寫入嘅儲存庫**：對話框喺改動任何嘢之前先講明原因。
- **中斷或者失敗嘅還原**：還原建立過嘅所有嘢都會被移除，唔會留低半途還原嘅磁碟。
- **解鎖時密碼錯誤**：已還原嘅資料夾會保留，只重試解鎖。

## 驗證

主程式部分、選擇器同兩個流程都有用模擬登錄嘅原始碼測試。真正 Docker Hub 嘅列出、上載同還原唔包括喺原始碼測試入面，喺用真實帳戶執行之前仍然未驗證。
