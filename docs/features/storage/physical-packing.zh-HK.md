# 加密分段實體打包

新保管庫預設每個實體分段上限為 80 MiB，即 83,886,080 bytes，已包括驗證加密記錄的額外資料。最高可設定 90,000,000 bytes。每個加密記錄仍然最多 64 KiB，並非把整個 80 MiB 檔案載入明文記憶體。

## 寫入及關閉

每次檔案系統寫入都先完成加密物件及本機日誌，才確認持久儲存成功。複製期間可能暫時產生很多細分段。最後一個可寫入描述符真正 Close 後，背景工作才打包；Cleanup 並不代表記憶體映射已放手，兩個寫入者亦必須全部關閉。

背景工作固定原有記錄快照，在命名空間鎖及檔案系統回呼鎖以外讀取、驗證和打包。採用新記錄之前會重新核對路徑、檔案身分、版本、寫入者世代、活動寫入者及目標上限。期間若有修改、縮短、改名、刪除或重建，就不會蓋過新資料。

完整替代記錄表透過原子日誌快照保存，並清除已被取代的疊加記錄。所有新加密分段必須先完成。採用前取消或中斷，原有資料仍有效；採用後中斷，新資料已持久保存。中途產生而未引用的密文保留，來源儲存不會自動清除歷史物件。

## 現有磁碟遷移

原生命令 `startPacking` 接受可選 `path` 及 `partSizeBytes`。沒有路徑時會排程所有現有檔案，並保存新預設上限；指定路徑則只處理檔案或子目錄。預設目標是 83,886,080 bytes。使用 `operations` 查進度及 `cancelOperation` 取消。

排隊的檔案身分及目標上限會寫進加密日誌，重開後可以繼續。已完成的打包版本會略過。仍有寫入者的檔案留在隊列，關閉或定期維護時再處理。命令完成不代表所有寫入者已關閉，請同時查看 `pendingPackingFiles` 及 `activeWriters`。取消不會撤銷已採用的完整檔案，並會持久暫停自動打包；定時維護及關閉寫入者都不能自行重開。再次明確執行 startPacking 才會繼續。狀態提供 paused，診斷提供 packingPaused。

取消操作會保留該次打包要求的世代，直至發佈結束。舊操作的取消不能暫停較新的明確打包或重新分段要求。

## 發佈及狀態

來源發佈逐批處理已持久保存的提交，在核心鎖以外驗證已落地的來源分段及複製缺少的密文，完成後才寫入提交中繼資料，最後只確認該批實際已上載的提交。傳輸層已確認可用但尚未下載的不可變物件保留延遲讀取，不會為未改動內容額外下載。已落地來源分段若損壞，只能由已驗證的本機密文修復；否則提交繼續待發佈。期間新增的提交不會被誤清除。來源已寫入但本機尚未確認的情況可安全重試。來源離線時，本機持久資料保留。

本機加密歷史每個子程序最多雜湊 64 個路徑，參數預算為 24,000 字元、批次預算為 128 MiB；單一較大物件仍受原有發佈上限限制。每個索引更新子程序亦最多處理 64 項。不可變密文比較、有限發佈批次，以及分段先於中繼資料的次序全部保留。

同步先在鎖外取得來源資料，重建命名空間前再保存期間發生的本機修改。檔案 Flush 及閒置版本保存只負責本機持久性，關閉檔案不會同步打包整個大檔案。

`storageDiagnostics` 提供目標上限、待打包檔案、活動寫入者、目前引用分段與實體 bytes、只屬歷史的分段與 bytes，以及暫存分段數目。無法在本機或來源觀察的物件只計數、不計 bytes。歷史仍然保留，所以遷移期間總用量可能增加，不能把目前分段數當作已釋放空間。

## 驗證界線

原生合成測試涵蓋雙寫入者、匯出快照、同時修改、改名、刪除重建、採用前取消、快照前後中斷、縮短後稀疏增長、慢速來源及確認重試。大型測試超過兩個 80 MiB 上限，使用 64 KiB 與 1 MiB 寫入並核對 SHA-256。合成測試不代表已驗證安裝版 Explorer 複製、真實磁碟遷移或程序記憶體峰值；這些需要另外記錄實際執行證據。

## 綁定來源的合成驗收

來源 `e06df2a14643932f5f23289ae4eea2d8e45b3676` 經完整 `build.bat /s` 入口建置，結束碼為 0；最終原生核心測試通過 43/43 項。套件內原生輔助程序的掛載測試使用 167,895,616-byte 合成檔案、64 KiB 及 1 MiB 寫入、兩個可寫入描述符，以及保留映射的寫入程序。打包後有三個目前分段，重新驗證開啟前後 SHA-256 均為 `0BFB35A1F43C4A06403A7BC845E1D1B6A8D55088918931CA548E2DB6D734BE60`。

打包及發佈期間，其他檔案 I/O 分別耗時 12.5979 ms 及 14.0371 ms；狀態回應分別為 0.2705 ms 及 0.2172 ms。輔助程序抽樣私人記憶體最高為 78,237,696 bytes，工作集峰值為 117,022,720 bytes。原生傳輸保留量峰值為 852,292 bytes，上限為 67,108,864 bytes。這些數據不包括其他程序，亦非所有情況的記憶體上限保證。核心測試強制回收後多保留 2,103,416 managed bytes，並非峰值配置量。

另一個沒有掛載的獨立合成探測，使用同一套件輔助程序，實測目前分段為 83,866,588、83,866,588 及 254,672 bytes，合共 167,987,848 bytes。距離上限的剩餘容量分別為 19,492、19,492 及 83,631,408 bytes。其 167,895,616-byte 檔案經驗證匯出後，SHA-256 為 `4af23f0cbe2c2b15762df1381f430e1fff026ce509f80966d3178bfacaf964eb`。這個獨立檔案的內容模式不同，不能當作早前掛載測試的逐段觀察。

掛載測試完成後及重新驗證開啟後，卸載分別在 26.8498 ms 及 11.471 ms 完成，均為第一次嘗試，原有 60,000 ms 時限沒有改動。映射寫入程序及輔助程序正常結束，沒有強制終止；合成磁碟已消失，所屬測試資料亦已移除。較早來源 `1fd3581` 曾超過同一時限，仍記錄為未完成，不會因後來成功而改寫歷史。來源、二進位雜湊、量度及限制見 `docs/evidence/storage-packing-e06df2a.json`。測試沒有接觸使用者保管庫，亦沒有執行安裝、更新或移除。
