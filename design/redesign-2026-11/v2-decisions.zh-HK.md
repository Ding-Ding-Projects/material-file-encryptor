# 第二版外框同頁面

桌面程式而家用起嚟似一個密集嘅桌面工具，唔再似一個網站。呢篇文章講外框、改咗嘅頁面，同埋背後嘅決定。

## 外框

- **標題列。** 程式標誌、磁碟切換器（顯示目前磁碟嘅代號同名稱，選單列出所有磁碟同「加入磁碟」）、磁碟分頁、你喺新分頁目錄開嘅分頁、**+** 新分頁目錄、可以搜尋所有磁碟同指令嘅搜尋欄（欄內有 `.*` 正則表達式切換）、**?** 說明模式按鈕、通知同視窗控制。
- **左邊導覽樹。** 首頁；磁碟（每個磁碟，加上目前磁碟嘅資料夾，同 **+** 加入磁碟）；可離線使用（附數目）、歷史、資源回收筒；Docker Hub 備份、已分享檔案（有呢個功能時）、本機工具、設定同說明。設定同說明會列出自己嘅頁面（個人化、本機存取、更新、說明文件、新功能）做子項目。喺設定或者說明撳右鍵或者 Shift+F10，會開返包括「結束」嘅分組選單。
- **頁面。** 每頁得一條工具列，最多一個實心主要按鈕，一張有欄位標題嘅表格，有需要時再加詳情窗格。
- **狀態列。** 一條幼線：掛載狀態、數目、同步狀態、加密同語言。

## 決定：頁面分頁收入導覽樹

頁面唔會再自動開成分頁。每頁喺左邊導覽樹撳一下就到，所以標題列只會放磁碟同你自己開嘅分頁。新分頁目錄仍然可以將任何頁面、工具或者設定開成分頁，「開啟所有分頁」仍然會將每頁開成分頁。頁面喺背後仍然係開住同可以到達（原本預設開啟嘅規則仍然適用於頁面清單），只係分頁列顯示少咗。關閉分頁只會喺分頁列移走，頁面仍然喺導覽樹撳一下就到。

## 決定：冇資訊圖示嘅說明

以前喺每個控制項前面嘅 (i) 圖示，已經喺桌面版面移除。同一段說明文字會：

- 喺指標停喺控制項上面或者鍵盤聚焦時，以提示框顯示；
- 成為控制項嘅無障礙描述，螢幕閱讀器會同控制項一齊讀出；
- 開啟說明模式（**?** 按鈕，呢個選擇會記住喺呢部電腦）之後，喺每個控制項下面直接顯示。

完整解說同逐步指引仍然喺指令面板，叫做「解說」同「指引」。網站同瀏覽器擴充功能仍然用圖示。詳見[資訊圖示](../../docs/features/interface/info-icon-guidance.zh-HK.md)。

## 頁面

| 頁面 | 改咗乜 |
| --- | --- |
| 磁碟清單（磁碟鎖住時） | 所有磁碟都會以表格行顯示。鎖住嘅磁碟喺佢嗰行下面有解鎖列：密碼或者金鑰檔、自動解鎖，同一個「解鎖」主要按鈕。**新增 ▾** 提供「喺呢部電腦新增磁碟」、「新增 Docker Hub 磁碟」同「從 Docker Hub 開啟磁碟」。 |
| 首頁 | 狀態儀表板：每個磁碟一個操作、最近活動、需要處理嘅事（附「處理」按鈕）、狀態同快速開始。未有磁碟時提供三個開始方法。 |
| 本機工具 | 按類別或者名稱分組嘅密集清單，有每個工具嘅用途，同有「開啟」及「喺新分頁開啟」嘅詳情窗格。 |
| 設定 | 類別清單加設定搜尋，每次顯示一個類別嘅密集標籤同控制項行。新增「備份」同「更新」類別。 |
| Docker Hub 備份 | 工具列有「立即全部備份」、「還原」、「重新整理」同「備份設定」，磁碟按儲存庫分組，每行有選單。完整嘅儲存面板仍然喺下面。 |
| 新增 Docker Hub 磁碟 | 有需要先登入，之後一版填晒資料，預設揀好 `<account>/material-file-encryptor-storage`，可以「更改儲存庫」。呢條路冇步驟側欄。 |
| 儲存庫選擇器 | 每個儲存庫只列一次；說明係一行字；**新增儲存庫** 一行會隨住磁碟建立一個公開儲存庫。 |
| 右鍵選單 | 先列對住撳中嘅嘢嘅操作；面板版面同外觀工具收入「自訂」。 |

## 仲未做嘅部份

以下喺設計板有出現，但要後端支援，所以會停用並寫住「會喺之後嘅更新推出」，或者暫時唔顯示；冇任何嘢扮識做：

- 改動後自動備份、鎖定時備份、程式關閉時喺背景備份；
- 每個磁碟嘅快照保留規則、清理、標籤數量指示同將磁碟搬去自己嘅儲存庫；
- 磁碟清單入面每個磁碟嘅大小、快照數目同「上次開啟」；
- 新增儲存庫一行嘅私人儲存庫（後端而家唔接受私人儲存庫）；
- 右鍵選單入面嘅篩選欄同正則表達式按鈕維持不變（設計板將佢哋移除）。
