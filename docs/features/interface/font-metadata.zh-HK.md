# 本機字型中繼資料及可變軸

呢個原始碼基礎會讀取本機字型中繼資料，並提供獨立數值軸選擇器。
目前未接駁外觀編輯器，亦唔代表已通過原生或瀏覽器互動驗收。

## 本機清單

Windows 提供者會檢查作業系統 Fonts 目錄及目前使用者嘅
Microsoft/Windows/Fonts 目錄。符合格式嘅檔案會逐一列出，唔會只取最近
使用字型或者截短項目數量。連結項目及超出所選位置嘅路徑會被拒絕。
舊式、壓縮格式及不存在嘅位置會保留為明確清單結果。

SFNT 及 TTC/OTC 檔案會提供 Unicode 家族與樣式名稱、`fvar` 軸及命名實例。
每個軸包括標籤、名稱、最小值、預設值、最大值及隱藏旗標。靜態字型會
標示 `static-font`。名稱及可變軸資料表各限 4 MiB，資料表與集合目錄各限
4096 個記錄，並驗證偏移、記錄大小、版本及軸範圍。可變資料最多支援
64 個軸及 4096 個實例，每檔中繼資料輸出最多 4 MiB。超出資源上限會明確
標示不支援，唔會截短清單再扮成功。只讀所需資料表，唔會修改、安裝、
下載字型或者將字型檔案交畀畫面。字型識別包括位置索引、相對檔案識別
及集合索引，唔包含主機絕對路徑。

## 接駁介面

`personalization.fontMetadata` 接受可選 `requestId`，對應嘅
`personalization.cancelFontMetadata` 會取消該要求。進度事件
`fontMetadataProgress` 包含要求識別及結果數量。原有 `listFonts`
家族名稱結果保持不變。桌面操作允許清單及真正編輯器接駁完成之前，
唔應公開呢條操作路線。

`mountFontPicker` 接受清單、`getCurrent`、`mutate`、`translate`、
`attachSearch`、`registerHelp` 及 `disabled`。提供可搜尋字型名稱、本機字型
預覽與系統及中日韓後備字型、數值軸、命名實例及預設軸重設。無效或者
無法使用嘅軸唔會呼叫 `mutate`。已接納修改會等原有回呼完成，由該回呼
維持編輯器驗證、權限、持續儲存及歷史。選擇器冇第二條儲存或歷史路線。

回呼收到 `fontFamily` 及 `fontVariationSettings`，後者只使用已驗證標籤及
有限範圍數值。選家族唔保證選中另一個已安裝樣式字型，明確字型對應、
內置字型合併、完整排版控制及實際畫面證據仍然待接駁。選擇器結束時，
已接納修改嘅取消及原子性仍由呼叫端負責。

## 驗證界線

測試包括 SFNT/TTC 名稱及軸、錯誤範圍、取消、連結與外部路徑、逐檔結果、
數值草稿拒絕，以及單一原有修改回呼。一次唯讀 Windows 提供者探測錄得
335 個檔案、166 個字型、四個可變字型及 193 個無法使用結果，原因係不支援
格式及不存在嘅使用者字型位置。當次提供者 SHA-256 係
`1454a5ad56514d0e478e222622a8d21edaa1244060b9a1a067446d0ba683c503`。
之後嘅相對識別及資源上限修改只經測試驗證，唔會冒認為之前探測嘅一部分。
冇安裝字型、匯出原始位元組、操作 GUI 或進行建置。
