# 已驗證啟動照片主機

桌面主機從[權威公開目錄](https://raw.githubusercontent.com/Ding-Ding-Projects/dim-sum-photos/main/catalog/index.json)及[已發佈照片版本](https://github.com/Ding-Ding-Projects/dim-sum-photos/releases)解析一張可選啟動照片。目錄內的英文及繁體中文名稱為準。只有標籤以 `catalog-v1` 開頭的正常已發佈版本可提供照片。此服務不會使用複製的目錄、生成替代圖或存放在原始碼庫的照片。

唯讀的 `surprise/resolvePublishedDish` 要求只接受空白內容，並傳回 `null` 或一個有大小限制的結果，包含雙語名稱、核准的公開網址、發佈狀態及已驗證的圖片資料網址。渲染端不會下載照片，瀏覽器配套亦不能呼叫此桌面路徑。

主機透過 GitHub CLI 取得目前目錄版本，讀取該確切版本並檢查已發佈資產資料。解碼前會核對資產網址、位元組數及 SHA-256 摘要。資料回應上限為 16 MiB；單張圖片上限為 4 MiB、每邊 4096 像素及總共 16,777,216 像素。只接受 PNG、JPEG 及 WebP 標記，原生解碼器亦須確認尺寸相符。不支援或無法解碼的圖片會省略。

私人應用程式資料快取最多保留一張目前圖片及其收據。收據包含目錄來源及版本、目錄摘要、發佈版本、圖片網址及摘要、位元組數、尺寸與媒體類型。每次啟動新處理程序，仍須先驗證公開資料，才可使用相符的快取。CLI 無法使用、離線、資產未發佈或驗證失敗均會傳回 `null`，即使已有舊快取亦然。關閉服務會中止其擁有的命令，並忽略延遲回應。

此主機只負責解析圖片。啟動協調器負責每次啟動唯一一次的 10% 抽選、首次使用及忙碌／更新／錯誤情況排除、School mode 與安靜狀態抑制，以及不阻塞、不搶焦點並自動消失的顯示。解析成功不代表啟動協調器已顯示照片。

主機亦透過 `personalization/accessibilityState` 讀取執行環境實際的 `accessibilitySupportEnabled` 布林值，並在支援狀態改變時發出 `accessibilityState` 事件。結果會報告狀態是否已知及是否啟用，來源標示為執行環境。這並不證明螢幕閱讀器正在執行，亦不證明旁白已被聽到。渲染端應在相關狀態已知前保持旁白關閉，顯示及無障礙驗證另行處理。

專項測試使用合成位元組及模擬傳輸，涵蓋來源限制、發佈資格、摘要及尺寸拒絕、私人快取收據、離線省略、取消及實際執行環境狀態。真正的啟動顯示、原生解碼及輔助技術互動仍須獨立整合證據。此服務沒有公開 HTTP API，不適用 Postman collection。

## 啟動時序及隨附指令解析

照片主機使用其他桌面服務相同的隨附工具摘要收據來解析 `gh`。
它接收應用程式工具目錄，不依賴全域 CLI 或主機 `PATH`。
隨附執行檔缺失或已改變時，會回報不可用，不會轉用不相關的執行檔。

短暫的啟動更新檢查會延後評估，直至檢查完成。延後不會消耗或重複
唯一一次的 10% 抽選。啟動機會由協調器建立起最多維持 15 秒；逾時
或遲來結果不會稍後補發。首次使用、錯誤、進行中的工作、實際更新、
安靜狀態及 School mode 仍會阻止顯示。可信的指標、鍵盤或輸入活動
會結束該次機會；開啟中的模態視窗亦會阻止照片在填寫表格期間出現。
互動開始時，已顯示的卡片會立即關閉。

專項檢查涵蓋更新檢查完成後的轉換、終止排除條件、遲來結果、可信互動、
預設隨附工具解析及已改變執行檔的拒絕。這些屬確定性的原始碼及服務
檢查，不代表已安裝環境或畫面顯示驗收。沒有照片被複製到此儲存庫。
