# 工作區框架及共用控制項

桌面工作區採用鼠尾草綠 Material Design 3 框架。標題列、分類導覽、頂部工具列及已開啟分頁固定不動，只有目前目的地的內容區捲動。表格及編輯器各自限制捲動範圍。視窗少於 840 CSS 像素時，導覽變成可關閉抽屜。設定及說明放在導覽底部。

新設定檔只開啟磁碟分頁。既有分頁、固定狀態、群組及已關閉記錄全部保留。註冊目的地不會自動開啟分頁。「所有分頁」使用同一個可搜尋操作選單，並提供相鄰正則表達式工具。分頁管理及鍵盤移動／調整面板功能放在情境操作內。

控制項由本機 Material Web 2.5.0 真實元件組成。日期、時間及檔案選取器使用已註冊組合，原生選取器只作內部實作。必須在建立輸入元件時傳入 type；之後更改 type 不會改變元件種類。安全檢查仍須在每次操作前執行，視覺選單不會授予權限。

操作選單會在按下 Escape、點擊外面、選取操作、導覽、目標移除及結束時關閉。方向鍵、Home、End、Enter 及空白鍵均可操作。關閉後適當還原焦點。

設計參考在 design/gui-redesign/，明確屬於設計資料，並非執行畫面證據。本機針對性檢查已涵蓋分頁、控制項映射、選單關閉及負面回歸；實際桌面建置及視覺矩陣仍需另外驗證。

新磁碟預設為 80 MiB（83,886,080 bytes），既有磁碟儲存的數值不會更改。
