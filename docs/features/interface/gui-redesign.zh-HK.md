# 工作區框架及共用控制項

桌面工作區採用鼠尾草綠 Material Design 3 框架。標題列、分類導覽、精簡頂部工具列及已開啟工作分頁固定不動。每個目的地都有獨立、限制範圍嘅捲動內容區，表格同編輯器亦各自限制溢出範圍。視窗少於 840 CSS 像素時，導覽變成可關閉抽屜。設定及說明留喺導覽底部。

新設定檔只開啟初始磁碟分頁。既有開啟分頁、固定狀態、群組及已關閉分頁全部保留。註冊目的地只會令佢可以被發現，唔會自動開啟。上一個及下一個控制項捲動分頁列；「所有分頁」開啟共用可搜尋情境選單，搜尋旁邊有正則表達式工作區。分頁管理及鍵盤面板版面控制放喺情境操作內，唔再長期佔用輔助列。

## 控制項 API

由 `src/shared/surface/controls.js` 匯入 `control`。呼叫形式係 `control(tag, props = {}, children = [], ownerDocument = document)`。建立時揀定類型，例如 `control('input', {type:'checkbox', checked:true})`。之後指定 `type` 唔會將現有自訂元件變成另一種基本控制項。按鈕、文字欄位、選擇器、核取方塊、單選鈕及滑桿會對應到本機隨附嘅真實 Material Web 2.5.0 元件。`option` 對應 `md-select-option`；先加入選項，再設定選擇值。原有 ID、名稱、資料屬性、停用狀態及輸入／變更監聽器都留喺提升後嘅主元件。請用 `CONTROL_SELECTOR` 或語意屬性，唔好假設原生標籤名稱。

日期／時間及檔案控制項使用已註冊組合，內部保留平台選取器。原生選取器輸入屬於內部實作，唔係外露視覺控制項。檔案值唔會寫入診斷、歷史或匯出資料。文字欄位保留驗證及選取 API。切換鈕為 Material 選取狀態提供 checked 別名。應用程式保留嚴格、只限本機嘅內容安全政策，唔會載入 CDN。

## 情境操作

`getContextOverlay(document)` 擁有唯一一個 `mfe-context-menu`，內含真實 `md-menu` 及 `md-menu-item` 子項。`openContextMenu({anchor,event,target,items,language,onClose})` 喺開啟時擷取目標。每個項目提供 `id`、本地化 `label`、可選嘅 `disabled` 同 `shortcut`，以及 `run(target)`。指標呼叫使用指標座標，鍵盤及按鈕呼叫使用錨點邊界。`registerContextActions(root, provider)` 傳回釋放函式。提供者收到 `{target,path,event}`，路徑來自 `composedPath()`。提供者由最深層已註冊根節點一路組合到祖先，所以本機操作仍然保留通用外觀及鎖定操作。明確項目 ID 會去除重複。共用主元件會移入呼叫者模態祖先並顯示於最上層；命令面板選項唔會建立另一個選單。准入檢查由提供者負責，每次敏感操作前都必須再次檢查。

外部指標輸入、Escape（包括搜尋欄有內容時）、選取、導覽、移除目標、調整視窗大小及結束都會關閉浮層。方向鍵、Home/End 及 Enter/Space 可以操作選單；錨點仍存在時，關閉會還原焦點。選取會先還原焦點再執行操作，令操作可以有意將焦點移到其他位置。搜尋結果綁定世代，過時嘅非同步結果會被丟棄。更新項目唔會重新連接已聚焦搜尋節點。Material 選單嘅字元跳選已停用，因為可編輯搜尋欄負責可列印按鍵。

## 驗證狀態

已納入版本管理嘅確定性參考及狀態清單放喺 `design/gui-redesign/`。佢哋係設計參考，唔係螢幕擷取或執行階段證據。本機專項測試涵蓋分頁保存／探索、控制項映射、情境鍵盤版面、Escape 及監聽器釋放、隱藏主元件行為，以及原始控制項嘅負面變更。整合桌面建置、實際輸入、版面矩陣及視覺一致性仍然係獨立必要檢查，呢啲來源測試冇宣稱已經通過。

新磁碟表單預設為 80 MiB（83,886,080 bytes），既有磁碟儲存數值維持不變。

## 通知朗讀

啟用朗讀後，正式通知及工作狀態變更會交由現有序列語音引擎依次讀出。單純位元組進度更新唔會重複朗讀。安靜注意力設定，以及未知或已啟用嘅執行階段輔助功能狀態，都會暫停朗讀，但視覺通知仍然保留。缺少語音或朗讀失敗時，只會顯示一次復原提示，引導使用者到個人化語言設定。呢個保守訊號唔代表能夠識別某一款螢幕閱讀器。

## 啟動短暫展示

取得初始工作及更新狀態後，合資格嘅再次啟動會透過共用啟動輔助程式進行一次百分之十抽選。學校模式、首次啟動、工作進行中、失敗、更新活動及安靜設定都會略過展示。主程式解析已批准公開目錄，提供已核實及限制大小嘅圖片資料；介面唔會自行連線下載圖片。解析後會再次核對狀態。可關閉卡片最多顯示五秒，列出雙語點心名稱，唔會移動焦點；應用程式進入忙碌或安靜狀態時會移除。缺少中繼資料或圖片時，正常工作介面維持原狀。
