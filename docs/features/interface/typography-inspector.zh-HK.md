# 有型別嘅文字排版設定

逐元素外觀編輯器透過原有圖層修改、驗證、儲存同復原流程，提供有範圍限制嘅文字排版控制項。字型家族同可變軸沿用獲准嘅字型流程。即時樣本會跟隨已接受嘅樣式，儲存失敗唔會當作成功預覽。

呢個來源單元唔等於畫面驗收。已安裝字型嘅精確字形對應仍然保守處理。醒目提示會改變元素背景，基線對齊效果取決於排版。陰影控制項可以建立一層陰影，現有多層陰影會保留，直至明確取代。完整顏色選擇器同圖像編輯器屬於其他工作。

## Search

搜尋只會篩選呢個設定區嘅屬性名稱，清除字句就會顯示全部屬性。搜尋唔會修改已儲存樣式。每個屬性嘅直接控制項上方都有可選用指引，指引會執行原有控制項，保留驗證同鎖定檢查。

## 驗證及復原

數值必須有限而且符合範圍。大小使用 px、pt、em 或 rem，相對大小另外限制為 32。顏色使用原有解析器。顯示引擎未支援嘅已儲存數值會繼續顯示同保留匯出。重設會移除明確屬性覆寫，讓其餘樣式繼承生效。原有外觀復原及重做仍然負責版本還原。

<a id="fontSize"></a>
## 字體大小

改變字形大小，唔會縮放周圍工作區。

預設值：16px。旁邊嘅有型別控制項會驗證格式同顯示引擎支援。

例子：24px 會令標題變大。

<a id="fontWeight"></a>
## 字體粗幼

選擇獲准字型嘅粗幼，靜態字型可能會合成中間粗幼。

預設值：400。允許範圍：1 至 1000。

例子：700 會要求粗體。

<a id="fontStyle"></a>
## 字體樣式

選擇正常、斜體或者傾斜顯示，已安裝字型仍然需要明確對應。

預設值：normal。選項：normal, italic, oblique。

例子：italic 會要求斜體字形。

<a id="fontVariant"></a>
## 大小楷變體

字型支援時使用小型大寫字形。

預設值：normal。選項：normal, small-caps。

例子：small-caps 會保留原文。

<a id="textTransform"></a>
## 大小楷轉換

只改變顯示嘅大小楷，唔會重寫原文。

預設值：none。選項：none, uppercase, lowercase, capitalize。

例子：uppercase 會以大寫顯示標籤。

<a id="textDecorationLine"></a>
## 文字裝飾線

喺呢個狀態組合底線、刪除線同頂線。

預設值：none。選項：none, underline, line-through, overline, underline line-through, underline overline, underline line-through overline。

例子：underline line-through 會同時顯示底線同刪除線。

<a id="textDecorationStyle"></a>
## 裝飾線樣式

控制全部裝飾線嘅紋樣，包括雙刪除線。

預設值：solid。選項：solid, double, dotted, dashed, wavy。

例子：double 配合 line-through 會產生雙刪除線。

<a id="textDecorationColor"></a>
## 裝飾線顏色

裝飾線可以使用同文字唔同嘅顏色。

預設值：#202020。旁邊嘅有型別控制項會驗證格式同顯示引擎支援。

例子：紅色底線可以保留黑色文字。

<a id="color"></a>
## 文字顏色

只改變指定目標及狀態嘅文字顏色。

預設值：#202020。旁邊嘅有型別控制項會驗證格式同顯示引擎支援。

例子：選擇有足夠對比度嘅前景色。

<a id="backgroundColor"></a>
## 文字醒目提示

改變元素背景，唔係文字入面某段嘅醒目提示。

預設值：#ffffff。旁邊嘅有型別控制項會驗證格式同顯示引擎支援。

例子：黃色背景可以標示元素。

<a id="letterSpacing"></a>
## 字元間距

改變字元之間嘅距離，負數可能令字形重疊。

預設值：0px。旁邊嘅有型別控制項會驗證格式同顯示引擎支援。

例子：1px 會拉開短標籤嘅字距。

<a id="wordSpacing"></a>
## 字詞間距

改變分詞空格嘅距離，冇空格嘅文字可能不受影響。

預設值：0px。旁邊嘅有型別控制項會驗證格式同顯示引擎支援。

例子：4px 會加闊英文分詞空格。

<a id="lineHeight"></a>
## 行高

使用字體大小嘅倍數設定行高。

預設值：1.5。允許範圍：0.5 至 5。

例子：1.5 會額外留半行距離。

<a id="verticalAlign"></a>
## 基線及上下標

移動行內方框，區塊元素可能唔受基線對齊影響。

預設值：baseline。旁邊嘅有型別控制項會驗證格式同顯示引擎支援。

例子：super 會提高上標，唔會改變儲存嘅文字。

<a id="direction"></a>
## 文字方向

控制行內文字方向，唔會翻譯或者重排儲存嘅字元。

預設值：ltr。選項：ltr, rtl。

例子：rtl 會由右至左排版。

<a id="textAlign"></a>
## 文字對齊

喺目標可用闊度之內對齊行內內容。

預設值：start。選項：start, end, left, right, center, justify。

例子：center 會將標題置中。

<a id="webkitTextStroke"></a>
## 文字外框

只喺顯示引擎支援時加入字形外框。

預設值：0px #202020。旁邊嘅有型別控制項會驗證格式同顯示引擎支援。

例子：1px #202020 會畫出幼身深色外框。

<a id="textShadow"></a>
## 文字陰影及光暈

加入一層有數值限制嘅陰影，零位移加模糊可以形成光暈，現有多層陰影會保留。

預設值：none。旁邊嘅有型別控制項會驗證格式同顯示引擎支援。

例子：0px 0px 8px #6750a4 會產生紫色光暈。
