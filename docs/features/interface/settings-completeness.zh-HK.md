# 設定完整度及一致性

此清單記錄尚未完成的桌面程式及各公開說明路由。共用元件不能代替任何一邊的完整實作或實際驗收。網站與本機流程分開核對。

## 桌面設定的中央修改界線

桌面設定儲存現在只有一個修改界線，即使個人化畫面接收現有儲存物件亦不能繞過。只有本機設定檔及獨立私人歷史均已解鎖時，實際設定修改才會記錄一次加密歷史。值沒有改變便不會產生事件。歷史寫入失敗會通知使用者，不會撤回已套用的設定。

受限制模式必須先成功設定或核對憑證，再由受權限保護的主機寫入共用記錄。只有成功寫入才授權相符的畫面狀態修改。匯入、重設及加密歷史還原不能代替此流程。可信主機讀取及訂閱事件使用獨立同步能力。密碼留在既有憑證界線，不會進入設定或歷史。

桌面設定重設及私人歷史修剪使用真正的雙鑰匙、完整滑桿確認。重設不能跳過模式授權；取消確認不會修改設定。這次修補不能證明程式其他破壞性操作已完成。
