# 瀏覽器擴充功能工作區

彈出視窗嘅「開啟工作區」會開啟擴充功能自己嘅選項分頁。連線、個人化、更新記錄、筆記同狀態係 Material 分頁，支援左右方向鍵同 Home/End；除非要求減少動態，否則每個面板都會淡入。切換唔會重建有焦點嘅控制。畫面使用本機 Material 元件同已封裝正則搜尋，唔載入外部執行資產。

語言（英文、廣東話或雙語）、主題（跟隨系統、淺色或深色）同所選分頁使用有版本同大小限制嘅擴充功能本機儲存。唔使用瀏覽器同步、廣泛主機權限或新增儲存權限。無效或過大快取會退回預設值。寫入失敗會保留可用嘅頁面狀態，並清楚講明變更未儲存。重設只恢復瀏覽器本機預設值。雙語次要標籤另起一行。

連線同傳輸狀態分開顯示。配對唔會開始傳輸。連線中斷或回應無效會清除即時狀態，唔保留舊成功訊息。只有確切擴充功能彈出視窗同選項頁來源可用配對、狀態同斷線通道。原生傳輸仍須喺桌面確認。

配對唔等於本機身份驗證。個人用詞、共享模式、憑證、原生設定、伺服器管理、轉換器同模型控制要有經檢閱嘅已驗證原生通道先可用。英文同廣東話趣味程度各自有 1 至 5 滑桿，預設 5，並可獨立重設。彈出視窗狀態同選項通知用共用訊息翻譯器。表情符號預設關閉，只喺本機訊息預覽對話框加入一個輔助工具略過嘅裝飾，唔改按鈕標籤或事實。更多訊息覆蓋同執行驗證仍待完成。版本讀自擴充功能清單，組建來源同暫存時間就由暫存組件提供，詳見下文。Status Hub 登記未可用。

## 更新記錄、組建來源同指令

更新記錄分頁唔使網絡連線都可以睇到版本更新記錄。暫存時會將儲存庫入面嘅更新記錄轉成已封裝模組，因為頁面政策會阻擋所有 fetch；篩選欄會喺本機收窄顯示嘅版本。廣東話模式顯示每個版本嘅廣東話摘要，雙語模式就同時顯示英文項目同摘要。

狀態分頁顯示擴充功能版本、封裝時所用嘅來源提交同暫存時間。如果暫存嗰陣受追蹤嘅擴充功能來源同嗰個提交唔同，提交會標示「另有未提交改動」。任何一項讀唔到，分頁會講明未可用，唔會靠估。

指令（Ctrl+K）會開啟一個 Material 對話框，列出工作區所有動作：開啟每個分頁、配對、中斷連線、重新讀取狀態、語言同主題選擇、訊息預覽同重設設定。輸入文字可以篩選清單，當刻做唔到嘅動作會顯示為停用。

## 匯出、設定說明、重設確認同快速鍵

「預覽匯出」會將目前篩選咗嘅更新記錄轉成 JSON、CSV 或 Markdown，儲存之前先顯示結果。匯出內容會先讀返一次核對：版本同改動數目要對得上，否則唔會提供檔案。CSV 儲存格如果以公式字元開頭，會喺前面加一個撇號，試算表就會顯示文字而唔會執行。匯出只包括版本說明，永遠唔會包括設定、配對資料或者個人用詞。

個人化入面嘅「設定說明」列出每個設定嘅目前數值、會改變乜嘢，同點樣恢復預設值。工作區搜尋可以搵到呢啲說明。

「重設瀏覽器設定」要經過刻意確認：開啟兩個確認開關，將滑桿拉到最右，然後揀「執行」。「緊急離開」會取消，乜都唔改。個別趣味程度重設仍然係一步完成，因為佢只改一個數值。

Alt+1 至 Alt+5 會開啟連線、個人化、更新記錄、筆記同狀態，Ctrl+K 會開啟指令面板，面板會喺指令隔籬列出呢啲快速鍵。Ctrl 加數字、Ctrl+T 同 Ctrl+W 呢類瀏覽器保留組合會留返俾瀏覽器處理。

## 名稱、強調色、最近改動同篩選

個人化入面嘅「名稱同強調色」可以令呢個瀏覽器用自己嘅產品名稱。名稱最多 60 個字元，唔可以有尖括號或者換行，會取代工作區標題、頁面標題、版本行、分頁清單名稱同彈出視窗入面嘅 Material File Encryptor。留空就會恢復原本名稱。

強調色可以揀六個預設之一，或者輸入 #rrggbb 數值，再用透明度滑桿調校。透明度會同頁面底色混合，強調色上面嘅文字會自動揀白色或者黑色之中較易睇嗰個。工作區會講明對比度，要達到 4.5:1 先會提供「套用強調色」。「用預設強調色」會返回內置色盤。

「最近改動」列出最多 50 項語言、主題、趣味程度、表情符號、產品名稱同強調色嘅改動，附時間同還原舊數值嘅按鈕。切換分頁、配對狀態同任何秘密都唔會記錄。「清除記錄」用同全部重設一樣嘅刻意確認，而且唔會改動目前設定。

「篩選」按鈕可以收埋更新記錄嘅篩選同匯出控制。收埋之後篩選文字同效果都會保留，隱藏篩選仍然生效時按鈕會顯示「篩選（使用中）」。

由第 2 版工作區儲存嘅設定，第一次讀取時會加上空白嘅產品名稱同強調色，之前所有選擇都會保留。

## 圖示、標誌、專注模式同說明文件連結

擴充功能有自己嘅圖示，尺寸係 16、32、48 同 128 像素，用應用程式綠色嘅資料夾加鎖標記。暫存只接受 icons 資料夾入面嘅細 PNG 檔案。

個人化入面嘅「揀選標誌」接受 64 KB 以內嘅 PNG、JPEG 或 WebP 圖片，讀取檔案之前會先檢查類型同大小。標誌會保存喺自己嘅本機記錄，並顯示喺工作區標題隔籬同彈出視窗。「移除標誌」會返回內置標記。

「專注」有三個本機開關：「專注」會收埋說明文字；「減少刺激」會關閉動畫同表情符號裝飾；「引導注意」會為打開咗嘅面板加框。「關閉所有專注模式」會一次過關晒三個。呢啲開關只會改變呢個瀏覽器嘅顯示方式，唔會同桌面應用程式共用。

狀態分頁會連去說明文件網站嘅確切地址 https://ding-ding-projects.github.io/material-file-encryptor/，並以文字顯示地址。

## 筆記

筆記分頁（Alt+4）只會喺呢個瀏覽器保存最多 50 篇短筆記。「新筆記」會喺目前分頁上面打開一個側邊面板，下面打開緊嘅嘢會保持原樣。面板分三步：先寫標題，再喺一頁空白寫筆記內容，最後檢查一次。「下一步」會先檢查每一步先繼續，「返回」會返去上一步；「取消」或者 Escape 會保留草稿，下次撳「新筆記」會還原。關閉面板之後，焦點會返去打開佢嘅按鈕。

用核取方塊揀多篇筆記就可以一齊處理。「匯出所選」會儲存做一個 Markdown 檔案。「刪除所選」要經過同全部重設一樣嘅刻意確認，之後會報告刪除咗幾多篇、幾多篇刪除唔到（嗰啲仍然揀咗）同幾多篇早已唔喺度。

## 預定改動、個人用詞同字型

個人化入面嘅「預定改動」可以喺指定日期同時間改主題或者語言。呢部分會講明時間用邊個時區，例如 America/Toronto (UTC-04:00)。少過一分鐘之後嘅時間，同埋同一分鐘再改同一個設定，都會被拒絕。每個預定改動都可以取消。工作區開住期間到期嘅改動會喺 30 秒內套用；關閉期間錯過咗嘅改動，下次打開時會按次序套用，並講明錯過咗幾多個同最早應該幾時套用。

「個人用詞」會匯入格式係 {"schemaVersion":1,"entries":{"original":"replacement"}} 嘅 JSON 檔案，最多 200 個項目，每個都係 60 個字元以內嘅純文字。只要有一個項目無效，成個檔案都會被拒絕，乜都唔會改。用詞只會改介面文字，唔會改筆記、匯出內容或者傳去桌面嘅任何嘢。每個原本字眼只會換一次，所以一個項目嘅新字眼唔會俾另一個項目再改。「清除用詞」會恢復原本文字。

工作區同彈出視窗用擴充功能入面附帶嘅 Noto Sans 字型，暫存時會對照應用程式嘅字型收據核對。香港中文字型太大，所以中文用系統字型。字型同其他資源都唔會由擴充功能以外載入。

針對性測試涵蓋無效及過大快取、儲存失敗、持久儲存、鍵盤分頁、偽造來源路徑同本機 CSP。來源暫存為每個工作區檔案計算雜湊。簽署、已安裝身份、真實瀏覽器互動、視覺對照同顯示縮放仍未驗證。

## 訊息封裝大小量度

獨立共用訊息語氣入口令暫存語言封裝由 431,433 位元組降至 999 位元組。保留嘅暫存收據用 SHA-256 綁定兩個輸出。暫存助手喺 25 種獨立英文／廣東話程度組合都同來源助手一致，共用語言測試亦通過。呢個只量度封裝大小，唔證明瀏覽器啟動或繪畫速度。共用凍結語氣表保持不變，桌面翻譯器繼續重新匯出同一個表。
