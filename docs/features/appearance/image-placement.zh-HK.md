# 具型別圖像擺位

## 交付狀態

呢個原始碼單元提供已註冊嘅 Material Design 3 檢查器同共用幾何，但尚未接駁外觀編輯器。整合時要按 `design/image-placement/HANDOFF.md` 嘅配接取代舊有圖像變形控制。未有實際畫面、安裝後或像素驗收。

## 擺位模型

裁剪座標使用正規化 PNG 來源百分比。闊度同高度必須為正數，裁剪矩形必須留喺來源範圍內。明確 `fit` 可選 `contain`、`cover` 或 `stretch`。焦點 X/Y 由 0 至 100，用嚟對齊完整顯示嘅剩餘空間，或填滿範圍嘅溢出部分。拉伸會填滿兩個方向，焦點喺拉伸模式冇可見影響。

共用幾何會回傳來源同目的地像素。即時 SVG 會轉成目標座標；點陣 worker 直接使用同一目的地，並裁切到輸出邊界。幾何模組唔會解碼像素、轉換色彩、暗中限制裁剪值，或修改來源位元組。

冇 `fit` 嘅舊模型保留即時完整顯示同點陣拉伸。檢查器會解釋呢個歷史差異，套用前必須明確選擇配合方式。重設會交俾原有操作，可以還原舊有擺位。唔會自動改寫舊圖像。

## 控制同原有操作

裁剪、焦點、移動、比例、旋轉、斜切、透明度同混合都係草稿。套用會驗證完整草稿，再呼叫原有修改一次。空白、格式錯誤同超出範圍嘅值唔可以儲存。重設使用提供嘅原有操作。目前圖層、鎖定、復原歷史、持久儲存同回復由呼叫端負責，唔會另建設定儲存。

操作未完成時會阻止重疊操作。銷毀會移除監聽、指引同搜尋配接。呼叫端必須先拒絕過時或已鎖定目標。搜尋使用主介面配接及其正規表示式建立器；冇配接時會明確顯示未能使用。標籤同可選指引支援英文、廣東話同雙語。語言改變時由呼叫端重新掛載，沿用原有編輯器生命週期。

## 安全同限制

既有渲染器只會收到已正規化嘅本機 PNG。冇新增上載 SVG、任意網址、解碼器、格式匯入或匯出。正規化限制、worker 取消同單一處理准入保持不變。本機版本同匯出仍然省略圖像像素。安全區、完整合成器、可編輯圖像匯出、其他來源格式同真實畫面驗收仍然未完成。

## 驗證

針對性測試涵蓋裁剪、配合方式、焦點算式、舊預設值、無效輸入、實際 SVG 同 worker 流程、一次原有修改、儲存拒絕後重試、鎖定、銷毀同重疊操作限制。呢啲係原始碼及元件測試，唔等於瀏覽器版面或無障礙驗收。
