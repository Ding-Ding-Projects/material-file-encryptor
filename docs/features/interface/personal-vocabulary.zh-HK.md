# 個人用詞

桌面設定接受 UTF-8 JSON 檔，可用標準 `{ "schemaVersion": 1, "entries": { "Original": "Replacement" } }`，或舊版 `{ "version": 1, "replacements": [{ "from": "Original", "to": "Replacement" }] }`。檔案最多 256 KiB，冇項目數量上限。鍵最多 160 個 Unicode 碼點，值最多 1,000 個。重複 JSON 鍵、重複來源字串、控制字元、不安全物件名稱、額外欄位（下文可選嘅 `displayName` 除外）、不支援版本同超過八層巢狀結構，全部喺套用前拒絕。

驗證採用原子方式；無效替換檔保留目前對應。替換只匹配原始標籤一次，最長優先，唔會連鎖；URL、路徑、數字同命令範例等技術文字保持原文。只影響標籤文字，並以純文字顯示。

每個接受版本編譯一棵字面 Unicode trie。線性掃描識別受保護技術文字，唔產生正則交替表達式。每次渲染最多接受 65,536 個 UTF-16 單位輸入、執行 1,000,000 次 trie 轉移，輸出最多 262,144 個 UTF-16 單位。超出任何渲染上限就完整傳回原始標籤，唔截斷亦唔部分替換。呢啲係逐次渲染資源限制，唔係有效檔案接受項目數量限制。

對應只留喺此裝置本機偏好。儲存寫入失敗會回報只限本次使用，唔會聲稱已持久儲存。重設恢復原始標籤並從已儲存偏好移除對應；無法更改儲存時明確警告。真實對應唔可經匯出控制下載，亦永不傳送至網絡服務、日誌或遙測。

公開文件預設鎖定。可見選擇器喺本機驗證檔案，待處理有效檔只保留記憶體。私人個人檔案控制器呼叫 `setAuthenticatedLocalSession(true)` 前，公開文字保持不變；之後先讀本機快取同套用用詞。以 false 呼叫會即時恢復公開文字。鎖定期間亦可清除。驗證控制器係獨立整合要求；選取檔案本身唔代表讀者已完成身份驗證。

聚焦測試涵蓋標準同舊版資料、大型清單、Unicode 上限、格式錯誤同重複 JSON、原子拒絕、快取驗證、儲存失敗、重設同單次替換。

## 回呼測試驗證

來源測試而家會執行實際加密快取持久儲存函數，並喺無關的基礎介面掛載前停止擷取回呼。測試涵蓋鎖定時保留待處理輸入、驗證後加密儲存、無效輸入保留原值、重新鎖定後拒絕及非同步重設。呢啲唔係瀏覽器、封裝或安裝驗收。

## 拖放套用同慶祝動畫

個人用詞檔案亦可以拖放到桌面視窗任何位置，或者瀏覽器擴充功能頁面（工作區同彈出視窗）。設定頁嘅上載保留作後備，驗證、儲存同慶祝動畫完全一樣。只處理帶有檔案嘅拖曳；放入文字欄位嘅操作交返文字欄位處理。只接受一個大小喺上限內嘅 `.json` 檔案；其他情況或者無效檔案，都會用本地化訊息拒絕，並且乜都唔會改。檔案拖過視窗時會顯示可見嘅放置目標，並設有減少動態後備。

檔案可以帶一個可選嘅頂層 `displayName`，例如 `{ "schemaVersion": 1, "displayName": "Team words", "entries": { "Original": "Replacement" } }`。必須係最多 40 個 Unicode 碼點嘅純文字，唔可以有控制字元或者角括號，亦唔會同替換項目一齊儲存。冇呢個欄位嘅檔案照樣有效。

用詞套用後，會出現全視窗、唔阻擋操作嘅慶祝動畫：用共用動態標記將 `displayName` 動畫帶入、停留約三秒，再動畫退出。冇 `displayName` 就顯示中性文字 “Personal wording applied”。動畫以 `role="status"` 同 `aria-live` 宣告，永不搶走焦點，亦只顯示標題，唔會顯示檔案其他內容。減少動態時改為靜態通知三秒。

喺瀏覽器擴充功能入面，用詞只會喺瀏覽器同桌面配對期間套用。未配對時，放入嘅檔案會被儲存，通知會講明配對後先套用，並且唔會播放慶祝動畫。
