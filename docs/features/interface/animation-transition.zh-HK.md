# 動畫同過渡編輯

## 目前界線

呢份係已安裝程式同公開文件外觀編輯器共用嘅未完成來源草稿。模型、原生動畫介面同編輯控制已保存。較早模型及 API 介面測試通過，但之後修訂、實際掛載控制測試、引導整合同畫面驗收仍然未完成。儲存數值同注入式 API 測試唔代表動作已喺畫面呈現。此處冇宣稱現時畫面或者計時錄影完成。

## 編輯同呈現

動作儲存喺每個外觀圖層，明確保留所選元素、圖層同狀態。動畫同過渡分頁提供有次序軌道及規則、啟用或停用或單獨播放、群組、前置關係、偏移、交錯、屬性輸入、關鍵影格、片段緩動、時間、標記、觸發同原生時間軸選項。數值控制同時間軸拖動並存。復原、取消復原、外觀版本、具名預設、樣式複製、重設同已驗證 JSON 都會攜帶動作資料。

介面呼叫目標顯示引擎嘅原生動畫 API。屬性選擇器列出計算屬性，亦接受明確自訂屬性名稱。CSS 解析成功唔代表已證明插值。顯示引擎拒絕時會顯示原因，同時保留可攜編寫資料。元素軌道操作確切目標。獨立圖層軌道需要實際圖像圖層節點；層疊到同一元素嘅 CSS 圖層唔會產生獨立像素畫面。圖像覆蓋層重建時會取消舊控制再接新節點，連續性仍需要計時驗收。

時間支援小數毫秒、自動持續時間、有正負號開始及結束延遲、有限或無限重複、重複起點、方向、填補同有正負號或零播放速度。關鍵影格保留明確偏移、絕對或相對時間、計算數值、逐片段緩動同合成。原生文件時間軸使用毫秒。捲動及視圖時間軸會偵測能力，並保留來源、方向、內縮同連接範圍；數值進度定位同逐影格語義仍需要完成來源及瀏覽器驗證。

## 能力同安全限制

目前顯示介面冇原生逐次重複延遲同彈簧物理功能。可攜設定仍然可見，未支援預覽唔會被當成已套用。具名、貝茲、線性同階梯緩動交由顯示引擎時間函數解析器處理。只有顯示引擎提供時先會使用合成同重複累積。共用彩虹速度仍然具決定性，軌道唔可以覆寫預留屬性。

觸發只限所選目標狀態、准許嘅互動事件、可見進度同明確動畫指令。佢哋唔會執行程式碼、擷取資源、認證或者執行受保護產品操作。匯入 CSS 會拒絕網址同宣告跳脫。有版本嘅動作輸入設位元組容量、有限數值驗證、循環偵測同原型鍵拒絕；未知未來資料只會保留供攜帶，唔會執行。

減少動態效果會保留編寫模型、取消原生動畫控制，並使用最後靜態數值。預覽喺 30 秒後暫停，銷毀時會釋放影格觀察。程式同作業系統偏好傳遞、確切狀態繼承、播放中斷、重疊屬性同圖層重建仍需要真實計時驗證。排程動作覆寫同完整逐控制引導文件亦係未完成整合要求。

## 驗證同畫面清單

手寫能力矩陣列明實作同呈現邊界。測試涵蓋外觀可攜往返、時間驗證、前置循環、實際目標 API 呼叫、過渡、事件範圍、減少動態效果取消同收尾。負面來源檢查會移除分頁、設定或者呈現介面。呢啲係來源同 API 邊界結果，唔係已建置畫面證據。

固定建置獲批准後，兩個介面都要經真正編輯器操作每項能力，保留逐次操作畫面加計時錄影或者計算樣式取樣、確切時間及觸發斷言、重新載入及減少動態效果檢查，同埋有界資源收尾。所有現有 README、文件、維基、圖庫同下載展示畫面都要用已檢查並綁定來源嘅新畫面取代。新畫面同引用核實前，原圖保留並清楚標示歷史。生成圖像唔可以代替。
