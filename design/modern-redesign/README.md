# Modern redesign boards

Design canvas for the next look of the desktop app: ink-dark tonal surfaces, large rounded cards, a floating navigation rail, a bento home grid, and drive cards that carry their own banner and icon. Boards: Home, Drive workspace, Docker Hub backup, Settings with search, and Home at 390 px. Every board has accent, theme and motion tweaks. The app is rebuilt to these boards; nothing here is implemented yet.
