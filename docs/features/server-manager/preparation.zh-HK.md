# 本機 Java 伺服器準備

呢個桌面流程只會準備已驗證嘅伺服器檔案，唔會啟動 Java、接受授權，亦唔會啟用四種管理目標。瀏覽器唔提供呢個流程。

## 更新官方版本

按「更新官方版本」先會讀取 Mojang 官方版本清單。主機驗證有上限嘅 HTTPS 中繼資料，並記錄來源 SHA-256 同擷取時間。開啟面板唔會自動連線。更新失敗會保留記憶體內舊清單，並標示離線；重新啟動後自動接管同復原仍未實作。

## 選擇與搜尋

每次載入 100 個官方版本。載入更多先會擴大可搜尋範圍；搜尋同正規表示式工具只處理已載入項目。選擇版本後，主機核對清單指定嘅 SHA-1，再解析官方中繼資料。冇伺服器下載嘅版本會明確顯示不可用。介面只傳主機發出嘅識別碼，唔可以指定網址、路徑、摘要、Java 執行檔或者提供者證明。

## 準備

同一時間只容許一項準備。主機要求最新選擇、最多 1 GiB 嘅確實下載大小，以及該大小加 16 MiB 嘅可用容量。容量檢查只係當刻觀察，唔係替其他寫入預留空間。檔案放喺應用程式資料下新建嘅專用工作階段目錄。既有本機介面卡逐段下載，核對確實大小同 SHA-1、記錄 SHA-256、同步檔案，寫入 `eula=false`，最後以重新命名發佈目錄。完成之前，已接收位元組唔代表驗證成功。

## 取消

取消只係要求停止指定操作，唔會即時宣稱完成。關閉應用程式會取消並等候進行中工作。失敗或取消會保留暫存同操作記錄供復原，唔會遞迴刪除。自動復原、重新啟動接管同可操作嘅復原管理介面仍待完成。

## 閱讀授權

成功準備後先可閱讀該伺服器嘅官方 Minecraft EULA 連結。閱讀或者開啟連結唔會接受授權，接受狀態保持 false。本單元冇接受授權或者啟動嘅 IPC 動作。

## 指引與無障礙

每項動作上方都有獨立、可選嘅指引，原本控制仍可直接使用。指引等候同一個原始操作，唔會重複修改。英文、粵語同雙語內容包括用途、選項、預設、效果、例子、驗證同復原。清除搜尋尊重唯讀狀態。控制使用已註冊 Material Design 3 元件；銷毀面板會釋放擁有嘅監聽、指引登記同訂閱，舊非同步結果唔會重畫替代面板。

## 安全與未完成範圍

桌面 IPC 嚴格核對每個動作嘅識別碼同欄位，拒絕多餘資料。主機自行解析官方來源、路徑同摘要，冇提供啟動提供者。原生程序監管、相容 Java 執行環境、按版本綁定嘅 loopback 設定、資源限制同原生檔案租約 IPC 未整合。單有租約原語唔足以安全啟動。本機 Docker、SSH 程序同 SSH Docker 管理未實作，四種目標都保持不可用。

## 驗證

針對性測試以合成位元組執行實際主機同檔案介面卡，並檢查桌面／瀏覽器 IPC 及注入 DOM 中嘅實際元件。覆蓋摘要不符、舊中繼資料、序列准入、容量不足、發佈前及串流中取消、授權狀態、原始識別碼、指引生命週期、清除搜尋同舊面板隔離。未進行真實下載、Java 或原生輔助程序執行、GUI 啟動或產品建置。實際畫面、鍵盤操作、完整語言／主題／縮放組合及封裝執行驗收仍待完成。

## 中繼資料准入同保留搜尋

進行中解析同保留選擇共用同步 100 個名額上限，聯絡提供者之前先預留，拒絕或關閉時都會喺 finally 釋放。更新、分頁、語言切換同狀態重畫後會重新套用搜尋；舊搜尋代次嘅延遲結果唔可以修改新面板。準備區以 `mfe-server-preparation` 登記確實 Material Design 3 同共用控制清單。呢啲係來源同元件檢查，唔係實際畫面驗收。
