# Server preparation design handoff

## Scope

An actionable desktop preparation panel, using the existing registered Material Design 3 framework and shared control guidance. This extends the existing application navigation. It is not a marketing page or a generic command form.

## States

Unavailable catalogue, explicit refresh, current/stale/offline metadata, paged version selection, loaded-row search with regex builder, unsupported distribution, serial capacity admission, unverified streaming progress, verified preparation, cancellation requested, canceled/failed recovery retention, and read-only official license review. Startup and license acceptance remain unavailable.

## Design route and evidence

The Material Designer creation/export flow and a local Material Designer checkout were unavailable in this session. Existing framework components and shared guidance are the fallback. No design export or rendered acceptance is claimed. Product build and GUI launch were prohibited for this bounded source unit under host memory pressure. Synthetic component tests do not prove pixels, focus behavior or responsive geometry.

## Required rendered acceptance

Use the exact reviewed package and an isolated hidden desktop. Inspect normal and minimum client geometry, English/Cantonese/bilingual, light/dark, and 100/125/150/200 percent scale. Verify keyboard selection, optional above-control guidance, search/regex and clear, serial preparation progress, cancellation settlement, unavailable startup, and license review without acceptance. Retain actual layout probes, privacy-reviewed captures, source/package identity and strict owned teardown. Real downloads require separate approval and fixture ownership; do not use user servers or worlds.
