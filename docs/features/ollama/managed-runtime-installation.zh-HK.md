# 受管理 Ollama CLI 安裝

Model Store 為未安裝嘅受管理本機 runtime 提供專用安裝流程。桌面主程序會先要求原生確認，再下載已固定版本嘅官方完整 Windows CLI ZIP，安裝到應用程式擁有、不可覆寫嘅版本目錄。現有 Ollama 安裝、模型資料夾、系統 PATH、開機啟動項目同服務會保留。安裝唔會啟動 Ollama，亦唔代表 API 健康。

候選版本係 x64 Ollama v0.40.3。官方 `ollama-windows-amd64.zip` 有 1,468,053,171 個壓縮位元組，SHA256 係 `e5ecff02dfc7cae8ddf6d6b7a7ac5f727ffeedf4491f44ae75ff5b0820dbbbd5`。直接解碼所得嘅來源清單記錄 82 個檔案，解壓後共 1,941,752,691 個位元組。ARM64 要先審閱同等完整檔案清單，先至可以提供。呢個流程唔會安裝額外 ROCm 或 MLX 套件。

主程序串流下載有明確上限，核對完整大小同摘要，只重用完全相符嘅快取。重新導向只接受官方發行傳送主機。被拒快取同未完成下載會保留作診斷。固定 Windows PowerShell 輔助程序直接使用 .NET ZipArchive，喺同一個受保護檔案串流核對摘要同解壓，持有上層目錄身分，拒絕清單以外項目同特殊檔案類型，並逐一核對已審閱 SHA256 同大小。輔助程序只透過自己嘅子程序環境接收有上限、冇秘密嘅操作設定，解壓前清除該欄位，只輸出固定階段或失敗分類。壓縮檔內容唔會執行。

`ollama.exe` 仍然必須符合有效嘅指定發行者同憑證規則。受保護憑證紀錄固定完整檔案樹嘅認可狀態，唔會單靠可以改寫嘅本機收據。主程序以原子操作發佈版本目錄、保存受保護認可，再核對完整檔案樹。來源不明或被修改嘅現有目錄唔會被覆寫。每次受管理啟動之前都會重新核對所有檔案同發行者，使用自己嘅工作目錄同受限制執行檔搜尋路徑，而且啟動仍然係另一個要明確確認嘅操作。

安裝事件只包含操作 ID、固定階段、結果同原因、有上限嘅位元組計數、版本、架構、可否取消同安裝狀態，唔包含主機路徑、命令、憑證或壓縮檔內容。瀏覽器呼叫者唔可以安裝或取消原生安裝，唯讀狀態亦保持有界限。

取消只針對完全相符嘅進行中操作。解壓期間，輔助程序確認目錄保護之後，主程序先建立全新、自己擁有嘅取消標記。輔助程序喺有上限嘅串流區塊之間檢查取消。主程序會等輔助程序確實結束，再刪除身分同固定內容仍然相符嘅標記。被替換或身分不確定嘅標記會保留。原子發佈同受保護登記會完整完成，期間唔接受取消。關閉服務會等自己擁有嘅安裝工作完成；已安裝但停止仍然唔等於運行中或健康。

針對性合成測試涵蓋操作權限、快取同下載拒絕、完整檔案樹修改、發行者拒絕、目錄同壓縮檔保護、解壓摘要、Unix 檔案屬性、取消同關閉次序。官方壓縮檔實際下載同唔執行內容嘅清單解碼已核對。來源審閱、封裝、真正按鈕安裝、自己擁有嘅 runtime 啟動、API 健康、模型執行，以及畫面無障礙同排版驗收，仍然係獨立待驗項目。來源測試唔構成端到端安裝或 runtime 成功證明。

受管理執行環境控制器只會為自己保留嘅原生擁有者提供「停止」。API 健康、連接埠或者程序 ID 都唔代表擁有外部執行環境。停止操作會喺非同步工作之前保留服務操作權，拒絕同時進行嘅模型預檢或操作，並且只會喺確認完整工作物件已結束同執行環境保護已釋放之後報告成功。未確定嘅結束狀態會保留擁有者供重試。瀏覽器呼叫者唔可以停止原生擁有者。安裝同啟動確認透過有界限嘅每次請求語言選擇，支援英文、廣東話同雙語。

已發佈嘅原生合成驗證程式實際測試咗同正式產品共用嘅生命週期演算法：原始父程序結束之後仍然保留完全相符嘅控制代碼，已記錄嘅存活子程序仍然屬於工作物件，執行環境檔案亦繼續受保護。停止同 EOF 結束必須等完整工作物件數量歸零，先釋放保護。包含喺工作物件內嘅額外主控台程序亦計入整體，唔會用固定程序數量代替子程序證明。呢啲係合成生命週期證據，唔係官方 Ollama 執行或者按鈕驗收。通過呢項證明之後，來源內固定嘅原生啟動認可已啟用；正式安裝、API 健康、真正按鈕操作同畫面無障礙驗收仍然待驗。防止新增目錄同主程序突然結束嘅次序仍然係未驗證限制。
