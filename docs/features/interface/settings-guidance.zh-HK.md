# 可選設定指引

逐步指引及解釋入口會放在確切目標正上方，只會在使用者要求時開啟。原有控制項繼續可用，並保留實際驗證、鎖定、身分驗證、確認、歷史及操作。上一步保留目前草稿，取消不會聲稱撤銷已完成修改。

## 來源及驗證範圍

以下每個穩定概念只在共用設定清單及欄位或操作行為記錄撰寫一次。即時說明讀取實際提供的選項及有類型的預設值，並分辨已儲存偏好、內建預設值及未儲存草稿，不會讀取秘密數值。修改時間表設定會更新數值欄位的類型及預設值。

針對性檢查在 DOM 測試環境掛載實際設定畫面，並使用真正設定及加密歷史處理程序。這不代表本機或瀏覽器驗收，亦不是畫面證據。巢狀編輯器、唯讀元素及進階搜尋指引仍待完成，並非整個產品完成。

## 確認及非同步生命週期

如有提供本機重設服務，重設會使用該服務；否則共用後備途徑使用實際的兩個開關及完整滑桿授權確認。頁面離開、身分驗證失效及移除畫面都會令授權失效，設定儲存仍會拒絕未授權模式切換。已確認修改只會在已驗證並解鎖的歷史記錄一次。下一步只接納一項待處理驗證，等候後再次檢查是否可用，並忽略已取消的後續處理。上一步還原焦點，已移除操作不能按舊識別碼聚焦替代目標。清除會等候原有已接納輸入或修改處理程序；事件被阻止或拒絕時保留先前顯示數值。

今次只涵蓋操作按鈕。其他欄位類型同表面仍屬獨立工作。元件檢查涵蓋延後完成、停用同移除控制、重設取消同排程驗證。目前真正新建畫面同 Material Design 3 視覺驗收仍然等待。

導覽指引明確使用 compactLabels 選項：可見文字為 Guide／Explain，廣東話顯示「指引／解說」，雙語顯示兩種語言；可存取名稱保留完整操作同確實目標。普通設定指引保留現有文字。獨有說明、可選操作同欄位對齊不變。修正後窄畫面仍須重新擷取。

## 語義 Material 欄位轉接

共用工廠使用已註冊 md-outlined-text-field 處理文字、密碼、URL 同數值，md-checkbox 處理核取值。文字欄位使用元件標籤，唔重複顯示外部標籤；核取方塊保留關聯可見標籤。明確語義種類清單將 select、date、time、range、color、file 同 search 保留為本次未完成原生控制。日期／時間唔會當成不支援 Material 文字欄位類型傳入。
