# 本機工具工作區

## 檔案轉換

先選擇來源檔案，檢查偵測結果預覽，再從合適類別選擇相容格式，檢查轉換選項，最後選擇輸出目的地。四個分頁切換時會保留狀態。左右方向鍵同 Home、End 可以切換分頁。每個類別同選項清單都有共用本機搜尋，並附有錨定式正規表示式建立器。停用嘅格式仍會顯示不可用原因。

轉換沿用現有有資源界限嘅本機轉換器服務，來源檔案保持不變。替換目的地仍會啟動既有確認流程。佇列記錄每頁載入 50 項，而且重新整理請求唔會重疊。讀取期間分頁控制會停用，並依實際回傳頁嘅偏移量更新；讀取失敗會回復上一個已顯示偏移量。每項工作顯示狀態、進度，以及既有暫停、繼續同取消操作。等待中嘅檔案選擇器唔會重新繪畫已關閉工作區。

## 本機模型

模型目錄、下載清單、本機對話、設定組合同說明各有獨立、可用鍵盤操作嘅面板。執行環境同目錄維護集中喺可展開區域。搜尋使用共用、有工作程序時間界限嘅正規表示式建立器。所選模型狀態清楚可見，模型事實保持原樣，每項排隊下載顯示位元組進度。目錄重新整理、下載同執行環境操作沿用既有確認及已驗證原生橋接界限。單純開啟面板唔會開始下載或啟動伺服器。

## 伺服器準備

準備畫面分開顯示有界限版本清單、目前選擇同操作卡片。下載位元組喺既有 SHA-256 驗證完成之前會標示未驗證。畫面繼續明確說明唔提供伺服器啟動、其他執行目標或接受授權條款。

## 驗證

專項合成元件檢查涵蓋轉換器類別清單、實際控制項建立、分頁導覽、既有原生請求資料同拆卸。呢啲檢查唔證明已建置版面、安裝、執行環境服務、網絡可用性或真實模型下載。已建置視覺驗收仍然需要另外完成。

## 已排版模型回應

本機模型答案同已儲存助手訊息使用既有隨附 DOM-only Markdown 顯示器。標題、段落、強調、清單、表格同圍欄程式碼會顯示為內容。使用者同系統訊息保持字面原文。JSON 模型中繼資料同設定組合啟動前檢查結果仍然係精確資料。模型 HTML 永不解讀執行；模型圖片冇資源目錄，亦永不載入；可執行、相對、data 同包含認證資料嘅連結唔會變成外部錨點。獲准 HTTP(S) 連結只會喺明確啟動後開啟，唔帶 opener 或 referrer。工作核取方塊係已停用嘅註冊控制項。

串流使用一個 60 ms 計時器更新目前回應，保留未完成程式碼圍欄同格式分隔符，並喺完成、取消或操作出錯時立即更新。早過原生請求回應到達嘅事件依操作身分隔離，最多暫存四個身分，每個身分最多 1 MiB 文字，只有原生回應指定嘅操作會被採用。切換已儲存對話、重新產生或拆卸畫面會令過時繪畫失效。操作停止或未完成時，部分結果仍然可見。

格式處理上限係 262,144 個字元、2,048 行、每行 8,192 個字元、16 層巢狀結構，以及每行 128 個連結開括號。超出格式上限會顯示說明，並完整顯示為字面純文字，唔會暗中刪減或者繼續遞迴分析。呢啲顯示界限唔會放寬原生服務嘅回應界限。

對抗性元件檢查涵蓋來源 HTML、可執行同包含認證資料嘅 URL、遠端圖片、程式碼圍欄、表格、工作標記、深層巢狀、過大內容、早到事件、分段資料、取消、拆卸，以及延遲嘅已儲存對話讀取。合成檢查唔代表真實模型執行或已建置視覺驗收。

## 即時切換語言

檔案轉換同本機模型工作區會原位更新現有文字標籤、分頁、欄位標籤、選項、無障礙說明、輔助搜尋、狀態文字同靜態說明。切換語言唔會重新掛載控制項、清除已選來源識別碼或未儲存轉換選項、刪除對話／系統指示／名稱草稿、替換私人附件選擇器，亦唔會重設進行中回應。搜尋查詢、所選選項同目前分頁都會保留。快取執行環境狀態可以重新標示，無須發出新執行環境請求。重建清單會清除過時標籤綁定。伺服器準備畫面已有語言更新方法，會保留查詢同所選狀態。

兩個專項回歸檢查喺舊來源實際失敗，修正後通過英文、廣東話同雙語切換。檢查使用真正控制項工廠同合成服務，冇下載模型或者發出供應商請求。已建置語言同顯示比例驗收仍然獨立進行。
