# 閱讀完整筆記同安全格式文字

筆記分頁保留簡短預覽，揀「閱讀完整筆記」就可以睇晒已儲存嘅內容。完整閱讀器同筆記精靈嘅檢閱步驟，都使用內置說明文件同一個只建立 DOM 節點嘅 Markdown 顯示器。標題、強調、清單、表格同程式碼區塊會保留格式，原本筆記唔會改動。「匯出完整筆記」會以 UTF-8 儲存完整 Markdown 內容同標題。

閱讀器唔提供圖片目錄或者相對文件路由。遠端圖片唔會載入，HTML 原文只會當文字顯示。只有冇內嵌登入資料嘅 HTTPS 連結可以開啟，而且唔會帶來源頁或者 opener。缺少圖片、相對連結同空白內容都有明確說明。既有 4,000 字元限制會喺顯示之前檢查，完整閱讀器唔會靜靜地截短內容。

呢個功能只處理本機筆記，唔係供應商連線或者模型執行功能。現有原生瀏覽器通道提供下載配對、只讀保護狀態，以及範圍有限嘅受保護身份摘要。[外部編輯器流程](external-editor.zh-HK.md)使用獨立授權嘅原生揀選同確認。[轉換流程](file-conversion.zh-HK.md)支援四個需要原生確認嘅固定選項轉換器。模型管理同學校模式仍然要有原生操作先可以提供可用控制。本機瀏覽器設定唔會被當成原生權限。

## 驗證

執行 `node --test test/extension-note-rendering.test.js test/extension-note-lifecycle.test.js test/browser-extension-notes.test.js`，檢查格式、完整長度、拒絕無效輸入、連結邊界、刪除後閱讀器清除，以及過長草稿還原。呢啲係可重複嘅 DOM 模型檢查，唔代表已安裝瀏覽器或者視覺驗收通過。實際組建同執行畫面仍需要另外驗證。
