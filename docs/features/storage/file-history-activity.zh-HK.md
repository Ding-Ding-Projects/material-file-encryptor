# 所選檔案版本及活動

檔案詳情元件保留所選項目的穩定身分，因此重新命名後，歷史不會轉到後來佔用舊路徑的另一檔案。版本由 `ListVersions(entryId)` 提供，現有全保管庫歷史仍可使用。

## 活動儲存

`RecordActivity(entryId, action, path, versionId, detail)` 明確記錄成功操作。支援匯入、編輯、重新命名、還原、取消、同步、刪除、建立、匯出及標籤。呼叫者只可提供保管庫相對路徑及簡短、不敏感的詳情，不可提供主機路徑或憑證。不得從檔案缺席推斷事件，亦不得補造過往操作。

每個不可變活動物件均以保管庫金鑰及活動專用關聯資料域驗證和加密。儲存及快取資料夾包含密文 `.mfe` 物件，名稱是無語意的隨機識別碼。`SynchronizeActivity()` 在儲存與快取之間複製前先驗證物件，並拒絕身分衝突；應從成功同步路徑呼叫。來源缺失時，本機記錄保留供日後同步。驗證錯誤會向上傳遞，不會顯示不可信活動。

`LabelVersion` 為不可變版本識別碼記錄有上限的可列印標籤。`ListVersionLabels` 回傳最近標籤，包括用來清除舊值的空標籤。`PreviewVersion` 最多解密 256 KiB，只接受嚴格 UTF-8 文字、拒絕二進位控制字元，並清除暫存位元組緩衝區。回傳文字是刻意供記憶體內顯示的資料，不得記錄或以未加密方式持久儲存。

`ListActivity` 支援項目、操作、包含端點的 UTC 日期及有逾時上限的正規表示式篩選。每頁最多 500 筆。游標是按時間戳記及識別碼排序後最後回傳的事件識別碼；即使有新事件仍保持錨定，未知游標會被拒絕。刪除及重建快取後，查詢前須呼叫 `SynchronizeActivity`。保管庫鎖定時不能列出活動。

加密快照包含已驗證活動清單。保管庫升級複製事件身分及時間戳記，並以目的保管庫金鑰及關聯資料域重新加密每個物件；回傳前會讀回兩份目的副本。標籤透過相同活動記錄保留。

## 顯示介面整合

從 `src/renderer/features/file-details/index.js` 匯入 `mountFileDetails`、載入旁邊的 CSS，並傳入根節點、`services` 及 `translate`。回傳物件提供 `selectEntry(entry)`、`refresh()` 及 `destroy()`。服務使用 lower-camel-case JSON，提供 `listVersions(entryId)` 及 `listActivity(query)`。選用的 `previewVersion(id)`、`restoreVersion(id)`、`exportVersion(id)` 及 `labelVersion(id,label)` 啟用對應控制。參數是不可變版本識別碼，不是列索引或目前路徑。

版本及活動分頁提供日期與正規表示式篩選、活動類型篩選、可見版本選取、批次匯出／還原，以及服務支援時的版本標籤。預覽接受文字或 `{text}`，逐行比較兩項選取並顯示新增及移除。比較上限為 5,000 行，透過 DOM 文字節點顯示；二進位或較大內容須匯出。主機必須為還原／匯出服務套用既有確認及目的位置流程。翻譯由所屬應用程式提供。元件不使用網絡或持久瀏覽器儲存。

版本表示式只在可拋棄 worker 內執行，期限為 150 ms。新查詢、選取變更或銷毀會終止舊 worker。限制為 256 字元、10,000 個候選版本、每列 32,767 個可搜尋字元及合計 4 MiB 可搜尋文字。逾時或無效表示式會顯示錯誤，不會讓過期符合列繼續可操作。原生活動查詢另有自己的表示式逾時上限。

## 驗證及尚待整合

`test/file-details.test.js` 檢查日期邊界、正規表示式錯誤、穩定選取、空結果、安全文字比較、災難性表示式終止、過期查詢取消及輸入上限。`ActivityTests.Run()` 檢查加密持久儲存、篩選、分頁、重新命名後身分、完整快照清單、跨金鑰升級保留及防竄改；所屬測試入口必須呼叫它。後端變更及同步掛鈎、控制器路由、顯示元件掛載、本地化文案及實際建置介面驗證屬整合責任，不是獨立元件已完成的聲明。
