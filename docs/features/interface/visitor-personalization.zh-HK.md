# 網站訪客個人化

訪客連接層會在說明網站自己的設定內掛載共用個人化控制。使用者毋須配對桌面程式，亦不會操作加密磁碟。語言、英文及廣東話各自的趣味程度、主題、密度、字型、動態效果、標誌、旁白聲線、注意力模式及本機排程都使用訪客自己的瀏覽器狀態。

## 儲存及私隱

設定以獨立訪客前綴儲存在目前瀏覽器來源，供各說明路由共用。連接層不會讀取桌面設定，亦不會將舊有成功或搜尋訊息滑桿當成語言偏好。如果儲存被拒絕，之後的修改仍可在本頁記憶體使用；通知會清楚說明重新載入後將會失去修改。此連接層不會套用私人用詞。

## 排程及能力界線

本機排程使用共用的時區、日期、星期、跨午夜及優先次序驗證。外部來源必須由主機明確提供可信能力；沒有能力時不會發送來源請求，而本機排程仍然可用。設定或核對模式解鎖憑證亦需要明確的存取能力。缺少能力絕不等於通過驗證。

## 整合及待驗證項目

`mountVisitorPersonalization(container, options)` 提供設定儲存、即時套用、開啟設定分頁、本機排程及銷毀介面。網站外殼負責路由掛載、公開文字、受限制操作及版本來源。歷史憑證和破壞性操作確認由獨立能力提供。

共用畫面部分巢狀編輯器仍使用原生控制。完整註冊元件、每個下拉選單的正規表示式篩選、進階外觀能力及實際瀏覽器互動仍未驗證。原始碼檢查只證明獨立語言偏好、儲存備援、本機排程及缺少能力時的拒絕行為，不能代替畫面或旁白聲音驗收。
