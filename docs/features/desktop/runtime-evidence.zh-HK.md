# 執行期拒絕證據

<a id="independent-modern-interface-phase"></a>

## 獨立現代介面階段

呼叫 `node scripts/local-headless-desktop-check.mjs` 時設定 `MFE_VERIFICATION_SCOPE=modern-only`，即可獨立執行現代介面階段。預設仍為 `full`。獨立範圍自動啟用全新原生測試資料，並要求 `MFE_BUILD_RECEIPT`；原有確切 `MFE_SOURCE_COMMIT`、封裝執行檔、選定輔助工具／傳輸設定及 `MFE_HEADLESS_EXECUTE=1` 要求全部保留。每次執行使用獨立 `MFE_DESKTOP_EVIDENCE_DIR`。未知範圍值會喺啟動前失敗。

如果只修正驗證器，而版本比不可變套件新，必須明確將 `MFE_VERIFIER_SOURCE_COMMIT` 設為驗證器乾淨工作目錄的確切提交。`MFE_SOURCE_COMMIT` 仍然代表目標套件，並須符合建置收據。呢個獨立覆寫只限 `modern-only`；驗證器身份遺失或唔符即失敗。每次新原生觀察都重新檢查乾淨驗證器目錄並記錄兩個身份，版面觀察則保留目標套件來源。唔會將舊應用程式位元組改稱新建置。

自動測試資料解鎖及掛載係非同步。檢查確切已掛載資料前，獨立路徑會喺 30 秒計劃期限內唯讀輪詢狀態，等候明確已解鎖／已掛載及驅動程式探索完成，唔會呼叫解鎖或掛載。已回報啟動錯誤、可見應用程式錯誤、驅動不可用或狀態查詢被拒絕，都會令準備失敗。之後儲存位置／快取／磁碟代號斷言仍屬必需。

原生建立的空保管庫只係設定，唔係 GUI 建立保管庫驗證。仍須全新設定檔、啟動、確切目標、已審閱原生基線、原生鍵盤轉換，以及新原生／程序／執行期觀察。量度工作區前，已掛載後端須符合測試資料的確切儲存、快取及磁碟代號。六個工作區狀態涵蓋 48 組設定及五個基線清除控制。然後執行器點擊真實 GUI 鎖定控制，確認同一後端身份已鎖定及解除掛載，再涵蓋三個對話框狀態、48 組設定及另外八個清除控制。合共 432 張狀態截圖及 13 張清除控制截圖。歷史、資源回收筒及離線部分明確只涵蓋空白狀態。模擬渲染器比例唔代表原生實體顯示比例獲認證。

獨立摘要寫入 `modern-phase-check.json`，包含 `verificationScope: "modern-only"` 同 `fullWorkflowVerified: false`。佢要求兩個完整階段摘要、已驗證探測、每張截圖的確切像素／私隱審閱及來源證明、正常程序／桌面關閉、啟動狀態還原，以及所屬憑證清除。首次及恢復審閱都須確切 445 個計劃中的現代介面檔名，加上全部三張基線／原生原圖；刪除狀態或清除控制圖片唔可以靜靜縮減獲接納清單。佢唔會填入 GUI 建立、舊格式轉換、複製升級、傳輸驗證、啟動切換行為或安裝的完整流程旗標。現有完整流程判斷不變，唔會接納獨立階段收據作完整驗證。

如果執行及收尾成功後只欠像素審閱，可用原有證據目錄配合 `MFE_CAPTURE_REVIEW_ROOT`。呢條路徑選用已儲存範圍及對應摘要，重新檢查原有資源雜湊、已完成階段／關閉／清除條件，並審閱保留的確切截圖，唔重新啟動亦唔重用即時身份。失敗或部分執行唔會變成只審閱成功。舊流程收據仍綁定原有來源及原生位元組，永不提升為新執行。

<a id="exact-history-restore-identity"></a>

## 確切歷史還原身份

歷史還原驗證先辨識測試資料選定版本，再喺已渲染還原控制尋找完全相同 ID。ID 係現有處理器版本身份的中繼資料，唔改變還原語義。另行取得的後端列位置唔能夠辨識渲染器獨立載入及篩選快照中的列。

選取前，驗證器要求封存準備完成、`aria-busy="false"`、要求／完成標記相符，以及 render／rendered 世代相符。佢記錄有界要求身份、相符數量、可見／啟用狀態及世代標記，再要求恰好一個可見、已啟用控制。點擊用同一確切 ID。遺失、重複、隱藏、停用或過期目標都明確失敗，唔准退回按位置選取。

動作失敗時，之後診斷查詢或寫入唔可以取代原有例外。原有物件及代碼會重新拋出，另有觀察／儲存失敗則分開記錄。失敗查詢唔會變成虛構觀察。真實動作成功後仍須還原檔案位元組及保留歷史斷言。

二十項集中檢查涵蓋後端清單重新排序、過期世代、身份編碼、遺失／重複／隱藏／停用控制、有界觀察及動作／查詢／寫入組合失敗。呢啲檢查及獨立來源審閱證明驗證器修正，唔係全新建置執行期或安裝判斷。較早 source55 還原嘗試喺呼叫還原前停止，仍係失敗證據。

如果已安裝生命週期驗證器提供有界、被拒絕的祖先邊，專案配接器會喺標準指令處理器清理例外前記錄。佢會重新拋出原有例外，唔會授權額外程序操作。

記錄器只接納缺少父程序或子程序早於父程序拒絕的版本化產生器欄位。佢驗證確切子程序及可選父程序身份、宣稱父 PID、100 ns 建立刻度、不存在／次序陳述及 64 KiB 邊界大小。不支援或不可用的中繼資料唔會記錄。

私人記錄以獨佔新 `rejected-edge-<random-id>.json` 直接放喺已驗證、儲存的生命週期執行根目錄。生命週期檔必須係該根目錄的 `lifecycle.json`，儲存程序須符合被拒絕驗證根，狀態須仍為 created 並未 cleaned。連結／重解析組件、改變的生命週期狀態、錯誤輸出根、已存在目的地或無法驗證讀回都會被拒絕。Windows 上建立期間會固定目錄鏈，唔分享刪除權限。每筆保留記錄包含來源生命週期 SHA-256、根身份及確切被拒絕邊。記錄只供私人診斷，永不公開或封裝。

標準輸出只含經清理失敗代碼、允許的原因／階段及中性已儲存／不可用數量，唔含私人邊、執行檔路徑或原始原生訊息。記錄失敗仍保留原有生命週期拒絕，程序保持不變。呢啲證據解釋證明點解停止，唔能夠建立程序所有權或准許終止。

集中離線測試涵蓋確切缺少父程序及時間次序記錄、例外身份不變、多筆保留記錄、嚴格結構及大小拒絕、過期生命週期脈絡、所有權唔符、獨佔建立、重解析拒絕及 stdout 遮蔽。唔代表即時桌面判斷。

<a id="bounded-ownership-proof-for-each-fresh-cdp-attachment"></a>

## 每次新 CDP 連接的有界所有權證明

每個執行期、控制、擷取及現代觀察計劃都用共用 `withCdpConnectionProof` 要求 `startupOwnershipAttempts: 3`。名稱指該 CDP 連接開始，唔只係應用程式啟動；每個計劃都開新連接。復原、最終還原及正常收尾明確移除繼承的選用設定，保留已安裝驅動預設一次嘗試。

已安裝驅動只接納一至三的整數。只有確切啟動根仍有效，而且被拒絕嘗試的私人快照成功儲存，先可以因 `INVALID_NODE_IDENTITY` 重試。每次嘗試取得全新完整連接前所有權證明，兩次相隔 500 ms。明確不可能的祖先關係優先於不完整列，仍屬終止條件。每個被拒絕證明都保留；私人證據遺失、根改變、其他拒絕或用盡嘗試都停止連接。舊失敗證明唔會供應之後嘗試的所有權。

共用輔助工具只註記計劃，唔執行或重試動作序列、部分完成計劃、目標隔離檢查、復原或收尾。嚴格單目標及身份檢查不變。來源綁定收據保留每個已執行計劃的真實結果及拒絕證據。集中檢查證明用途路由、移除繼承次數及部分工作失敗後只執行一次，唔聲稱即時重播成功。

<a id="native-proof-for-the-newly-created-empty-drive"></a>

## 新建立空白磁碟的原生證明

將合成 GUI 建立保管庫轉為舊格式測試資料前，驗證透過 `native-empty-root-proof.py` 證明掛載根係空白，取代 Node `fs.readdir` 可以列舉空白 WinFsp 根的假設。真實封裝 1.33.1 重現開啟預期 MaterialVault 磁碟區的有效目錄，第一次 `NtQueryDirectoryFile` 完成回傳 `STATUS_NO_SUCH_FILE` 及零位元組。Node 26.10.0 配合 libuv 1.52.1 對同一掛載根回報 `ENOENT`。呢個係列舉相容性結果，唔係掛載不存在證據。

WinFsp 固定的[目錄完成實作](https://github.com/winfsp/winfsp/blob/ddca7bd5481857a65ba552f643b8776fd070836f/src/sys/dirctl.c)會喺最初空結果回傳 `STATUS_NO_SUCH_FILE`，列舉結束則回傳 `STATUS_NO_MORE_FILES`。驗證器只接納呢兩種狀態配合零目錄資料，唔會捕捉並重新解釋任意 `ENOENT`、增加目錄項目，或改變產品、保管庫格式、公開 API。

呼叫方要求全新準備、由本次工作擁有的 GUI 測試資料、儲存的磁碟保留、確切儲存／快取路徑，以及原生查詢前後均為掛載、解鎖、閒置。原生輔助工具以目錄列舉及屬性讀取權限開啟根，查詢全程保留控制代碼，比較前後目錄屬性、確切檔案 ID 及磁碟區身份。另行重開的根須符合保留控制代碼；兩者磁碟區序號須一致，檔案系統須為 `MaterialVault`。缺少根、普通檔案、非空資料、其他狀態、身份變更、不支援平台及逾時一律拒絕。非同步查詢最多等五秒，之後取消並再等最多五秒；緩衝區保持有效直至取消或程序退出。呼叫方設定十二秒程序上限。

成功證明會喺已驗證生命週期執行根寫入獨佔私人 `gui-empty-root-proof.json`，記錄封裝來源及執行檔雜湊、原生及測試輔助工具雜湊、生命週期雜湊、確切原生狀態、前／後／重開身份及明確空白判斷。永不覆寫現有記錄。收據及測試路徑保持私人。鎖定及舊格式轉換前必須有此證明；佢唔授權其他磁碟或程序操作。

檔案 ID 及磁碟區序號係標準十進位字串，分別有無號 64 位及 32 位上限。原生產生器序列化前先比較，JavaScript 使用方驗證確切字串形式，唔轉為 number。較早重現的數字檔案 ID 保留作歷史證據，唔能支持確切 JavaScript 往返身份聲稱。

集中測試涵蓋兩個允許狀態、非空資料、非預期狀態、根及磁碟區身份變更、錯誤檔案系統、缺少根、普通檔案、掛載／生命週期綁定變更、不支援平台、逾時及現有收據拒絕。真實全新普通 NTFS 目錄比較係唯讀，明確唔接納作 MaterialVault 證據。假回呼只測決策邊界，唔建立原生或桌面行為。原有封裝重現保持獨立證據；新輔助工具仍須整合重播先可完整接納執行期。

<a id="legacy-fixture-history-and-failed-run-retirement"></a>

## 舊格式測試歷史與失敗執行的清除

GUI 建立會為選定儲存身份建立主機擁有的密文歷史。即使冇使用者檔案，將該組設定由格式 2 改成格式 1，都會同之前記錄的不可變 `vault.json` 物件衝突。全新隱藏重播喺格式 1 掛載及寫入／讀取成功後，重現同步拒絕；保留歷史標頭同目前標頭有唔同物件雜湊。錯在測試資料，產品不可變性維持不變。

原生空白及鎖定狀態證明後，驗證器喺自己合成根建立獨佔 `legacy-storage` 及 `legacy-cache` 目錄。只複製空保管庫設定，喺第一次主機登記前修改副本標頭，再用真實控制開啟新身份。GUI 建立的格式 2 組合及歷史保留。已有目的地目錄會被拒絕。複製升級繼續用另一組全新資料，並獨立重開舊格式原本。

介面回報錯誤時，動作輪詢而家會停止，將有界訊息保留喺私人步驟收據並即時拒絕動作。唔會將後端拒絕變成不透明逾時或當成同步成功。

GUI、舊格式或升級動作建立憑證前，獨佔所屬測試記錄會將確切儲存／快取組合綁定原有測試及輔助工具。確認程序不存在及桌面關閉後，清除流程驗證記錄、忘記每組已登記資料，再只移除確切產生金鑰。執行期完成前失敗亦用同一清除流程。記錄及合成密文／歷史保留；清除會列明處理咗邊組資料，唔會聲稱執行期通過。

## 已審閱圖片庫發佈流程

圖片庫以 `docs/site/gallery-review.json` 保留有限獲批准清單：14 張歷史原圖及兩項明確排除。呢次改動唔接納任何新桌面或網站截圖。全新執行期及發佈驗證仍係獨立要求。

獲批准記錄按已審閱流程 ID 分組，使用穩定錨點。每個確切圖片 SHA-256 喺視覺圖片庫只出現一次；每次記錄出現仍保留各自狀態、來源版本、原圖連結、主題、渲染比例、時間／時區及驗證範圍。跨流程重複圖片視覺上歸第一個獲批准出現的流程，但仍可按每次出現的流程搜尋。原始位元組及獲批准路徑保留，永不改寫或丟棄。圖片延遲載入並有固有尺寸；來源資料用原生可展開詳情。搜尋計圖片卡、隱藏空流程組及導覽連結，排除清單則保持可見。

公開 JSON 係明確欄位投影，唔會複製未知中繼資料、原始收據、程序身份、機器路徑或批准管理資料。新增項目須有明確獲批准路徑、已審閱來源／圖片綁定、確切 `promotionReceiptSha256`，以及 `reviewedBindings[path].metadataSha256`，符合套用已審閱流程後 `JSON.stringify(projectGalleryRecord(record))` 的 SHA-256。提升收據保持私人；摘要係參考，唔係審閱者睇過像素的證明。批准列之前先執行來源綁定提升流程。任何摘要都唔能取代真實來源、關閉或私隱審閱。

可選公開來源欄位係 `artifactSha256`、`promotionReceiptSha256`、`viewportWidth` 同 `viewportHeight`。缺少歷史值保持缺少或明確不可用。擷取日期及時區只來自已驗證產生器來源，唔從檔名、檔案時間或發佈時間推算。比例只描述已記錄渲染比例，唔建立實體顯示比例。

集中驗證用 `node --test test/site-publication.test.js test/site.test.js`。負面案例涵蓋未審閱中繼資料、缺少提升證明、格式錯誤來源、排除重疊及重複流程 ID。合成 445 次出現案例驗證確切位元組去重同時保留全部出現記錄；佢係資料測試，唔係聲稱有 445 張真實截圖。來源 `67c1996569e1767ceca844dfac412cfd550a5390` 之後通過三種寬度、語言及兩個主題的 18 組真實圖片庫瀏覽器設定。全部 37 張保留圖片已審閱，原有瀏覽器及伺服器關閉另獲接納。呢個唔提升新桌面截圖，亦唔建立實體顯示比例覆蓋。
