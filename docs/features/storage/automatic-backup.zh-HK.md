# 自動 Docker Hub 備份同快照保留

登入咗 Docker Hub、睇過一次公開 repository 嘅說明之後，每個磁碟都會自己備份。你唔使揀 repository 名，亦唔使設定排程，舊快照會自動清走，repository 唔會爆。

## 開啟

1. 開 **Docker Hub 備份**，登入。
2. 睇清楚說明：備份會放喺**公開**嘅 repository。只會上載加密咗嘅資料，但係任何人都睇到個 repository、入面有幾多個磁碟同快照、大細、備份時間同磁碟名。檔案名同內容永遠睇唔到。
3. 撳 **開啟自動備份**。

第 3 步之前唔會自動上載任何嘢。想某個磁碟只留喺呢部電腦，就熄咗佢喺磁碟表嗰個掣，或者喺嗰行嘅選單揀 **停止備份**。

## 幾時備份

- **改動之後：** 磁碟靜咗大約 1 分鐘。每次再有改動都會重新計時。
- **定時檢查：** 每個鐘一次，順手執返漏咗嘅改動，例如離線時改過嘅嘢。
- **鎖定時：** 有改動等緊備份嘅磁碟一鎖就會備份。
- **關程式時：** 有改動等緊嘅磁碟最多有 2 分鐘備份；夠鐘仲未完就會取消，下次開程式再做。
- **網絡返嚟時：** 等緊網絡嘅磁碟一連返就會備份。

一次只會備份一個磁碟。用緊磁碟永遠優先：備份會喺安全嘅位置暫停，之後自己繼續。失敗之後會隔 1、5、15 分鐘再試，之後每個鐘一次。

**程式關咗都繼續備份** 要用 Windows 排程工作，而家係關咗。設定入面見到，但暫時未開得。

## 備份去邊度

新磁碟會去一個共用 repository：`<account>/material-file-encryptor-storage`，未有就會開一個公開嘅。幾個磁碟共用都安全：每個快照都寫明係邊個磁碟嘅 vault id，標籤係 `mfe-<device id>-<random>`，加密分層按內容定址。**設定 > 備份 > Repository 安排** 可以改成每個磁碟一個 repository，磁碟嗰行選單嘅 **搬去自己嘅 repository** 就只搬嗰一個磁碟。舊 repository 入面已有嘅快照會留喺度。

已經備份去你自己揀嘅 repository 嘅磁碟會繼續用返佢。用私人 repository 嘅磁碟唔會自動備份，佢自己嘅排程照用。

## 每個磁碟保留嘅快照

每次備份驗證完，每個磁碟保留：

- 最新 **10** 個快照，
- 有快照嘅最近 **7** 日，每日 1 個，
- 有快照嘅最近 **8** 個星期，每星期 1 個，

即係每個磁碟最多 **25** 個。三個數字可以喺 **設定 > 備份** 改。嗰行選單嘅 **而家清走舊快照** 唔使新備份都可以即刻套用。

清走嘅範圍刻意收得好窄：

- 只有**呢部電腦**幫**呢個磁碟**上載嘅快照先會考慮。同一個 repository 入面其他磁碟、同埋其他電腦幫呢個磁碟上載嘅快照，一概唔掂。
- 最新一個驗證咗嘅快照永遠保留，呢部電腦還原緊嘅快照亦會保留。
- 每個快照用 manifest digest 同一個有刪除權限嘅 Docker Hub token 刪除。之後會確認 digest 同標籤都答「搵唔到」；如果標籤仲喺度，會經 Docker Hub API 刪埋再確認。
- 確認唔到嘅刪除唔會令備份失敗，會記低、喺頁面顯示，下次備份之後再試。
- 加密分層交返 Docker Hub 處理；同其他快照或者磁碟共用嘅分層照用得。

呢次更新之前嘅快照冇建立時間。程式會用 Docker Hub 標籤清單推算；推算唔到就當佢最舊，只會靠「最新」規則保留。

## 1,000 個標籤上限

程式每個 repository 最多讀 1,000 個快照標籤，入面所有磁碟一齊用。每個 repository 嗰行會顯示 **1,000 個標籤用咗 N 個**。去到 800 會變橙色，並提議 **將磁碟搬去各自嘅 repository**。

## 頁面顯示咩

- 一行摘要：幾多分鐘前備份咗、備份緊幾多 %、等緊網絡，或者需要處理。
- 按 repository 分組嘅磁碟表：可見性、磁碟數目同標籤錶，跟住每個磁碟嘅上次備份、快照數目、狀態同掣。
- 每行嘅選單：立即備份、還原…、而家清走舊快照、搬去自己嘅 repository、停止或開始備份、開啟呢個磁碟。

## 驗證狀態

- 單元同服務測試覆蓋保留規則、磁碟隔離、失敗安全、重試時間、觸發條件同請求驗證。
- 清走舊快照已經用真實 Docker Hub、正式嘅同步服務同傳輸，喺同一個 repository 用兩個合成磁碟試過：只有第一個磁碟嘅舊快照被清走，第二個磁碟嘅冇郁，刪咗嘅 digest 答「搵唔到」，最新快照還原之後資料完整。
- 未證明：喺表入面以唯讀方式顯示其他電腦嘅磁碟、改磁碟名、喺選單刪除某個磁碟所有備份、大細一欄，同埋程式關咗都繼續備份。詳情睇 ROADMAP.md。
