# 本機工具工作區

## 檔案轉換

四個分頁依次提供來源、格式、選項同佇列記錄。切換分頁會保留選擇；方向鍵同 Home、End 可以操作分頁。每個格式類別同選項清單都有本機搜尋及正規表示式建立器。未能使用嘅格式會保留原因。

轉換沿用現有有界限本機服務，來源檔案保持不變，覆寫目的地仍須確認。記錄每頁最多載入 50 項，顯示狀態、進度同暫停、繼續及取消操作。

## 本機模型

模型目錄、下載清單、本機對話、設定組合同說明各有獨立分頁。執行環境維護集中喺可展開區域，模型清單使用共用搜尋建立器，所選模型同每項下載進度清晰可見。既有確認、私隱及本機橋接界限保持不變，開啟分頁唔會自行下載模型或啟動服務。

## 伺服器準備

版本清單、所選版本同準備操作分開顯示。下載位元組未通過 SHA-256 核對前會明確標示未驗證。此流程仍然唔提供伺服器啟動、其他執行目標或接受授權條款。

## 驗證界限

合成元件檢查涵蓋格式目錄、控制項、鍵盤分頁、原有服務資料同拆卸。真正建置畫面、安裝及本機服務驗證需要另行完成，唔會用來源檢查代替。
