# 封裝文件目錄重用

可信主程序將 `app.isPackaged` 傳畀文件服務。只有明確嘅封裝執行環境
決定先會啟用服務生命週期內重用，似封裝嘅路徑唔會啟用。開發環境
每次要求都重新讀取目前目錄，保留來源修改即時可見嘅行為。

`src/main/documentation-catalog-service.js` 延後至首次要求先載入。封裝模式
嘅同時目錄及更新記錄要求，共用一次讀取同解析。JSON 只會完整深度凍結
一次，直接服務呼叫者因此唔可以改變之後嘅回覆。讀取或解析失敗會釋放
承諾，容許下次重試。關閉會釋放參照，拒絕未完成或之後嘅結果。現有
要求驗證同退出准入保持不變。

封裝檔案喺該應用程式生命週期內不可變。安裝新版本需要自己嘅新服務
生命週期。快取唔會取代 IPC 序列化、畫面文章呈現或瀏覽器文件讀取。
保留已解析目錄會增加主程序記憶體，同時避免重複暫存讀取同解析。

量度嘅目錄有 8,043,502 bytes，獨立 Node 程序重複暖快取讀取及解析中位數
為 14.45 ms。呢個只係有界元件量度，唔係冷快取結果或整體應用程式
改善。綁定候選版本嘅服務前後量度，同實際 GUI 驗收各自獨立。

相同字節嘅受控實際服務傳送比較，重新讀取中位數為 14.96 ms，已載入
封裝目錄則為 0.0014 ms。同時目錄及更新記錄中位數分別為 33.11 ms
同 0.0338 ms；首次封裝讀取、解析及凍結用咗 14.64 ms。另一個服務
生命週期明確執行垃圾回收後，觀察到載入增加 8,295,528 heap bytes，
關閉後減少 8,362,216 heap bytes。呢啲只係本機 Node 元件觀察，原始
時間樣本另行保存；IPC、ASAR 存取、畫面處理同已安裝應用程式反應
仍未驗證。

`test/documentation-catalog-service.test.js` 檢查延後同時重用、巢狀修改拒絕、
讀取或解析失敗後重試、開發資料更新、不支援動作、載入期間關閉，以及
正式傳送同退出接駁。合成結果唔代表已安裝執行環境反應速度。
