狀態：已加入原始碼實作及針對性 Node／DOM 邏輯驗證。實際組建外觀、輔助技術同正式操作副作用觀察仍然未驗證。

## 說明入口

每個已登記控制項上方提供一個 48 像素 Material 圖示按鈕，包含隨附 SVG、指明目標嘅無障礙名稱，同滑鼠停留／鍵盤焦點提示。開啟後會喺原有控制項上方顯示非模態面板，焦點移到標題。關閉或按 Escape 會返回說明按鈕；返回控制項操作會聚焦原有目標。

面板包含用途、可用狀態、完整樣本步驟、獨立練習、明確嘅逐步操作入口，同可展開完整說明及文件連結。開啟說明唔會驗證或執行原有操作。停用或唯讀目標仍然可以查看說明及練習。真實逐步操作保留原有驗證、權限及非同步結果；取消唔會聲稱撤回已完成修改。

分頁列可使用 `inlineGridColumn`。入口同面板仍然留喺同一 shadow root，父層提供共用 CSS grid，儲存格使用 `display:contents`。入口佔指定欄，展開面板佔完整下一列；擁有者透過 `onOpen` 關閉其他已開啟面板。實際組建版面仍需驗證。

五個分類分頁使用設定指引模組嘅 `settingsTabGuidance(key)`，穩定識別碼係 `settings.navigation.language`、`settings.navigation.appearance`、`settings.navigation.schedules`、`settings.navigation.attention` 同 `settings.navigation.history`，同欄位或操作描述分開。每個練習有真正本機 `md-tabs` 同五個 `md-primary-tab`，提供獨立面板識別碼、翻譯內容、選取狀態同焦點，Material 鍵盤處理採用自動啟動。父層分頁仍需明確綁定呢啲導覽描述；輔助函式存在唔代表已整合或完成實際鍵盤驗證。

## 預先編寫樣本邊界

`guidance-playground.js` 只接收 `definePractice` 建立嘅不可變 JSON 樣本，必須明確列出識別碼、類型、標籤、起始值、輸入、操作同預期結果。存取函式、回呼及非普通物件會被拒絕。練習只接收本機容器、翻譯函式同樣本，唔會接收真實目標、選項、目前草稿、服務或憑證。

純運算支援有限文字、子字串搜尋、數字、可見性、選項、顏色、樣本移除／重設／加入、導覽、合成檔案選取、時間預覽同固定公開憑證示範文字。每次開啟有獨立草稿；重設會還原預先編寫值，關閉會銷毀狀態同監聽。選項描述會明確選用本機 Material 選擇器、單選或按鈕元件。選單採用練習內部絕對定位，每次練習有獨立單選群組名稱，唔會安裝正式介面嘅全文件選項輔助工具。主題、密度同字型家族例子只會修改自己樣本嘅色彩角色、間距同字型；其他未支援概念保留明確缺口。輸出只會係文字或有界限嘅本機預覽屬性。

樣本唔會接觸網絡、儲存、歷史、IPC、原生選擇器、剪貼簿、音訊或真實計時器。DOM 標記唔係安全隔離容器；原始碼驗證之外，仍需喺實際組建觀察正式操作計數保持不變。

## 覆蓋範圍同未完成項目

88 個靜態設定描述已有 88 個獨立預先編寫練習，包括五個分頁、七個星期選項同四個日期欄。日期使用三個 Material 數字欄，會拒絕無效日期，唔會自動滾到下個月。涉及設定、憑證、歷史、匯入／匯出同提醒嘅操作，只會改變明確合成記錄；確認同驗證都喺本機樣本進行，全部可以重設。憑證例子只接受固定公開示範文字，唔會建立憑證或金鑰；匯出只顯示刪敏 JSON，時間例子唔會啟動計時器。

清除變體有獨立可編輯合成欄位同本機清除操作。十四個純量／快照時間表數值範圍，按明確設定中繼資料選擇樣本，唔會讀取真實數值。旁白同專注選項保留獨立巢狀控制項。快照擷取同移除提供本機記錄示範，會拒絕移除使用中合成參照。

11 個巢狀外觀概念同六個字型概念亦有樣本；字型選擇會實際改變樣本文字粗幼，非粗幼字型軸仍需專用運算。全部 19 個關鍵影格概念同 16 個過渡屬性概念已有獨立合成操作，覆蓋工廠識別碼有精確比較。樣本會改變影格、內部副本、時間座標同独立起止資料列；超出範圍移動會被拒絕，重設保留中繼資料，離散播放仍然明確不可用。動畫、顏色、圖片、繪畫工作區、文字樣式輔助變體、標誌編輯同伺服器準備仍需完整練習對照。類型清單唔等於完整覆蓋。未知描述會明確顯示練習尚未實作，唔會用通用成功訊息冒充。
