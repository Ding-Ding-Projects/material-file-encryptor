# 共用工作區組件

桌面介面使用五個已註冊組件：`mfe-titlebar`、`mfe-main-workspace`、`mfe-content-panel`、`mfe-data-table` 同 `mfe-selection-toolbar`。每個都繼承 `SurfaceElement`，自行管理 shadow 結構、樣式表、連接生命週期同支援嘅投影內容。工作區頂部工具列係主工作區內嘅群組；標題列係唯一嘅 banner。

現有畫面 ID、檔案操作、表格標題、記錄內容、選取回呼同語言目標繼續留喺 light DOM。表格保留原生語義。內部捲動區會複製表格標籤或 caption 嘅文字作為名稱，避免跨越 shadow 邊界引用 ID。面板沿用原有無障礙名稱，或者使用可見標題。此改動冇新增鍵盤攔截或資料儲存。

外觀繼續繼承現有角色變數。工作區 flex 邊界、面板捲動、表格捲動、響應式間距同選取工具列換行都由組件管理。視窗按鈕保留不可拖動區域。移除組件時會解除 slot 監聽器同本地文字觀察器；重新連接時保留投影記錄同操作監聽器。

## 驗證同限制

`test/surface-compositions.test.js` 驗證真實 constructor 註冊、所屬 shadow 部件同樣式表身份、生命週期、語義化表格標題同記錄、穩定操作節點，以及替換後必須失敗嘅負面測試。驗收檢查器透過現有控制檢查阻止缺失或被替換嘅組件通過。收據只係結構檢查嘅補充，普通節點註冊唔代表擁有權。

原始碼同模擬 DOM 測試唔能夠證明實際畫面、原生視窗操作、瀏覽器無障礙、封裝或設計一致性。視覺驗收仍須使用綁定原始碼版本嘅隱藏桌面互動同幾何量度，涵蓋正常及最小視窗、英文／廣東話／雙語、淺色／深色，以及 100／125／150／200 百分比縮放。組件唔會記錄憑證、檔案內容或個人詞彙。
