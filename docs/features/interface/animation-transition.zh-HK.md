# 動畫同過渡編輯

## 目前界線

呢份係已安裝程式同公開文件外觀編輯器共用嘅未完成來源草稿。模型、原生動畫介面同編輯控制已保存。針對性檢查涵蓋實際掛載數值及影格控制、本機時間表邊界、靜態比較、時間驗證、減少動態狀態篩選、完成控制再次觸發同顯示例外收尾。完整引導整合同畫面驗收仍然未完成。儲存數值同注入式 API 測試唔代表動作已喺畫面呈現。此處冇宣稱現時畫面或者計時錄影完成。

## 編輯同呈現

動作儲存喺每個外觀圖層，明確保留所選元素、圖層同狀態。動畫同過渡分頁提供有次序軌道及規則、啟用或停用或單獨播放、群組、前置關係、偏移、交錯、屬性輸入、關鍵影格、片段緩動、時間、標記、觸發同原生時間軸選項。數值控制同時間軸拖動並存。復原、取消復原、外觀版本、具名預設、樣式複製、重設同已驗證 JSON 都會攜帶動作資料。

介面呼叫目標顯示引擎嘅原生動畫 API。屬性選擇器列出計算屬性，亦接受明確自訂屬性名稱。CSS 解析成功唔代表已證明插值。顯示引擎拒絕時會顯示原因，同時保留可攜編寫資料。元素軌道操作確切目標。獨立圖層軌道需要實際圖像圖層節點；層疊到同一元素嘅 CSS 圖層唔會產生獨立像素畫面。圖像覆蓋層重建時會取消舊控制再接新節點，連續性仍需要計時驗收。

時間支援小數毫秒、自動持續時間、有正負號開始及結束延遲、有限或無限重複、重複起點、方向、填補同有正負號或零播放速度。關鍵影格保留明確偏移、絕對或相對時間、計算數值、逐片段緩動同合成。原生文件時間軸使用毫秒。捲動及視圖時間軸會偵測能力，並保留來源、方向、內縮同連接範圍；進度定位使用按能力偵測嘅原生百分比，逐影格明確需要文件時間。兩者仍需要瀏覽器驗證。

## 能力同安全限制

目前顯示介面冇原生逐次重複延遲同彈簧物理功能。可攜設定仍然可見，未支援預覽唔會被當成已套用。具名、貝茲、線性同階梯緩動交由顯示引擎時間函數解析器處理。只有顯示引擎提供時先會使用合成同重複累積。共用彩虹速度仍然具決定性，軌道唔可以覆寫預留屬性。

觸發只限所選目標狀態、准許嘅互動事件、可見進度同明確動畫指令。佢哋唔會執行程式碼、擷取資源、認證或者執行受保護產品操作。匯入 CSS 會拒絕網址同宣告跳脫。有版本嘅動作輸入設位元組容量、有限數值驗證、循環偵測同原型鍵拒絕；未知未來資料只會保留供攜帶，唔會執行。

減少動態效果會保留編寫模型、取消原生動畫控制，並使用最後靜態數值。預覽喺 30 秒後暫停，銷毀時會釋放影格觀察。程式同作業系統偏好傳遞、確切狀態繼承、播放中斷、重疊屬性同圖層重建仍需要真實計時驗證。本機時鐘時間表按日期、跨午夜時段、時區、星期日子同優先次序揀具名預設；規則未生效時會還原編寫模型，唔會聯絡供應商。完整逐控制引導文件仍然未完成整合。

## 驗證同畫面清單

手寫能力矩陣列明實作同呈現邊界。測試涵蓋外觀可攜往返、時間驗證、前置循環、實際目標 API 呼叫、過渡、事件範圍、減少動態效果取消同收尾。負面來源檢查會移除分頁、設定或者呈現介面。呢啲係來源同 API 邊界結果，唔係已建置畫面證據。

固定建置獲批准後，兩個介面都要經真正編輯器操作每項能力，保留逐次操作畫面加計時錄影或者計算樣式取樣、確切時間及觸發斷言、重新載入及減少動態效果檢查，同埋有界資源收尾。所有現有 README、文件、維基、圖庫同下載展示畫面都要用已檢查並綁定來源嘅新畫面取代。新畫面同引用核實前，原圖保留並清楚標示歷史。生成圖像唔可以代替。

## 明確時間導引清單

以下34個手寫概念已有雙語說明記錄。呢34個概念會將已審查選用導引掛載喺確切欄位上方，使用原有修改事件並等候獲接受嘅消費操作。實際掛載元件測試涵蓋引導數值儲存。其他動態控制、完整文件閱讀器整合同真實瀏覽器導引驗收仍待完成。

### duration

持續時間

設定呢條軌道每次重複所佔嘅時間。

非負小數毫秒或者 auto。

300 毫秒。

改變關鍵影格間距同後續軌道開始時間。

用 125.5 設定短而精確嘅淡入。

模型拒絕負數或者非有限持續時間；原生進度時間軸決定 auto 時間。

將持續時間重設為 300，或者復原外觀版本。


### start-delay

開始延遲

相對序列起點移動呢個效果。

有正負號嘅小數毫秒。

0 毫秒。

正數會等候；負數由效果中段開始。

用 -100 令 300 ms 效果跳過最初 100 ms。

只接受可攜數值範圍內嘅有限數字。

將開始延遲重設為 0，取消提前或者等候。


### end-delay

結束延遲

調整軌道之後、前置關係完成之前嘅間隔。

有正負號嘅小數毫秒。

0 毫秒。

影響計算結束時間同後續相依軌道起點。

用 200 喺後續效果之前留空檔。

原生顯示引擎會驗證最終效果時間。

序列意外等候時，將結束延遲重設為 0。


### repeat-count

重複次數

選擇呢個效果提供幾多次重複。

非負有限次數，包括小數，或者 infinite。

1 次。

改變有效時間；無限前置軌道唔可以有後續相依軌道。

用 2.5 播放兩次加下一次嘅一半。

前置驗證會拒絕將無限軌道用作前置軌道。

還原為 1，或者先移除後續連結再揀 infinite。


### iteration-start

重複起點

選擇有效時段開始時取樣嘅重複位置。

非負小數重複索引。

0。

移動最初取樣嘅影格位置，唔會刪除編寫影格。

用 0.5 由第一次嘅中段開始。

負數同非有限重複起點會被拒絕。

將重複起點重設為 0，由第一個影格開始。


### playback-rate

播放速率

設定呢個原生動畫控制嘅編寫速度同方向。

介乎 -100 至 100 嘅有限有符號速率；零會停留時間。

1。

獨立於時間軸預覽速度，乘算原生播放速度。

用 -1 反向播放，或者 0.5 半速播放。

超出支援範圍嘅速率會喺儲存前被拒絕。

將播放速率重設為 1，再重新開始預覽。


### repeat-delay

重複延遲

保留重複之間嘅要求空檔，供可攜資料使用。

非負小數毫秒。

0 毫秒。

目前介面冇逐次重複延遲成員，非零數值會令原生預覽無法使用。

喺匯入預設保留 150，記低要求嘅行為。

編寫數值會驗證同保留，播放時唔會靜靜忽略。

將重複延遲重設為 0，啟用目前顯示引擎預覽。


### direction

方向

選擇每次重複嘅方向。

normal、reverse、alternate 或者 alternate-reverse。

normal。

交替模式會每隔一次反向，保留影格編寫次序。

用 alternate 配合兩次重複，移出去再返嚟。

只接受四個原生方向選項。

動作由意外端點開始時，將方向重設為 normal。


### fill

填補

選擇效果數值喺有效時段之外會唔會套用。

none、forwards、backwards、both 或者 auto。

none。

控制延遲前同完成後呈現，唔會修改已儲存基礎樣式。

用 forwards 喺完成後保持最後效果。

模型只接受原生填補模式。

揀 none 或者停止播放，釋放效果。


### global-easing

整體緩動

塑造呢個效果嘅整體時間進度。

具名緩動、cubic-bezier()、steps() 或者支援嘅 linear() 停點。

linear。

喺逐片段緩動之前轉換效果進度。

用 cubic-bezier(0.4, 0, 0.2, 1) 設定常用平滑曲線。

不安全 CSS 會被拒絕；未支援語法保留編寫值，並標示預覽無法使用。

將整體緩動重設為 linear，取消曲線塑形。


### animated-property

動畫屬性

指定呢條影格軌道改變嘅確切顯示屬性。

顯示引擎計算屬性名稱，或者有效自訂屬性名稱。

opacity。

每個影格值都會套用到所選範圍嘅呢個屬性。

揀 transform，再將影格值設為 translateX(20px)。

屬性名稱同數值都會驗證；解析器接受唔代表已證明插值。

還原 opacity 同數值影格，分辨邊個屬性被拒絕。


### after-track

前置軌道識別碼

喺另一條編寫軌道完成之後開始呢條軌道。

留空，或者現有有限前置軌道識別碼。

留空，冇前置軌道。

將前置結束時間加到呢條軌道偏移同交錯時間。

輸入淡入軌道識別碼，等淡入完成先移動。

缺失識別碼、循環同無限前置軌道會被拒絕。

清除前置識別碼，還原獨立起點。


### track-name

軌道名稱

為可選軌道列入面呢條軌道命名。

最多 160 個字元嘅純文字。

新動畫用 Animation，新過渡規則用 Transition。

改變顯示標籤，唔會改穩定識別碼同前置關係。

將透明度軌道命名為淡入。

控制字元同過長名稱會被拒絕。

重設名稱或者復原外觀版本。


### parallel-group

並行群組

標記屬於同一編寫並行群組嘅軌道。

留空或者純文字群組名稱。

留空。

保留群組標籤；實際時間仍由偏移同前置關係決定。

將透明度同變形軌道設為 entrance，並用相同偏移。

群組名稱唔會靜靜同步各自編寫嘅偏移。

清除群組標籤，移除呢個整理群組。


### sequence-offset

序列偏移

相對已解析前置邊界移動呢條軌道。

有正負號嘅小數毫秒。

0 毫秒。

解析前置關係之後，直接加到原生開始延遲。

用 -50 同前置結尾重疊 50 ms。

完整前置圖必須有限同冇循環。

將序列偏移重設為 0，再檢查前置連結。


### stagger-offset

交錯偏移

按軌道喺編寫清單嘅位置安排間距。

每個清單位置嘅有正負號小數毫秒。

0 毫秒。

加入交錯乘以軌道索引；移動軌道會改變呢部分時間。

索引為 2 嘅軌道用 25，會加入 50 ms。

最終原生延遲需要顯示引擎接受。

將交錯偏移重設為 0，取消清單位置間距。


### target-scope

目標範圍

選擇效果改變元素，定係真正獨立圖像圖層。

element 或者 layer。

element。

圖層範圍需要實際圖像圖層節點；層疊 CSS 圖層唔會提供節點。

揀 layer，只移動一個圖像覆蓋層而唔移動目標元素。

缺少獨立圖層節點時會標示預覽無法使用，保留編寫數值。

揀 element，或者先建立真正圖像圖層再用 layer。


### target-state

目標狀態

將呢條軌道限制喺明確互動或者結果狀態。

文件列出嘅一般、互動、驗證、載入或者結果狀態。

新增時用所選外觀狀態；重設軌道會用 normal。

未生效繼承圖層會取消原生控制；減少動態亦會篩選狀態。

揀 hover，效果只屬於游標停留嘅目標。

未知狀態會被拒絕，未生效狀態唔會被當成生效。

揀 normal，或者檢查狀態繼承設定。


### composition

合成

選擇呢個效果點樣同現有屬性數值合成。

replace、add 或者 accumulate。

replace。

原生效果合成同編寫軌道次序決定重疊屬性優先次序。

用 add 喺基礎變形之上加入受支援變形部分。

顯示引擎支援程度取決於屬性同數值類型。

揀 replace，再停用競爭軌道去分辨效果。


### iteration-composition

重複合成

選擇已完成重複會唔會累積到之後嘅重複。

replace 或者 accumulate。

replace。

只有原生效果提供 iterationComposite 時先會套用累積。

對受支援重複變形用 accumulate。

未支援 iterationComposite 時會取消嘗試控制並標示無法使用。

將重複合成重設為 replace，使用一般顯示路徑。


### trigger

觸發方式

選擇開始呢個效果嘅目標事件或者狀態變化。

列出嘅狀態、指標、焦點、拖曳、可見度同明確指令事件。

entry。

只會開始動畫，唔會執行受保護產品操作。

揀 hover 設定指標進入效果。

未列出事件會喺儲存前被拒絕。

還原 entry，再重新預覽去分辨事件傳送。


### from-state

來源狀態

接受觸發之前，要求特定先前狀態。

any 或者一個文件列出嘅目標狀態。

any。

按變化之前捕捉嘅狀態集合篩選過渡。

揀 normal，限制由一般狀態進入。

先前狀態唔符合時，效果唔會開始。

揀 any，取消先前狀態限制。


### to-state

目的狀態

傳送觸發時要求目的狀態。

一個文件列出嘅目標狀態。

normal。

按目標目前狀態集合篩選效果。

揀 invalid，設定驗證結果動畫。

未知目的狀態會被拒絕。

揀 normal，或者修正帶動效果嘅目標狀態。


### progress-threshold

進度門檻

設定呢個觸發所需嘅最低可見進度。

介乎 0 至 1 嘅小數。

0。

低於門檻嘅可見事件唔會開始軌道。

用 0.5，要求最少一半可見。

超出 0 至 1 嘅數值會被拒絕；一般事件會傳送完整進度。

將進度門檻重設為 0，取消可見度限制。


### debounce

防重複間隔

壓住同軌道上次接受觸發太接近嘅重複傳送。

0 至 60000 毫秒。

0 毫秒。

逐軌道使用執行時鐘，唔會延遲產品操作。

用 250 壓住快速重複指標事件。

負數或者過大間隔會被拒絕。

調查重複觸發冇出現時，將防重複間隔重設為 0。


### retrigger

再次觸發行為

決定新觸發點樣處理仲播放緊嘅控制。

restart、ignore、reverse 或者 replace。

restart。

ignore 保留播放中控制；reverse 反向；restart 同 replace 取消再開始新效果。

用 ignore，避免停留效果播放中重新開始。

已完成控制可以再開始；取代時會取消填補。

重入結果唔清楚時，揀 restart 同停止現有預覽。


### cancel-on-exit

離開時取消

選擇離開軌道有效狀態時會唔會取消效果。

true 或者 false。

true。

狀態離開會取消原生控制；未生效繼承圖層仍會獨立停止。

停留效果要喺指標離開時消失，就保留 true。

欄位轉換之後只接受布林值。

還原 true，或者按停止去釋放持續效果。


### trigger-priority

優先次序

安排同一觸發傳送嘅效果次序。

介乎 -1000 至 1000 嘅有限數值。

0。

較低優先次序先開始；之後編寫效果同合成決定重疊呈現。

用 10，喺優先次序 0 基礎效果之後開始強調。

優先次序唔會授權產品指令或者改變事件範圍。

將優先次序重設為 0，還原一般編寫次序。


### timeline-source

時間軸來源

選擇帶動效果嘅原生時鐘。

document、scroll 或者 view。

document。

document 用毫秒；原生 scroll 同 view 時鐘用進度。

揀 scroll，將動作連到所選捲動來源。

冇原生時間軸建構支援時會保留模型，並標示無法使用。

顯示引擎冇 scroll 或者 view 支援時，揀 document。


### timeline-element

時間軸元素

指定提供原生時間軸進度嘅實際元素。

target、parent 或者文件捲動元素。

target。

捲動時間軸用呢個來源；視圖時間軸觀察呢個主體。

目標位於相關捲動容器之內時，揀 parent。

原生建構例外會被攔住同顯示，唔會遺下監聽。

還原 target，或者檢查邊個祖先真正捲動。


### timeline-axis

時間軸方向

選擇原生時間軸量度嘅實體或者書寫方向。

block、inline、x 或者 y。

block。

改變邊個捲動方向或者視圖進度帶動效果。

橫向捲動列用 x。

只會儲存原生方向選項。

將時間軸方向重設為 block，使用一般書寫流程。


### view-inset

視圖內縮

調整原生視圖時間軸使用嘅可見範圍。
