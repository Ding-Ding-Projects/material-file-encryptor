# 伺服器管理基礎

呢個單元提供官方 Java 版本探索、指定版本嘅伺服器發佈中繼資料解析、綁定來源嘅設定描述、類型化設定控制項，同明確列出四種目標嘅能力清單。獨立內部本機程序轉接器而家提供有條件嘅建立同生命週期操作，但未接入產品介面。驗證期間冇執行真實伺服器或接受真實授權。SSH 及容器轉接器同現有伺服器接管仍然不可用。

## 版本目錄及來源

`refreshJavaCatalogue` 會讀取 Mojang 完整官方版本清單，設十秒逾時、四 MiB 回應上限、HTTPS 來源限制，同拒絕重新導向。所有回傳版本都會保留，包括歷史渠道。重複身份、缺少最新版本項目同不可信中繼資料網址都會被拒絕。快照會記錄精確來源 SHA-256 同擷取時間。`catalogueState` 會分辨現行、過期、離線同不可用快照；離線唔等於現行。

`resolveJavaDistribution` 會先按版本清單嘅 SHA-1 驗證指定版本中繼資料，再讀取專用伺服器項目。缺少伺服器下載會明確標示不可用。如果官方中繼資料冇列出執行環境，歷史 Java 執行環境要求會保持未解析。已解析下載會記錄網址、SHA-1 同大小，但唔會聲稱已驗證下載位元組、已安裝、已驗證執行，或者已取得 EULA 同意。完整官方歷史 Bedrock 發佈目錄仍然不可用，現行下載頁填補唔到呢個缺口。

## 設定及目標界線

描述必須包含版本類別、精確版本、已驗證發佈 SHA-256、官方來源修訂、說明、權限、持久化使用者同即時或重新啟動語義。布林值對應開關、列舉對應可搜尋選擇器、數字對應有界數值控制項，文字對應文字控制項。呈現器由擁有者提供本地化文字同真實動作回呼。未知擴充設定會原封不動保留；編輯未知擴充內容需要真實描述。呢度冇提供通用 JSON 或 shell 編輯器。

本機程序、本機容器、SSH 程序同 SSH 容器分別列出身份同權限證明要求。本機程序生命週期有內部有條件實作，但仍然不可用及未驗證；其餘三種執行目標轉接器尚未實作。連線中斷絕對唔可以當成伺服器已停止。

## 內部本機程序轉接器

`LocalProcessServerAdapter` 會建立全新專用根目錄，以串流取得有上限嘅官方發佈檔，驗證精確大小同 SHA-1，記錄 SHA-256，然後只發佈已驗證位元組。建立失敗或取消會保留持久化未就緒狀態同專用暫存資料，留待復原。現有根目錄絕對唔會覆寫。授權狀態由 `eula=false` 開始；寫入 `eula=true` 必須有明確同意，綁定精確伺服器身份、版本、發佈雜湊同官方 EULA 網址。測試只會模擬呢個契約，唔會接受真實伺服器授權。

啟動預設仍然不可用：可信主機必須提供已驗證相容 Java 執行檔及雜湊，同綁定版本嘅本機回送設定、支援屬性結構及可用連接埠證明。呢啲服務必須由真實受保護提供者供應，絕對唔可以信任呈現器自行聲稱已驗證。完成非同步批准後，會喺可信原生拒絕寫入及刪除檔案租約保護兩個精確檔案期間，重新檢查發佈同執行環境位元組。租約提供者預設不可用，必須保留真實原生 handle 直到專用程序退出；一個布林聲稱或者重新雜湊本身唔係原子檔案固定。假程序測試冇執行原生租約實作，亦冇證明呢個原生保證。釋放租約失敗會保留擁有權物件、阻止新啟動，並記錄需要復原狀態。准入、釋放同持久化錯誤會一齊保留；釋放失敗後仍然會嘗試持久化。單憑程序錯誤唔會釋放租約或丟棄子程序物件，真正退出結算最多只會釋放一次。發佈前取消啟動唔會留下設定；較後取消會記錄已生成設定，只有專用位元組保持不變，先可以重新嘗試。啟動唔會經 shell，亦會隱藏。JVM 會用 `-Xmx512M`；呢個唔係完整原生程序記憶體或 CPU job 界線。預設 `windowsProcessIdentity` 透過有界原生程序查詢讀取精確 PID、建立時間同執行檔路徑。轉接器亦會保留自己嘅子程序物件，身份失去驗證時會停止放行。

正常停止只會向已驗證專用程序寫入 `stop`，喺有界逾時內等候，絕對唔會強制終止。生命週期狀態寫入會依次進行，防止較舊執行快照覆蓋後來退出狀態。程序啟動唔等於伺服器就緒，就緒狀態仍然未驗證。重新啟動及復原接管、完整資源或 job 限制、儲存容量准入、完整記錄及狀態協定、GUI 授權控制項、原生 IPC 或提供者整合同真實伺服器驗收仍然待完成。新轉接器工作階段唔可以靜靜接管已持久化程序或根目錄。其餘三種目標轉接器仍然不可用。

## 整合交接

只可以將目錄模組匯入可信主機層，並提供明確更新同擁有者快取持久化。唔好向呈現器暴露任意擷取網址。啟用編輯之前，設定描述必須綁定實際已驗證發佈，同已生成或按版本審核嘅預設值。透過現有本地化介面掛載 `mountConfigurationControls`，並提供既定權限、確認、持久化同歷史動作。登記表及導覽、控制項上方自選引導、完整文件及說明、結構化集合控制項、原生 IPC、授權、執行生命週期、擴充套件同實際呈現驗收，仍然屬於整合或後續實作工作。呢個單元冇改動共用登記表或導覽檔案。

執行 `node --test test/server-manager.test.js`。呢啲測試證明來源行為同反向清單及設定檢查，唔代表已安裝伺服器或 GUI 驗收。
