# 面板版面同可操作通知

`mountSurfaceFoundation` 提供 `registerPanel(id, element)`。每個工作面板掛載內容後須登記。`registerViews` 亦會自動登記面板版面，除非該檢視指定 `layout: false`。

每個已登記面板都有移動、調整大小同重設版面控制。可拖動前兩個控制，或將焦點移至控制再按方向鍵。鍵盤每步 10 像素，配合 Shift 為 40 像素。數值幾何儲存喺 `mfe.panel-layout.v1:<id>`，套用時限制喺目前視口範圍。重設會刪除該面板已儲存幾何。銷毀會移除控制並恢復原本行內幾何。控制文字支援英語、廣東話同雙語模式。

通知接受標準 `progress: {value, label}`，百分比限制為 0 至 100，並可有最多四個標準 `recovery: [{id, label}]` 動作。掛載時提供 `onNotificationAction(actionId, canonicalRecord)`。由回呼決定執行邊個受支援主程式操作，唔會從動作文字推斷要執行嘅命令。冇回呼時，復原控制保持停用。`updateNotification(id, patch)` 會隨操作進度更新同一筆記錄。

通知中心支援選取、選取可見、批次已讀同批次關閉。JSON 同 CSV 匯出保留標準欄位，包括進度同復原中繼資料；顯示翻譯唔會改寫記錄。通知聲音須喺每個工作階段由可見開關啟用，只播放短本機音調，唔使用音訊檔或網絡請求。

更改基礎介面語言時，會喺重建外框期間保留可匹配嘅暫態控制，例如搜尋文字、正則旗標、選取範圍同已開啟對話框。同一語言呼叫唔會重新掛載。保留機制使用結構控制路徑；若元件結構同時改變，可能無法匹配欄位，因此唔係持久表單草稿儲存。

聚焦可執行測試涵蓋指標同鍵盤版面動作、持久儲存同重設、標準進度／復原記錄、回呼路由、音訊啟用，同暫態搜尋／對話框恢復。測試使用確定性 DOM 固定資料。封裝桌面同瀏覽器版面、輔助技術行為同真實主程式操作，整合後仍須執行時驗證。
