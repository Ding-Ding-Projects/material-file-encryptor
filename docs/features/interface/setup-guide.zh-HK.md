# 設定指南

設定指南是桌面程式內的簡短逐步精靈。首次啟動時會自動執行，之後亦可隨時從「使用說明」頁面（開啟設定指南）或指令面板（開啟設定指南）重新開啟。每個步驟都會透過程式其他部分所用的同一段程式碼執行真正的設定動作，然後顯示實際發生了甚麼。

## 步驟

1. 歡迎。介紹這個指南。這一步和最後一步必須經過，其餘步驟都可以略過。
2. 外觀及語言。選擇英文、廣東話或兩者並列，以及跟隨裝置、淺色或深色外觀。每個選擇都會經由與「設定」相同的偏好設定途徑套用，並顯示結果。
3. 系統需要。讀取 WinFsp 驅動程式的實際狀態，以及本機伺服器監管是否可用，並分開報告。檢查只會讀取。只有在驅動程式缺少而且可以使用安裝程式時，才會出現「安裝 WinFsp」，Windows 會保留它自己的批准提示。
4. 你的磁碟。輸入磁碟名稱，也可以按需要輸入加密儲存資料夾和快取資料夾（「瀏覽」會開啟系統的資料夾選擇器）。「建立磁碟」和「解鎖現有磁碟」會開啟現有的磁碟對話框，並預先填入這些數值。對話框仍然會要求密碼或金鑰檔，並保留它自己的驗證；指南完全看不到機密內容。對話框關閉後，指南會讀取磁碟狀態，並報告磁碟是否已就緒。
5. 瀏覽器。用現有的配對畫面顯示一次性的瀏覽器配對碼。你仍然需要在桌面上批准配對。離開這一步時配對碼會被清除。
6. 完成。把每個步驟整理為已完成或已略過，並附上結果，然後帶你進入工作區首頁。

## 進度、續做及略過

進度條和步驟清單會顯示你所在的位置。「上一步」和「下一步」每次移動一步；「略過這一步」會把該步驟記錄為已略過；「儲存並關閉」和「略過設定」會返回首頁，但不會遺失已儲存的步驟。「重新開始」只會清除已儲存的指南進度，不會更改任何偏好設定、磁碟或配對。

進度會以單一項目儲存在裝置上，只保留步驟、哪些步驟已完成或已略過、語言、外觀和磁碟名稱。密碼、金鑰檔、資料夾路徑和配對碼絕不會被儲存。如果已儲存的記錄損毀或無法讀取，會整份拒絕並重新開始。如果裝置無法儲存進度，指南會告知，並在本次使用期間繼續運作。

## 具破壞性的步驟

如果程式已經指向另一個磁碟，再建立新磁碟會改變程式開啟的磁碟。目前磁碟的檔案不會被刪除，但在你再次解鎖該資料夾之前，程式不會再開啟它們。這一步使用現有的雙鑰匙確認和完整滑桿；拒絕的話不會有任何改變，也不會儲存任何內容。

## 鍵盤及無障礙

每個動作都是真正的 Material 按鈕或欄位，可以用 Tab 鍵到達。Alt+右鍵前往下一步，Alt+左鍵返回上一步。每當步驟改變，步驟標題都會取得焦點，結果會透過狀態區域朗讀。所有文字都有英文、廣東話及兩者並列。面板會使用 Material 動態標記滑入，當裝置要求減少動態時，動畫和過渡效果都會移除。

## 適用範圍

設定指南係桌面程式嘅功能。網站同瀏覽器擴充功能都冇設定精靈：網站係說明文件同下載頁，擴充功能就有自己喺工作區入面嘅配對流程。兩者都記錄為「不適用」而唔係「欠缺」，而獨立嘅公開網站要求維持不變。

## 驗證範圍

原始碼檢查會用偏好設定、驅動程式、磁碟對話框、確認和配對服務的模擬版本，驅動真正的模型和畫面，包括重新啟動後續做、略過、鍵盤移動和本地化。這些並不是已建置程式的驗收。首次使用流程在已建置程式上的互動及畫面擷取，以及在真實裝置上安裝驅動程式或建立磁碟的執行結果，尚未記錄。
