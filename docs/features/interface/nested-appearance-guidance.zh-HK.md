# 巢狀外觀控制項指引

呢個來源單元覆蓋十一種圖層導覽及本機標誌控制項。指引放喺原有控制項之前，透過同一事件執行並等候原有接收端完成。原有驗證、權限及歷史記錄繼續有效。其他巢狀編輯器控制項、實際畫面及所有最新截圖驗收仍未完成。

### nested-select-state

互動狀態

用途: 選擇之後圖層修改所屬嘅互動狀態。

選項: normal、hover、focus、active、selected、disabled、dragged、invalid、loading、success、warning、error

預設值: "normal"

影響: 選擇 hover 唔會模擬滑鼠停留，亦唔會改 normal 狀態。

例子: 先選 focus，再修改鍵盤焦點外框。

驗證: 只可選十二個已登記狀態。

復原方法: 返回 normal 檢查基本外觀。


### nested-select-layer

所選圖層

用途: 選擇屬性欄及圖層操作要處理嘅圖層。

選項: 目前群組內一個現有圖層。

預設值: "0"

影響: 選取只會改編輯目標，唔會修改已儲存屬性。

例子: 先選第二個圖層，再改佢個名。

驗證: 圖層必須存在於目前開啟嘅群組。

復原方法: 重新選之前嘅圖層，選取本身唔會新增樣式修訂。


### nested-toggle-visible

圖層可見性

用途: 決定呢個圖層會唔會參與畫面合成。

選項: 顯示或者隱藏呢個圖層。

預設值: true

影響: 隱藏會保留圖層資料，但唔再顯示佢嘅效果。

例子: 隱藏陰影圖層，比較其餘合成效果。

驗證: 使用呢個圖層原有嘅可見性操作。

復原方法: 重新顯示同一圖層，或者使用外觀復原。


### nested-toggle-locked

圖層編輯鎖

用途: 鎖住呢個圖層嘅屬性修改，直到解除編輯鎖。

選項: 鎖定或者解除鎖定圖層。

預設值: false

影響: 呢個編輯鎖唔係設定檔密碼，亦唔代表憑證權限。

例子: 背景圖層完成後鎖住，再編輯上面嘅圖層。

驗證: 由原有圖層鎖處理程序決定狀態變更。

復原方法: 使用同一圖層嘅解除鎖定操作。


### nested-open-group

開啟群組

用途: 進入可編輯群組，選取入面嘅子圖層。

選項: 開啟所選可編輯群組。

預設值: "Root group"

影響: 開啟已點陣化但可編輯嘅群組，會透過原有操作移除產生嘅點陣預覽。

例子: 開啟文字裝飾群組，修改入面嘅底線圖層。

驗證: 已鎖定群組及不可變嵌入來源唔可以進入。

復原方法: 使用返回上層群組，嵌入副本必須透過獨立操作先可以分離。


### nested-parent-group

返回上層群組

用途: 離開目前群組，選取包含佢嘅圖層。

選項: 返回上一層群組。

預設值: "Root group"

影響: 導覽會保留子圖層屬性，唔會將群組合併。

例子: 修改巢狀邊框圖層後返回上層。

驗證: 只限已開啟子群組時使用。

復原方法: 重新開啟該群組，繼續修改子圖層。


### nested-logo-file

選擇本機標誌

用途: 選擇本機靜態圖片，轉換成顯示用標誌。

選項: 一個本機靜態 PNG、JPEG 或 WebP 檔案。

預設值: null

影響: 原有轉換器會喺本機儲存已平面化嘅 128 × 128 PNG。

例子: 選擇正方形、透明背景嘅靜態 PNG。

驗證: 只限 PNG、JPEG 或 WebP，最多 4 MiB、每邊 8192 及解碼後 16000000 像素。

復原方法: 選另一張有效圖片，或者重設標誌恢復原樣。


### nested-logo-fit

標誌填放方式

用途: 選擇完整放入圖片，或者填滿正方形標誌畫布。

選項: contain 保留完整圖片，cover 填滿正方形。

預設值: "contain"

影響: 填滿會裁走超出部分，完整放入可能留透明邊位。

例子: 用完整放入保留闊身文字標誌。

驗證: 原有切換只提供 contain 及 cover。

復原方法: 切換返 contain，檢查預覽。


### nested-logo-x

水平焦點

用途: 調整圖片喺標誌轉換畫布嘅水平位置。

選項: 0 至 1，每格 0.01。

預設值: 0.5

影響: 偏移會影響剩餘空間或裁切位置，唔會改圖片比例。

例子: 填滿時向右移，保留靠右邊嘅主體。

驗證: 使用原有 0 至 1、每格 0.01 嘅範圍控制項。

復原方法: 返回 0.5，再檢查轉換預覽。


### nested-logo-y

垂直焦點

用途: 調整圖片喺標誌轉換畫布嘅垂直位置。

選項: 0 至 1，每格 0.01。

預設值: 0.5

影響: 垂直偏移會決定裁走上面定下面超出嘅部分。

例子: 向上移，保留直幅圖片上方嘅面部。

驗證: 使用原有 0 至 1、每格 0.01 嘅範圍控制項。

復原方法: 返回 0.5，再檢查轉換預覽。


### nested-logo-reset

重設標誌

用途: 移除本機儲存嘅自訂標誌，恢復原有顯示。

選項: 恢復原有標誌，之後唔會選取任何檔案。

預設值: null

影響: 原有重設會清除所選檔案，並以 null 通知標誌接收端。

例子: 試完節日標誌後重設。

驗證: 只可透過原有重設控制項及目前權限執行。

復原方法: 重新選擇本機圖片建立自訂標誌，重設本身冇獨立備份。

## 失敗、安全及驗證

被阻擋、停用、已移除或冇記錄接收端嘅控制項唔會執行指引操作。接收端拒絕、儲存失敗同無效圖片會保留失敗狀態，唔會顯示成功。標誌只喺本機轉換成平面化 PNG，冇網絡讀取。移除編輯器會取消指引及移除事件監聽。來源消費端測試唔代表瀏覽器、已安裝版本或視覺驗收。
