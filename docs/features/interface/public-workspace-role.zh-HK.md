# 公開說明工作區角色

公開瀏覽器工作區會先開啟說明文件，提供說明、更新記錄、偏好設定、本機存取、狀態，以及獲授權轉換工具和本機模型工具。加密磁碟檔案瀏覽、匯入、開啟、匯出、離線操作、掛載、同步及鎖定由已安裝程式負責，此頁面不提供這些操作。

## 用戶端連接界線

瀏覽器連接層只接受明確清單內的個人化、狀態、轉換及本機模型功能要求。主要磁碟操作和不支援的功能範圍會在讀取連線狀態或發送網絡要求之前被拒絕。已安裝程式的伺服器 API 不變。配對仍需本機迴路位址、一次性代碼及桌面程式明確批准。中斷連線會清除憑證及本機工具畫面。

## 確認及頁面生命週期

取代輸出、刪除模型及刪除對話使用共用頁面內雙鍵確認及完整滑桿。需要輸入指定文字或模型名稱的操作仍須完全相符。最後選擇「確認」才會批准。呼叫端未實際執行操作之前，不會顯示操作完成或「完成」狀態。開啟或取消確認框不會批准操作。時段失效及每次離開頁面都會取消待批確認，快取頁面會取得新的確認控制器。其他工作流程的共用實際執行模式不變。

瀏覽器快取導覽會清除配對及私人用詞，同時保留可用的文件控制。一般離開頁面會釋放工具、計時器、觀察器及共用控制。舊有 Files 分頁會從開啟及還原清單移除，其他分頁、群組及通知狀態保留。

## 驗證

針對行為檢查涵蓋發送網絡前拒絕、保留配套功能、真實雙鍵及滑桿操作、指定文字不符、取消、頁面結束及舊分頁遷移。伺服器檢查繼續覆蓋已安裝程式的 API。來源檢查不代表已驗證建置瀏覽器版面、實際配對、本機工具或部署結果，這些仍須獨立驗證。

## 配對偏好設定及功能限制

外部時間表讀取會把所選來源及穩定時間表識別碼傳至已安裝主機。配對後可讀取已安裝字型名稱。共用模式每五秒讀取一次，避免重疊要求；已中斷或更換連線的舊回應不會更新偏好設定。相同狀態不會重複建立歷史記錄。

Home Assistant 憑證儲存及清除、原生字型詳細資料掃描、原生圖片正規化及模型連接埠設定仍只限桌面程式。瀏覽器不會擴大任何允許清單。請在已安裝程式設定這些功能；瀏覽器圖片正規化沿用本機工作執行緒。瀏覽器不會讀回憑證值，連線畫面會列明限制。

設定指引會在內建文件閱讀器開啟相關文章及概念，並登記指令。修剪歷史須先通過本機驗證及解鎖私人歷史，再完成雙鍵及完整滑桿確認，實際修改時再次驗證。授權失效會取消待批確認。導覽及已開啟工作分頁保持固定，只有所選內容捲動。新設定檔只開啟說明文件，使用其他目的地時才建立工作分頁。
