# 伺服器管理基礎

呢個單元提供官方 Java 版本探索、指定版本嘅伺服器發佈中繼資料解析、綁定來源嘅設定描述、類型化設定控制項，同明確列出四種目標嘅能力清單。獨立內部本機程序轉接器而家提供有條件嘅建立同生命週期操作，但未接入產品介面。驗證期間冇執行真實伺服器或接受真實授權。類型、容器同 SSH 目標、設定同插件喺下面嘅受管伺服器一節描述；現有伺服器接管仍然不可用。

## 版本目錄及來源

`refreshJavaCatalogue` 會讀取 Mojang 完整官方版本清單，設十秒逾時、四 MiB 回應上限、HTTPS 來源限制，同拒絕重新導向。所有回傳版本都會保留，包括歷史渠道。重複身份、缺少最新版本項目同不可信中繼資料網址都會被拒絕。快照會記錄精確來源 SHA-256 同擷取時間。`catalogueState` 會分辨現行、過期、離線同不可用快照；離線唔等於現行。

`resolveJavaDistribution` 會先按版本清單嘅 SHA-1 驗證指定版本中繼資料，再讀取專用伺服器項目。缺少伺服器下載會明確標示不可用。如果官方中繼資料冇列出執行環境，歷史 Java 執行環境要求會保持未解析。已解析下載會記錄網址、SHA-1 同大小，但唔會聲稱已驗證下載位元組、已安裝、已驗證執行，或者已取得 EULA 同意。完整官方歷史 Bedrock 發佈目錄仍然不可用，現行下載頁填補唔到呢個缺口。

## 設定及目標界線

描述必須包含版本類別、精確版本、已驗證發佈 SHA-256、官方來源修訂、說明、權限、持久化使用者同即時或重新啟動語義。布林值對應開關、列舉對應可搜尋選擇器、數字對應有界數值控制項，文字對應文字控制項。呈現器由擁有者提供本地化文字同真實動作回呼。未知擴充設定會原封不動保留；編輯未知擴充內容需要真實描述。呢度冇提供通用 JSON 或 shell 編輯器。

本機程序、本機容器、SSH 程序同 SSH 容器分別列出身份同權限證明要求。本機程序生命週期有內部有條件實作，但仍然不可用及未驗證；其餘三種執行目標只由下面描述嘅受管伺服器服務實作，而且測試只用注入嘅假物件。連線中斷絕對唔可以當成伺服器已停止。

## 內部本機程序轉接器

`LocalProcessServerAdapter` 會建立全新專用根目錄，以串流取得有上限嘅官方發佈檔，驗證精確大小同 SHA-1，記錄 SHA-256，然後只發佈已驗證位元組。建立失敗或取消會保留持久化未就緒狀態同專用暫存資料，留待復原。現有根目錄絕對唔會覆寫。授權狀態由 `eula=false` 開始；寫入 `eula=true` 必須有明確同意，綁定精確伺服器身份、版本、發佈雜湊同官方 EULA 網址。測試只會模擬呢個契約，唔會接受真實伺服器授權。

啟動預設仍然不可用：可信主機必須提供已驗證相容 Java 執行檔及雜湊，同綁定版本嘅本機回送設定、支援屬性結構及可用連接埠證明。呢啲服務必須由真實受保護提供者供應，絕對唔可以信任呈現器自行聲稱已驗證。完成非同步批准後，會喺可信原生拒絕寫入及刪除檔案租約保護兩個精確檔案期間，重新檢查發佈同執行環境位元組。租約提供者預設不可用，必須保留真實原生 handle 直到專用程序退出；一個布林聲稱或者重新雜湊本身唔係原子檔案固定。假程序測試冇執行原生租約實作，亦冇證明呢個原生保證。釋放租約失敗會保留擁有權物件、阻止新啟動，並記錄需要復原狀態。准入、釋放同持久化錯誤會一齊保留；釋放失敗後仍然會嘗試持久化。單憑程序錯誤唔會釋放租約或丟棄子程序物件，真正退出結算最多只會釋放一次。發佈前取消啟動唔會留下設定；較後取消會記錄已生成設定，只有專用位元組保持不變，先可以重新嘗試。啟動唔會經 shell，亦會隱藏。JVM 會用 `-Xmx512M`；呢個唔係完整原生程序記憶體或 CPU job 界線。預設 `windowsProcessIdentity` 透過有界原生程序查詢讀取精確 PID、建立時間同執行檔路徑。轉接器亦會保留自己嘅子程序物件，身份失去驗證時會停止放行。

正常停止只會向已驗證專用程序寫入 `stop`，喺有界逾時內等候，絕對唔會強制終止。生命週期狀態寫入會依次進行，防止較舊執行快照覆蓋後來退出狀態。程序啟動唔等於伺服器就緒，就緒狀態仍然未驗證。重新啟動及復原接管、完整資源或 job 限制、儲存容量准入、完整記錄及狀態協定、GUI 授權控制項、原生 IPC 或提供者整合同真實伺服器驗收仍然待完成。新轉接器工作階段唔可以靜靜接管已持久化程序或根目錄。其餘三種目標由下面嘅受管伺服器服務處理。

## 類型、四個目標、插件同設定

`src/main/server-targets-service.js` 入面嘅受管伺服器服務同上面已驗證下載準備流程分開。佢嘅伺服器用自己嘅識別碼 `managed-<uuid>`，並經同一個主機派發入口使用。佢可以喺四個目標上面準備、啟動、停止、回報狀態、讀取日誌尾同取消伺服器：本機進程、本機容器、SSH 進程同 SSH 容器。所有外部進程同網絡呼叫都係注入嘅，所以測試用假物件。

類型：`src/features/server-manager/flavors.js` 讀取官方公開 API。包括 Vanilla 用 Mojang 版本中繼資料、Paper 用 `api.papermc.io/v2`、Purpur 用 `api.purpurmc.org/v2`、Fabric 伺服器啟動器用 `meta.fabricmc.net/v2`、Forge（由 Minecraft 1.18 起）用 Forge 推廣檔同 `maven.minecraftforge.net`，以及 NeoForge 用 `maven.neoforged.net`。請求只限 HTTPS、限定精確主機（包括重新導向），而且有大小同時間上限。完整性按來源實際提供嘅資料如實回報：Vanilla 有 SHA-1 同大小、Paper 有 SHA-256、Purpur 只有 MD5 而且標示為較弱、Forge 同 NeoForge 有旁邊嘅 SHA-256 或 SHA-1 校驗檔（如果存在），Fabric 啟動器就完全冇雜湊。冇雜湊嗰陣，結果會寫 `unverified-upstream`，並改為固定已收位元組自身嘅 SHA-256；冇驗證過嘅嘢絕對唔會講成已驗證。Forge 同 NeoForge 提供安裝程式，安裝程式先係已驗證嘅檔案，並用文件記載嘅 `--installServer` 參數執行一次；完成後嘅伺服器本身並冇獨立驗證。

目標：本機進程用系統 `java` 運行，帶記憶體上限同擁有權標記 `-Dmfe.server=<id>`，正常停止係向控制台寫 `stop`，絕對唔會強制終止進程。本機容器透過 `docker` 用參數陣列運行，用官方 `itzg/minecraft-server` 映像（由映像自己下載類型，所以桌面驗證唔到，結果會寫 `delegated-to-image`），或者用 `eclipse-temurin` 加上以唯讀方式掛載嘅已驗證 jar。連接埠只公開喺 `127.0.0.1`，停止同狀態只會處理 `mfe.server` 標籤相符嘅容器。SSH 進程同 SSH 容器用系統 `ssh` 執行檔同參數陣列，帶 `BatchMode`、`StrictHostKeyChecking=yes`，並且關閉密碼驗證，所以主機金鑰必須預先已受信任，亦永遠唔會用密碼。遠端指令係由固定範本砌成嘅單一字串，只含白名單同單引號包住嘅值；已驗證 jar 經連線串流上傳，遠端 SHA-256 必須同本機一致。金鑰檔案喺原生檔案選擇器揀；主程序保留路徑，呈現器只會見到不透明嘅 `key-<uuid>` 同檔案名稱。冇金鑰就用 ssh-agent。

授權：準備階段寫入 `eula=false`。喺原生對話框接受確實授權之前，啟動會被拒絕，之後先會將 `EULA=TRUE` 交畀容器映像。

設定：`src/features/server-manager/server-properties.js` 定義可編輯嘅鍵同佢哋嘅類型同範圍，例如連接埠、伺服器訊息、最多玩家、難度、遊戲模式、正版驗證同視野距離。RCON、綁定位址、世界名稱同資源包鍵都唔可以編輯，註解同未知鍵會逐位元組保留。

插件同模組：`src/features/server-manager/extensions.js` 用 `api.modrinth.com/v2` 處理插件（Paper、Purpur）同模組（Fabric、Forge、NeoForge）。只有 API 發佈咗 SHA-512、下載主機係 `cdn.modrinth.com`、大小喺 128 MiB 以內而且收到嘅位元組相符，檔案先會安裝。喺原生檔案選擇器揀嘅 jar 會連同本機計算嘅 SHA-256 安裝，並標示為未對照發佈者驗證。安裝需要伺服器處於停止狀態。

Java 要求：準備伺服器嗰陣，`resolveJavaRequirement`（位於 `src/features/server-manager/flavors.js`）會讀取 Mojang 版本中繼資料嘅 `javaVersion.majorVersion`，並以 `javaMajor` 連同伺服器一齊儲存（`javaSource` 記錄係 `mojang` 定 `table`）。Paper、Purpur、Fabric、Forge 同 NeoForge 都係行 Mojang 嘅版本，而且佢哋嘅公開 API 都冇發佈更嚴格嘅數值，所以 Mojang 嘅數字適用於所有類型。如果讀唔到中繼資料，就會用 `requiredJavaMajor` 入面記載嘅版本對照表，包括 26.1 及之後呢類以年份命名嘅版本需要 Java 25，來源會顯示為 `table`。每次啟動之前，桌面程式都會拿呢個數字同實際會用嘅 Java 比較：本機進程用本機嘅 `java -version`，SSH 進程就經 SSH 執行 `java -version`。如果搵唔到 Java 或者版本太舊，啟動會喺啟動任何嘢之前被拒絕，訊息會用英文、廣東話或者雙語講明需要同搵到嘅主要版本。拒絕之後卡片會停喺 `failed`，並顯示例如「需要 Java 25」嘅原因籌碼，換咗夠新嘅 Java 之後再啟動就會清除。容器目標用同一個數字揀映像：掛載 jar 用 `eclipse-temurin` 執行環境映像，官方映像模式用對應嘅 `itzg/minecraft-server` 標籤。

失敗狀態：伺服器消失之後，卡片唔會繼續停喺 `running`。本機進程會即時回報自己結束；容器經 `docker inspect`（狀態同結束代碼）檢查，SSH 進程就檢查 pid 是否仍然存在，只要有任何卡片仍然運行，兩者都會每隔幾秒輪詢一次，手動更新狀態都會做同一個檢查。按要求停止，或者以代碼 0 結束（例如遊戲內嘅停止指令），會變成 `stopped`；其他結束方式會變成 `failed`，並附上已知嘅結束代碼或者訊號、放喺 `errorCode` 嘅原因，同放喺 `lastLines` 嘅最後 20 行日誌，卡片會喺原因籌碼下面顯示。Windows 以無號 32 位元數值回報嘅結束代碼會轉成有號數字顯示（`4294967295` 會顯示為 `-1`）。常見嘅異常代碼會顯示易讀原因而唔係光禿禿嘅數字：`crashed`（「意外終止」）同 `terminated`（「被其他程式終止」）；數字代碼仍然保留喺次要嘅「結束代碼」一行。結束只會喺輸出管道讀完之後先回報，所以 `lastLines` 一定係結束前嘅最後幾行，由舊到新排列，包括結束事件之後即刻到嘅輸出。再次啟動失敗嘅卡片會清除失敗記錄。

關閉視窗：普通關閉只會隱藏視窗，磁碟機繼續留喺系統匣。第一次發生時會顯示一次性、唔會阻擋操作嘅系統匣提示（`src/main/tray-notice.js`），講明程式仍然運行同點樣結束；設定檔入面嘅標記檔會防止重複顯示。要完全結束，請按 `Ctrl+Q`，或者喺「說明」或「設定」選單、新分頁選單、指令面板揀「結束」，或者喺系統匣選單揀「結束」。當受管理伺服器處於 `starting` 或者 `running`，關閉會改為詢問你係保持喺系統匣運行、停止伺服器並結束，定係取消，由 `src/main/window-close.js` 處理。每個結果都睇得到，唔會被靜靜雞丟棄。結束時本機進程伺服器會用主控台 `stop` 指令停止；容器同 SSH 伺服器喺桌面程式結束之後會繼續運行，對話框亦會講明。

介面：`src/renderer/features/server-manager/targets-panel.js` 係準備控制項下面嘅面板。有顯示真實可用性嘅目標選擇器、只喺要求時先載入嘅類型同版本選擇器、狀態籌碼、日誌、設定表格同插件安裝，支援英文、廣東話或者雙語，並使用共用動態 token 同減少動態嘅後備。

驗證：執行 `node --test test/server-targets-service.test.js test/server-flavors.test.js test/server-launch-plans.test.js test/server-properties-and-extensions.test.js test/server-managed-adapters.test.js test/server-targets-panel.test.js`。呢啲測試只用假進程、Docker、SSH 同網絡。冇真實伺服器、容器、SSH 主機、Java 執行環境、Docker 守護程式或者下載參與，面板亦未喺已建置應用程式擷取，所以呢一節所有內容都只係用合成測試資料驗證。

## 整合交接

只可以將目錄模組匯入可信主機層，並提供明確更新同擁有者快取持久化。唔好向呈現器暴露任意擷取網址。啟用編輯之前，設定描述必須綁定實際已驗證發佈，同已生成或按版本審核嘅預設值。透過現有本地化介面掛載 `mountConfigurationControls`，並提供既定權限、確認、持久化同歷史動作。登記表及導覽、控制項上方自選引導、完整文件及說明、結構化集合控制項、原生 IPC、授權、執行生命週期、擴充套件同實際呈現驗收，仍然屬於整合或後續實作工作。呢個單元冇改動共用登記表或導覽檔案。

執行 `node --test test/server-manager.test.js`。呢啲測試證明來源行為同反向清單及設定檢查，唔代表已安裝伺服器或 GUI 驗收。
