# 公開文件頁面控制

首頁、文件總覽、文章、分類索引、維基同畫面紀錄集會直接掛載共用 Material 控制。呢啲控制只操作公開內容同訪客偏好設定，唔會開啟保險庫、掛載磁碟或執行本機程式操作。已連線瀏覽器工作區係另一個獨立介面。

## 導覽同搜尋

首頁章節使用可儲存嘅分頁，支援關閉、還原、固定、排序同群組操作。每份文件都有獨立瀏覽器儲存範圍，文章唔會覆寫另一頁嘅分頁選擇。Ctrl+Shift+F 開啟指令面板，可前往內容或聚焦實際偏好控制。

內容搜尋同偏好搜尋各自提供貼近欄位嘅完整正則表達式工具。預設使用純文字。表達式喺獨立 worker 執行，限制字數、測試內容同運算時間。無效或逾時狀態會顯示喺原有欄位，搜尋內容唔會傳送到伺服器。

## 偏好同私隱

英文同廣東話趣味程度各自為 1 至 5 整數，兩者預設為 5，並可以獨立重設。舊有成功／搜尋訊息分類唔會被當成語言選擇。遷移保留語言同表情符號設定，兩個新語言值則設為 5。任何程度都保留事實，包括錯誤同警告。

通知中心將訪客訊息儲存在該文件範圍，支援篩選、已讀狀態、移除同 JSON／CSV 匯出。首頁從 site-provenance.json 讀取建置版本同時間。資料缺失會明確顯示無法取得，唔會使用開頁時間代替。

外殼可以接收已驗證嘅共用 School 設定，抑制受限制控制、指令結果同翻譯，並保留原有選擇。靜態瀏覽器無法直接讀取桌面受保護共用記錄。訪客個人化同存取元件提供瀏覽器本機設定及驗證邊界；跨桌面程式同步需要另外建立橋接。選擇用詞檔案本身唔代表已通過驗證。

已驗證而未套用嘅用詞檔案，如果認證後加密失敗，仍然保留供重試；介面會顯示錯誤，唔會套用部分用詞。認證同取代操作分開管理。清除同加密儲存使用同一把瀏覽器寫入鎖；認證還原用詞前會先等候已排隊嘅清除完成。

## 驗證

針對檢查涵蓋預設值、遷移、兩種語言獨立程度、嚴肅模式、文件狀態隔離、必要元件註冊同產生頁面深度。刻意移除必要來源邊界會令檢查失敗。實際建置頁面操作、窄版面檢查、畫面擷取同部署讀回仍然需要獨立驗證。

## README 圖表同已檢閱公開證據

發佈目錄明確包括 `README.md`。原有三幅流程圖喺暫存時轉成本地可存取 SVG，保留宣告節點、箭嘴同來源文字。只支援 README 有界子集：`flowchart LR` 或 `flowchart TD`、引號節點標籤同有方向箭嘴。不支援語法會以 `UNSUPPORTED_README_FLOWCHART_SYNTAX` 失敗，唔代表一般 Mermaid 支援。標籤保留正常可讀大小，放喺具名稱、鍵盤可聚焦捲動區域，窄畫面亦一樣。瀏覽器像素、溢出同互動仍需實際呈現證據。

只有兩個已檢閱 JSON 從已追蹤公開來源發佈：`docs/evidence/main-performance-20261012.json` 同 `docs/evidence/hosted-update-1344-20261012.json`。已凍結允許清單綁定正規化內容雜湊同確切路徑。已改動、過大或未檢閱內容會拒絕。附近證據檔案同私人輸出永不枚舉或複製。文章內部連結會指向已交付檔案。效能、舊控制器資料、下載套件位元組同已安裝驗收仍有獨立結果。
