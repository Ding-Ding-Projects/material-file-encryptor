# 瀏覽器本機訪客存取及私人記錄

訪客轉接層會喺文件網站掛載現有本機存取工作區，提供本機設定登記、驗證及鎖定。驗證成功後先開放共用驗證器及便利鎖控制，設定鎖定時亦會鎖定私人記錄。呢個設定同桌面磁碟、伺服器帳戶、電郵或連線配對無關。

## 登記及驗證

輸入本機設定密碼，再選擇「建立本機設定」。之後每次開啟都由鎖定狀態開始，輸入密碼並選擇「解鎖本機設定」。登出、離開網頁或其他同源分頁改動相關資料時都會鎖定。錯誤密碼唔會啟用驗證回呼或私人用詞，原有共用密碼等候機制仍然適用。

共用設定完成密碼驗證及快取金鑰衍生後，外殼先會收到 `onAuthentication(true)`。外殼須將狀態傳畀現有私人用詞載入器，鎖定則立即回報 `false`。轉接層冇提供任何私人用詞或預設替換資料。

## 受保護儲存

瀏覽器憑證轉接層只明文保存第 2 版加鹽密碼驗證值。驗證器秘密、鎖記錄、模式解鎖驗證值及私人記錄驗證值，都經共用 AES-GCM 設定金鑰加密。密碼驗證及快取金鑰採不同用途，使用 310,000 次 PBKDF2。每筆密文綁定自身識別，原始密碼唔會儲存。記錄名稱及設定驗證值屬可見中繼資料，密文仍有被離線猜密碼的風險。

憑證寫入須有瀏覽器 Web Locks 或明確提供的等效服務。唔支援時會清楚報告，唔會改存明文。每個已驗證時段會綁定登入所用的確實驗證記錄，受保護操作會核對持久儲存中的身分。寫入會喺寫鎖內，於非同步加密前後再次核對。即使儲存事件延遲，舊分頁亦唔可以喺設定移除或取代後重新建立密文。設定鎖定或重設亦會取消尚未完成的寫入。明文記錄上限為 256 KiB，讀取儲存封套上限為 2 MiB。呢個係本機儲存加密，唔能夠防禦同源惡意程式、已被入侵的瀏覽器或已解鎖時段的存取。

私人記錄採現有共用管理器，另設記錄密碼，其驗證值再由設定加密保護。記錄使用認證加密及經檢查的雜湊鏈，快照略去憑證、秘密及私人用詞欄位。鎖定設定亦會鎖定記錄。個人化介面須接收轉接層的 `historyManager`、`historyCredentialStore` 及驗證狀態，單獨掛載轉接層唔代表已完成接線。

## 驗證器、便利鎖及支援

共用工作區提供真正的本機 TOTP 登記、驗證碼確認及產生、QR 匯入及顯示，以及便利鎖。剪貼簿同鏡頭操作仍受實際瀏覽器權限及 API 限制，缺乏能力時會報告無法使用。秘密只會喺設定驗證後載入。鎖定會銷毀並重新掛載工作區，以清除記憶體內驗證器項目及敏感欄位。便利鎖只控制介面動作，唔會加密文件，亦唔能夠阻止同源程式改動控制項。

支援單只限今次使用，可經共用工作區建立、編輯、選取及明確匯出。唔會提交到伺服器，鎖定或關閉網頁會清除清單。分享匯出描述之前請先檢閱。訪客介面已移除桌面資料夾動作。

## 復原及破壞性重設

忘記設定或記錄密碼後，無法復原加密內容。請清除此瀏覽器對呢個網站的儲存資料，再建立新設定，冇電郵或伺服器重設。清除整個來源的瀏覽器資料亦會移除其他偏好。

「重設訪客記錄」只移除本轉接層的設定、驗證器、鎖、等候狀態及私人記錄命名空間，保留其他瀏覽器鍵。操作採現有真正破壞性確認流程：啟用兩個確認開關、把滑桿移至 100%，再選擇執行。執行前取消或緊急離開唔會改動記錄。完成後會保留「完成」控制，關閉確認後先重建鎖定登記介面。如工作區已被銷毀後因缺少 Web Locks 或儲存例外而重設失敗，關閉確認亦會重建可用的鎖定設定控制，並保留原有錯誤。部分儲存失敗唔會被報成已移除所有記錄。

## 整合及驗證界線

`mountVisitorAccess(container, options)` 回傳 `authenticated`、`credentialStore`、`historyCredentialStore`、`historyManager`、`credentialCapabilities`、`lock`、`refresh`、`setLanguage`、`openLockWizard`、`bind`、動作保護轉送及 `destroy`。選項包括 `storage`、`foundation`、`onAuthentication`、`onHistoryAccess`、`language`、`schoolMode`、`withLock`、`confirmDestructive`、`notify` 及 `eventTarget`。`onHistoryAccess` 接收 `{ authenticated, historyManager, historyCredentialStore }`。模式密碼只可喺本機設定驗證後設定及核對，唔會虛構原生鑰匙圈或遠端排程服務。

`encryptPrivateCache(value, purpose)` 及 `decryptPrivateCache(envelope, purpose)` 只轉送已驗證共用設定的加密能力，唔會暴露金鑰。有界用途字串會參與認證加密，操作回傳前亦會核對持久設定身分。公開載入器可用呢啲方法保存獨立的加密用詞快取封套；鎖定必須還原原有用詞並丟棄解密狀態。轉接層唔會儲存未加密用詞內容。

針對性測試涵蓋共用設定控制、加密憑證持久化及竄改拒絕、獨立記錄驗證及略除敏感欄位、跨分頁鎖定、取消待寫入操作，以及真正雙開關滑桿流程。呢啲係使用共用 DOM 測試環境的行為驗證，唔代表瀏覽器佈局、無障礙、剪貼簿、鏡頭、部署或桌面磁碟驗收。公開外殼接線及部署後執行驗證仍須分開完成。
