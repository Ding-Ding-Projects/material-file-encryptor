# 封存檔同結構化資料轉換器

內置轉換器同 PDF 轉換使用同一個 AppContainer。呢啲格式唔會靠外部執行檔、PATH 搜尋、服務或者下載套件啟用。

## ZIP

`zip-list`、`zip-extract` 同 `zip-repack` 接受一個 ZIP 檔。列出內容會匯出 JSON 項目索引；解壓需要已批准嘅目的地目錄授權，並保留相對路徑。重新封裝支援未壓縮同 Deflate 項目，會重新開啟輸出封存檔作驗證，逐項比較名稱同位元組序列。

只支援名稱使用 UTF-8 或 ASCII 嘅未壓縮同 Deflate 項目。加密封存檔、ZIP64、多卷、符號連結、特殊檔案、不安全路徑、不分大小寫嘅重複名稱、檔案／目錄衝突、錯誤 CRC、重疊內容同未支援壓縮方法都會被拒絕。上限係 1,000 項、每項解壓後 16 MiB、總解壓內容 64 MiB、100:1 解壓比例、16 層路徑同每個名稱 240 個 UTF-8 位元組。整體輸入上限仍然係 64 MiB。呢啲保守限制會刻意拒絕部分本來有效嘅封存檔。

發佈輸出之前會檢查所有目的地路徑。目錄解壓絕不取代現有檔案，父目錄亦唔可以經符號連結或者 junction 重新導向。每個輸出都以原子方式發佈；發佈期間如果有外部程式同時寫入，後續輸出仍然可能停止，屆時會列出已完成嘅輸出名稱。來源檔案唔會改動。封存檔註解、額外欄位、權限同未支援中繼資料唔會還原或保留；解壓同重新封裝都需要確認相關披露。

## CSV、TSV 同 JSON 表格

六個方向係 CSV／TSV 轉 JSON、JSON 轉 CSV／TSV、CSV 轉 TSV 同 TSV 轉 CSV。JSON 表格係由字串陣列組成嘅長方形陣列。標題只係第一行普通字串，唔會猜測數值、日期、布林值或者公式。

CSV 可以用逗號、分號或者 tab 分隔；TSV 使用 tab。支援引號內分隔符號、內嵌 CR／LF、雙引號轉義、空白儲存格、空白行同只有標題嘅文件。輸出換行可以係 LF 或 CRLF。必須使用嚴格 UTF-8，移除 BOM 亦會披露。錯誤引號、唔一致行寬、JSON 儲存格唔係字串、無效 Unicode 同超出資源上限都會被拒絕。每個輸出都會重新解析，再同預期表格比較。

上限係輸入／輸出 16 MiB、100,000 行、1,024 欄、1,000,000 個儲存格同每格 1 MiB。試算表應用程式可能執行似公式嘅字串。介面會明確提供三種處理：拒絕呢啲儲存格、保留並警告，或者加上單引號並報告改動格數。預設係拒絕，轉換亦需要確認披露。

XLSX、ODS、7z 同 RAR 仍然會清楚顯示為不可用。分隔文字支援唔會被描述成完整試算表引擎。
