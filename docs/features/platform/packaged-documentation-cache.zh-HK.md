# 已封裝文件目錄重用

主程序將 `app.isPackaged` 當作可信輸入。只有呢個明確決定先啟用目錄同更新記錄要求共用一次延後讀取及解析。睇落似封裝嘅路徑唔會啟用重用。開發環境每次讀取新內容。

已封裝 JSON 會深度凍結，讀取或解析失敗可重試；關閉會釋放保留參照，並拒絕未完成或之後嘅結果。現有要求驗證同退出准入保持不變。安裝另一版本需要新服務生命週期。保留解析目錄會用記憶體，但避免重複讀取同解析。

呢次主線基準調整唔包括較新嘅存取、瀏覽器或伺服器生命週期方法。專用測試涵蓋並行重用、修改拒絕、重試、開發環境新內容、不支援操作、讀取期間關閉同實際功能服務派送。來源 `187364a3094b1f66e5798d10991f2e3d09d40af9` 嘅八項專用檢查通過並獨立重跑，確切根目錄組建退出 0，生產位元組符合 ASAR。同一份 7,863,011 位元組抽出目錄，31 組交替樣本量到重新讀取中位數 17.3215 ms，重用為 0.0182 ms；並行中位數分別為 28.5182 ms 同 0.0065 ms。首次讀取、解析同凍結用 24.9591 ms。[精選公開證據](../../evidence/main-performance-20261012.json) 保留來源同輸入雜湊。呢啲係本地 Node 元件量度，唔包括 IPC 同原本 ASAR 存取。IPC、畫面速度、已安裝行為同可見驗收仍然分開。
