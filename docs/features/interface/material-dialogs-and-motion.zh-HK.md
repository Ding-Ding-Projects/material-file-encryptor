# Material 對話框、控制項同動畫

桌面應用程式入面嘅訊息框、控制項同畫面轉場，全部改用 Material Design 3 元件同動畫。呢篇講解改咗啲乜、點樣保持提示可信，以及邊啲已經驗證、邊啲未驗證。

## 訊息框

由應用程式程序發出嘅確認、同意同錯誤提示，而家以 Material 對話框顯示，唔再用作業系統訊息框。範圍包括瀏覽器配對、本機模型連線更改、伺服器授權審閱、排程憑證儲存、檔案匯入確認、關閉程式選擇同更新提示。選擇檔案同資料夾嘅視窗仍然用系統原生版本。

### 信任界線

- 每個提示都喺應用程式程序擁有嘅獨立模式視窗開啟，配備隔離嘅預載程式、沙盒同嚴格內容安全政策。
- 主應用程式視窗無法代答提示。只有該對話視窗、配合該提示專用嘅一次性數值、而且揀嘅係確實存在嘅按鈕，選擇先會被接受。
- 關閉視窗或者撳 Escape 等同揀取消按鈕。Enter 會啟動目前焦點所在嘅按鈕，焦點一開始停喺預設按鈕。
- 如果對話視窗無法建立，就改為顯示作業系統訊息框，同意提示永遠唔會被略過。

### 外觀

對話框冇作業系統邊框。標題以細字標籤顯示喺頂部，拖住佢可以移動視窗。前置圖示按提示類型顯示：資訊、問題、警告或者錯誤。

## 控制項

- 轉換器、本機模型同檔案詳情嘅分區切換，改用帶有作用中指示嘅 Material 分頁。
- 清除功能以尾端圖示按鈕形式放喺文字欄位入面。
- 下拉選單自帶標籤同說明文字，外框選單保留足夠闊度顯示標籤。
- 進度改用 Material 線性進度條。
- 展開區域改為帶旋轉箭咀嘅展開面板。
- 更新狀態以英文同廣東話文字解釋。應用程式唔認得嘅原因代碼仍然照原樣顯示。
- 文件目錄改為導覽抽屜樣式，並標示目前開啟嘅文章。
- 暫不可用嘅伺服器目標以停用清單顯示。

## 動畫

共用嘅 Material 緩動同時長標記控制畫面同分頁面板進場（淡出淡入）、卡片同表格列進場（向上淡入並輕微錯開）以及展開區域動畫。系統嘅減少動態效果設定會將以上全部關閉。

### 動畫規範

瀏覽器擴充功能頁面、桌面畫面、文件網站（包括原始頁面、產生頁面範本同暫存輸出）同設定檔驗證頁面共用同一份規範。每個互動元素都用 Material Web 元件，或者有記錄嘅狀態層，懸停、聚焦同按下都會經過渡改變。對話框、側邊面板、分頁面板、展開區域同狀態訊息進場時，都用共用標記 `--md-sys-motion-easing-standard`、`--md-sys-motion-easing-emphasized-decelerate` 同 `--md-sys-motion-duration-short4`，唔會直接寫緩動曲線。每個過渡同動畫都有 `prefers-reduced-motion` 覆寫。`scripts/audit-material-motion.mjs` 會靜態檢查呢份規範，而 `test/material-motion-audit.test.js` 要求零項發現。唯一允許嘅原生控制項係隱藏嘅檔案輸入、主頁目的地卡片同文件網站嘅無腳本基線標記，每項都喺程式碼入面列明原因。文件網站嘅例外只會喺 `scripts/audit-material-motion.mjs` 確認 `preparePublicDocumentControls` 會喺綁定任何監聽器之前，將每個原生控制項升級做已註冊嘅 Material 控制項時先被接受。由腳本建立嘅控制項直接用 Material Web 元件。`node scripts/audit-material-motion.mjs --site out/site` 會審核暫存網站，而測試亦會暫存一份並要求嗰度同樣零項發現。

### 執行時審核

`scripts/audit-runtime-motion.mjs` 會喺真正渲染出嚟嘅畫面上驗證同一份規範。佢透過 DevTools 協定驅動一個用完即棄嘅無頭 Edge 或 Chrome 設定檔，載入暫存嘅瀏覽器擴充功能、暫存嘅文件網站同桌面畫面（由原始碼提供，預載橋接用替身），並喺每個狀態執行 `scripts/runtime-motion-page.mjs` 入面嘅頁面端審核：

- 每個可見嘅互動元素（包括開放 shadow root 入面嘅元素）都會分類為 Material Web 控制項、有記錄嘅原生例外，或者發現項。位於 Material 元件自己 shadow root 內嘅部件，算係該元件嘅一部分。
- 每個互動元素都要有過渡、動畫、水波紋或者狀態層。超連結同展開摘要亦都要有過渡。
- 打開嘅對話框、選單、側邊面板同分頁面板必須有進場動畫，透過運行中嘅 Web Animations、CSS 動畫同過渡觀察。
- 模擬 `prefers-reduced-motion: reduce`，或者開咗應用程式內嘅動態或注意力設定之後，任何可見元素都唔可以仍然保留過渡或動畫，包括 Material Web shadow root 入面嘅元素。頁面樣式表去唔到呢啲 shadow root，所以 `src/shared/surface/reduced-motion.js` 會喺要求減少動態效果期間（媒體查詢、文件元素上嘅 `data-motion="reduced"` 或者 `data-low-stimulation="true"`），將一份細小嘅樣式表套入每個 `md-*` 元素嘅 shadow root，關閉減少動態效果時移除，亦涵蓋之後先加入嘅元素，並且即時完成 Material Web 用腳本啟動、有限長度嘅 Web Animations，例如按壓水波紋。瀏覽器擴充功能、文件網站同桌面畫面全部都會安裝。shadow root 入面嘅殘留動態會當作發現項計算，並列出所屬嘅 `md-*` 宿主。

執行時例外清單比靜態嘅短：隱藏嘅檔案輸入、`mfe-date-field` 同 `mfe-file-picker` 入面嘅平台選擇器輸入，以及主頁目的地卡片，每項都喺程式碼入面列明原因。文件網站唔需要任何例外，因為佢嘅基線標記喺審核讀取之前已經升級。先用 `node scripts/build-browser-extension.mjs` 同 `node scripts/build-site.mjs` 暫存，再執行 `node scripts/audit-runtime-motion.mjs --surface all --out receipt.json`。提交嘅收據 `docs/evidence/runtime-motion-<shortsha>.json` 按畫面記錄元素數量、發現項、進場探測同減少動態效果嘅結果。桌面畫面嘅執行係原始碼替身證據，並唔涵蓋已安裝嘅應用程式。`test/runtime-motion-audit.test.js` 會對靜態測試頁執行頁面端分類器，並要求冇過渡嘅原生按鈕被標記、Material 控制項通過。測試亦要求 shadow root 測試頁入面嘅殘留動態被標記，同埋共用輔助程式可以正確套用同移除佢嘅樣式表。

涵蓋範圍：瀏覽器擴充功能同桌面畫面會分別以英文（`en`）、廣東話（`yue`）同雙語（`bilingual`）模式審核，各自作為獨立畫面報告，例如 `extension/yue`。網站審核涵蓋每一個分類頁同每一個文章頁（亮色，寬度 1280 同 360 像素），兩者各抽樣一部分用暗色再審核，另外亦涵蓋 wiki 同工作區頁面嘅內部狀態：每個分頁、每篇 wiki 文章、展開摘要、wiki 搜尋，以及工作區第一份、中間同最後一份文件。`node scripts/audit-runtime-motion.mjs --surface all --without-shadow-reduction` 係負面對照，必須報告 shadow root 殘留動態。每個程序可以各自執行一個畫面並行審核，再用 `--merge a.json,b.json --out merged.json` 合併收據。

## 關閉程式

唯讀請求，例如讀取目錄、狀態同字型清單，唔會再阻止程式關閉。修改資料、傳輸同等待用家操作嘅工作，仍然會阻止關閉並顯示關閉選項。

## 語言

對話框文字會跟隨介面語言。廣東話模式下，標題、訊息、說明同按鈕都會以廣東話顯示；雙語模式下，每行會同時顯示英文同廣東話。有標籤嘅說明行只會翻譯標籤，所以檔案名、位址同其他數值會保持原樣。未有已審核翻譯嘅文字會保留英文，唔會靠估。

## 驗證

- 重點測試涵蓋對話框信任界線（包括一項如果唔執行一次性數值檢查就會失敗嘅測試）、更新原因文字同關閉程式嘅待處理規則。
- 喺隱藏桌面擷取已建置應用程式嘅畫面，顯示已轉換嘅畫面，以及一個真正嘅同意提示以 Material 對話框顯示，撳 Escape 取消後冇任何更改。
- 喺隱藏桌面擷取到對話框喺淺色同深色主題下嘅樣子，佢哋跟隨應用程式內嘅主題設定；憑證提示亦分別以英文、廣東話同雙語模式擷取，每次取消後都冇任何更改。
- 150% 以外嘅顯示縮放同其餘個別提示仍未擷取。
