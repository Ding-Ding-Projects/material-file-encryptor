# Shared desktop surface foundation

This module adds locally bundled Material Web 2.5.0 controls to the current desktop renderer. It does not replace the native encryption engine or acquire operating-system privileges. The host supplies all actions and save capabilities.

- [Integration and behavior](integration.md)
- [Current implementation and verification gaps](coverage.md)

The foundation exposes no HTTP API. A Postman collection is not applicable.
