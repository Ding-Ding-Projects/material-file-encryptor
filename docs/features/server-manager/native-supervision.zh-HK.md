# 受保護本機伺服器監督

桌面主程序透過現有私人原生主機通道，將檔案準備接駁生命週期監督。瀏覽器呼叫者唔可以使用呢項功能。呈現器請求只包含工作階段擁有嘅伺服器識別碼，唔可以選擇執行檔、根目錄、網址、連接埠、命令、提供者、摘要，或者授權同意布林值。

接受授權會開啟原生確認對話框，列出已準備伺服器嘅確實版本同發佈檔案 SHA-256。取消會保留 `eula=false`。只有對話框確認按版本綁定嘅授權合約後，先會儲存接受狀態。接受授權唔會啟動伺服器。

原生主機會喺已初始化工作階段根目錄下，登記已驗證伺服器位元組。原生生命週期操作會序列處理准入、登記、狀態、啟動、正常停止同關閉。同一個原生程序同時擁有 Java 子程序及拒絕寫入／刪除嘅檔案租約。正常停止會核對確實建立時間同執行檔身份，寫入 `stop`，再等候最多十秒。逾時會保留監督同租約，亦容許另一段有上限嘅觀察。流程唔會嘗試強制終止。父程序通道 EOF 會要求正常關閉；關閉仍未驗證時，原生主機會繼續保留。

## 目前准入限制

實際伺服器啟動仍不可用。所需嘅確實版本產生網絡設定證據尚未保留，因此原生設定准入一律拒絕放行。版本清單唔會被用嚟推斷 loopback 屬性結構、管理設定、就緒狀態或者歷史版本相容性。

執行環境探索只考慮已審核隨附嘅 `server-runtime` 清單，唔會使用 PATH、JAVA_HOME、呈現器指定執行檔或者未審核本機安裝。清單必須綁定 Java 主版本、執行檔 SHA-256 同 release 檔案 SHA-256。目前未隨附任何已審核執行環境清單。呢個實作唔會安裝執行環境或者自動接受授權。已安裝執行環境探索同可信套件取得仍待完成。

驗證模式同測試模式會明確停用生產原生回呼。合成測試核對受保護主程序接線、識別碼驗證、確實授權確認、取消、登記身份同設定不可用狀態。呢啲測試唔代表原生編譯、租約 IPC、子程序啟動、實際設定消費、就緒狀態或者正常執行關閉已驗證。本機程序支援要宣稱可運作之前，仍需要綁定候選版本嘅原生同真實執行環境證據。
