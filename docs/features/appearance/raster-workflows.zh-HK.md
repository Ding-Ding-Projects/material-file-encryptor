# 點陣群組同本機外觀修訂

## 目前實作

**Rasterize group** 將群組內有上限來源圖層合成獨立 512 × 512 PNG 畫面。巢狀群組會先獨立合成，再將透明度同混合模式套用到父群組。支援內容包括靜態 HEX 背景填色、已正規化 PNG、矩形／橢圓／多邊形／路徑遮罩、有序 canvas 濾鏡效果，同現有仿射變換。點陣化會拒絕未支援字型、通道增益、色域選取同其他 CSS 屬性；呢啲仍可經現有即時 CSS 編輯器使用。處理失敗後，之前有效模型保持生效。

**Embed immutable source** 保留深度凍結嘅來源圖層樹快照，外部變換同網格參數分開。**Restore embedded source** 從原始樹重新生成；**Detach embedded copy** 建立可編輯來源子圖層，唔改舊修訂嘅原始快照。格式係本應用程式有界圖層結構，唔係通用 Photoshop 或 SVG 文件匯入器。

**Triangle mesh warp** 提供 3 × 3 點網格同數值 X／Y 控制。四個格各拆成兩個三角形，以 canvas 仿射映射獨立渲染。重複改動從嵌入原始來源重新生成，唔會反覆扭曲之前結果。點範圍係 −100–200%，退化三角形會被拒絕。呢個係二維分段仿射變形，可能有取樣接縫，唔係三維變形模型。

命名顏色輸入喺現有數值色彩空間之外，接受 148 個 CSS 名稱同 `transparent`，唔分大小寫。反向讀值只有喺 alpha 亦相符時先包含全部精確別名。超出支援 sRGB 色域會被拒絕，唔會暗中裁切。

## 處理邊界

`mountAppearanceEditor` 接受 `normalizeImage({dataUrl})`，作為桌面隔離嘅可選主程序回呼。呼叫前先限制同檢查 PNG 位元組。回傳靜態 PNG 會再次檢查簽名、尺寸、位元組長度同中繼資料一致性。隔離不可用時，回呼必須拒絕，唔可以改喺渲染程序解碼原始圖片。

冇此回呼時，每次正規化／合成都由一個專用 module worker 使用 `createImageBitmap` 同 `OffscreenCanvas` 執行。佢冇 DOM 存取，移除環境網絡 API，並喺十秒後、取消、成功或失敗時終止。輸入上限仍係 4 MiB、每邊 4096 像素，同八百萬像素。合成上限每邊 1024 像素、128 圖層，同四層巢狀；介面使用 512 像素。正規化輸出上限 1 MiB。關閉或銷毀編輯器會中止活躍工作者工作。遲到結果唔可以取代較新編輯。

工作者隔離唔係獨立作業系統程序，亦唔係硬性程序記憶體配額。原生解碼安全仍依賴 Chromium。聲稱更強隔離之前，仍要有套件 AppContainer 主回呼驗證同真實渲染圖片檢查。PNG 標頭檢查唔係 CRC 驗證；成功解碼正規化會提供新 PNG。

每個編輯器只接受一項活躍圖片操作，包括自訂主程序回呼。工作者模組亦獨立限制每個渲染程序範圍最多一個活躍工作者。超額呼叫會即時以忙碌狀態拒絕，唔會喺介面背後建立不斷增長嘅背景佇列。關閉編輯器會中止活躍訊號。每個圖層、子合成、未扭曲來源同最終輸出完成後，都會重設 canvas backing store；失敗亦會作最後清理。呢啲限制唔包括未有文件記錄嘅瀏覽器解碼器配置。

## 持久本機修訂

每次成功外觀儲存，都先向本機儲存新增獨立修訂紀錄，之後先通知主程序或套用新外觀。有序索引將每個修訂連到前一個，現有紀錄絕不改寫。修訂面板重新載入紀錄，將選定快照還原為新修訂。圖片位元組會遞迴省略，包括嵌入來源，所以修訂還原唔可以恢復本機像素。介面會披露呢項限制。

本機日誌係已遮蔽瀏覽器儲存，唔係加密封存或者 Git 儲存庫。現有密碼保護主程序歷史保持獨立。上限係 2000 個紀錄，每修訂 2 MiB；達到上限會拒絕新儲存，唔會靜靜地刪舊紀錄。日誌寫入失敗會還原之前模型同復原／重做堆疊。如果儲存連回復都拒絕，編輯器會回報需要復原，阻止進一步儲存；`getPersistenceStatus()` 公開此狀態。應先匯出目前樣式，再重新載入，之後先繼續編輯。

復原同重做加埋嘅 UTF-8 快照資料上限係 16 MiB，另外保留原有項目數上限。最舊快照會移除，同時保留最近且符合限制嘅修訂。模型本身嘅 UTF-8 JSON 上限係 8 MiB。修訂讀取分頁，每頁最多二十項同 8 MiB。索引發佈失敗只會移除該操作新建嘅紀錄；移除失敗會回報需要復原。現有修訂同無關儲存鍵唔會刪除。

## 驗證狀態

專項測試涵蓋網格幾何同退化拒絕、工作者取消同終止、無效來源輸出、主回呼優先、不可變嵌入快照、巢狀畫面合成、路徑裁切保留、只追加持久化，同失敗回復。呢啲係來源／元件測試。新控制仍需要綁定套件互動同像素擷取；之前套件畫面唔證明呢份來源。

## 廣東話說明

「將群組轉成點陣預覽」會將支援嘅靜態填色、PNG 圖像、幾何遮罩、效果同變形合成獨立畫面。巢狀群組先各自合成，再套用透明度同混合模式。唔支援嘅文字或通道操作會明確拒絕，唔會靜靜地忽略。

「嵌入不可變更嘅來源」保留原始圖層快照。網格扭曲每次都由原始來源重新產生，唔會反覆扭曲上一次結果。三角網格係二維近似，可能有取樣接縫，唔係三維編輯器。

桌面主程式可以提供隔離解碼回呼。瀏覽器備用路徑使用獨立 worker，設有十秒時限、取消同輸入輸出限制，但唔等於獨立作業系統程序。實際安裝版本嘅隔離同像素效果仍然需要另外驗證。

本機外觀版本會逐項新增，唔會改寫舊記錄。還原會建立新版本。圖像像素唔會寫入版本記錄，所以版本還原唔能夠取回圖像。呢個係經刪除圖像資料嘅本機儲存，唔係加密備份或 Git 歷史。容量滿咗會拒絕新儲存；回復失敗會要求先匯出樣式再重新載入。
