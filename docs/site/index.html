02Credentials and securityChoose an unlock method and understand recovery+

Choose a password or a key file

A password or key file unlocks the vault. Keep your credential separately from the encrypted storage folder. Losing the credential can mean losing access to the encrypted files.

Understand automatic unlock

Starting with Windows and unlocking automatically are separate settings. Startup is enabled by default. Optional automatic unlock protects the saved secret using DPAPI for the current Windows user.

DPAPI is tied to the Windows user context. It is not a portable recovery method, and it does not protect files exposed through a drive that is already unlocked. Keep the original password or key file for recovery.

Concurrent edits

When devices change the same file concurrently, the engine preserves conflict copies instead of silently replacing one version. Review those copies to decide which changes to keep.

Know what encryption covers

The architecture encrypts stored file parts and the offline cache. When you open a file, its application receives decrypted content. That application may create its own temporary files or recent-file records. Encryption also does not confirm that a cloud provider finished uploading a change.

03Offline accessEncrypted caching, pinned files, and on-demand reads+

Pin the files you will need

The offline cache retains encrypted file bytes. Pinning is intended to keep the selected files available locally. Before disconnecting, every required encrypted part must have been retrieved successfully.

Protect pending changes

Dirty cache contains changes not yet published to the storage folder. Cache eviction preserves dirty, pinned, and open file data. An encrypted change saved locally is not confirmation of a completed cloud upload.

Open through the drive

Cached files remain encrypted on disk and become readable through the unlocked mounted drive. The design does not create a separate plaintext working folder.

If neither storage nor a complete local cache is available, the file cannot be read. Changes still need access to the appropriate storage path to be persisted and, where applicable, uploaded by your sync provider.

04Part sizes and resplittingPhysical file limits, encryption overhead, and existing files+

Set a physical part-size limit

Enter a custom number and choose a 1024-based unit. The default is 10 MiB and the physical maximum is 90,000,000 bytes including encryption overhead. Each file has its own fixed ciphertext chunks, with a shorter final chunk. This is not a maximum size for the original file.

History and deleted files

Encrypted snapshots use real Git history. Save versions manually or after 30 seconds without writes to a file. History defaults to forever; changing the restore-list period does not erase stored history. The Recycle Bin supports restore and empty actions. Emptying the Bin retains historical recovery and does not promise reclaimed storage. Existing vaults use an explicit verified copy upgrade.

Apply changes intentionally

The current limit applies to newly created or edited files. Changing the setting does not rewrite files that are already stored. Use the explicit Resplit action to recreate existing encrypted parts with the new limit.

Resplitting can require additional local space and can cause your sync provider to upload replacement encrypted parts. Wait for the operation and any provider upload to complete before relying on another device’s copy.

05 / A few useful answers

Before you begin.

Do I need a cloud account?+

No. The storage folder can be local. OneDrive and Google Drive are examples of services that can synchronize the encrypted folder; the design does not depend on either provider.

Is this website the encryption app?+

No. This is the project’s public website. The application is a separate Windows desktop program. The website cannot open, unlock, or encrypt a vault.

Does encrypted mean uploaded?+

No. Encryption describes the stored file contents. Your sync service manages cloud upload and reports its own progress, errors, and conflicts.

Can I download a verified release?+

A verified Windows release is not available from this page yet. Follow the source repository and check GitHub Releases for the project’s current published artifacts.
