# 由瀏覽器要求本機轉換

連線工作區提供來源、格式、檢閱同工作步驟。先配對，再喺桌面選擇器揀來源，載入已驗證目錄，揀相容格式，最後喺桌面揀輸出同確認。瀏覽器只會收到不透明選擇識別碼、偵測類型同位元組數。檔案名稱、路徑、內容、預覽、雜湊同登入資料都留喺原生服務。

## 目前轉換器邊界

今次增量支援四個固定選項轉換器：`json-format`、`text-utf8`、`base64` 同 `hex`。只有現有原生服務確認內置轉換器同已驗證作業系統隔離可用，格式先會啟用。所有目錄類別仍然顯示可搜尋清單。其他轉換器因瀏覽器選項未支援而明確停用，原生未可用轉換器亦保持停用。今次增量唔代表通用轉換器要求、PDF 操作、其他格式選項、批次揀選或者輸出開啟及匯出控制已完成。

檢閱會說明所選格式嘅編碼同中繼資料行為。原生確認會顯示確實來源同目的地，並再次交代變更。來源保持不變，輸出唔會覆寫現有檔案。現有轉換器會進行有界限嘅位元組偵測、來源重新驗證、容量檢查、隔離轉換、輸出驗證同原子發布。

## 接受、進度同取消

接受工作之前，原生服務會喺原子發布佇列記錄之前即時檢查有效瀏覽器權限。呢個邊界之前撤銷權限，工作就唔會加入佇列。接受之後，持久工作由桌面管理，即使瀏覽器中斷連線或者回應遺失，工作仍會繼續。短暫連線到期唔會撤銷已接受工作。

工作頁每頁最多顯示 20 項，按原生產生並綁定配對連線嘅擁有者識別碼篩選。分頁逐筆讀取持久佇列，唔會將全部工作保留喺瀏覽器記憶體。重新讀取會顯示真實狀態同原生粗略進度，唔會估計完成。暫停、恢復同取消需要明確原生確認，亦會檢查同一擁有者邊界。原生錯誤詳情同輸出名稱唔會轉送，失敗工作會提示使用者檢查桌面。

停止等候同中斷連線只取消待接受嘅瀏覽器要求，唔會取消已接受工作。如果接受後確認回應遺失，狀態會明確標示未確定，請檢查桌面。重新配對會建立新可見範圍，舊工作仍可以喺桌面歷史恢復。重新啟動後使用既有持久轉換佇列同受保護原生授權恢復，唔會用瀏覽器設定假裝恢復原生權限。
