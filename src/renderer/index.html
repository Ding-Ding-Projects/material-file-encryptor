A FAMILIAR WAY TO WORK

How it works

One drive. Encrypted underneath.

Unlock and mount a real Windows drive through WinFsp. Open files in Explorer and edit them with your usual apps. The drive decrypts requested data in memory and encrypts writes.

  1. Choose encrypted storage

    Use a folder on your computer or one managed by your cloud app. Your cloud app moves the encrypted files.

  2. Keep an encrypted cache

    Keep offline retains encrypted parts on this device. Remove offline copy releases unneeded cached data. There is no decrypted working folder.

  3. Lock when you are finished

    The drive unmounts before its keys are released. If an app is still using files, close those files and try again.

Export copy creates an ordinary decrypted file at the destination you choose. Other apps and Windows can also create their own temporary files or thumbnails.

Keep your password or key file safe. There is no password recovery.
