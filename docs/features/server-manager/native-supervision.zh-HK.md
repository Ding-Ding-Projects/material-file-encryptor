# 受保護本機伺服器監督

桌面主程序透過現有私人原生主機通道，將檔案準備接駁生命週期監督。瀏覽器呼叫者唔可以使用呢項功能。呈現器請求只包含工作階段擁有嘅伺服器識別碼，唔可以選擇執行檔、根目錄、網址、連接埠、命令、提供者、摘要，或者授權同意布林值。

接受授權會開啟原生確認對話框，列出已準備伺服器嘅確實版本同發佈檔案 SHA-256。取消會保留 `eula=false`。只有對話框確認按版本綁定嘅授權合約後，先會儲存接受狀態。接受授權唔會啟動伺服器。

原生主機會喺已初始化工作階段根目錄下，登記已驗證伺服器位元組。原生生命週期操作會序列處理准入、登記、狀態、啟動、正常停止同關閉。同一個原生程序同時擁有 Java 子程序及拒絕寫入／刪除嘅檔案租約。正常停止會核對確實建立時間同執行檔身份，寫入 `stop`，再等候最多十秒。逾時會保留監督同租約，亦容許另一段有上限嘅觀察。流程唔會嘗試強制終止。父程序通道 EOF 會要求正常關閉；關閉仍未驗證時，原生主機會繼續保留。

## 目前准入限制

實際伺服器啟動仍不可用。所需嘅確實版本產生網絡設定證據尚未保留，因此原生設定准入一律拒絕放行。版本清單唔會被用嚟推斷 loopback 屬性結構、管理設定、就緒狀態或者歷史版本相容性。

執行環境探索而家只考慮[已審核專用可攜執行環境](preparation.zh-HK.md#reviewed-portable-java-runtime)，唔會使用 PATH、JAVA_HOME、呈現器指定執行檔或者未審核本機安裝。原生主機嵌入固定完整執行環境清單，登記之前獨立驗證壓縮檔、每個成員同 release 檔案主版本。Windows x64 嘅 Java 21 係首個支援取得組合；其他主版本同架構保持不可用。流程只準備擁有嘅檔案，唔會全域安裝、執行 Java 或自動接受伺服器授權。已安裝執行環境探索仍待完成。

驗證模式同測試模式會明確停用生產原生回呼。合成測試核對受保護主程序接線、識別碼驗證、確實授權確認、取消、登記身份同設定不可用狀態。呢啲測試唔代表原生編譯、租約 IPC、子程序啟動、實際設定消費、就緒狀態或者正常執行關閉已驗證。本機程序支援要宣稱可運作之前，仍需要綁定候選版本嘅原生同真實執行環境證據。

## 完整執行環境成員生命週期

原生執行擁有者而家會同時取得驗證同保留租約。每個固定執行環境檔案及其目錄祖先，都會連同伺服器發佈檔案一齊持有。取得途中失敗會釋放已取得控制代碼。確定建立程序之前失敗亦會釋放。程序建立已傳回子程序之後，即使身份觀察出錯，仍會保留嗰個確實子程序同完整成員租約。正常停止逾時亦會保留。釋放必須透過已保留子程序控制代碼觀察退出，唔會領養相同 PID。

專用驗證器加入全新合成檔案同受管理 .NET 子程序。八項檢查涵蓋部分取得、未啟動釋放、程序建立失敗、存活時 DLL 同授權成員修改拒絕、逾時保留、確實退出釋放、啟動後不確定保留，同不確定子程序確實退出釋放。負面模式刻意釋放執行環境保護，必須喺 DLL 寫入斷言失敗。驗證器唔會執行 Java 或伺服器檔案。新模式嘅候選版本編譯同執行證據仍待完成；來源斷言唔可以代替呢啲證據。

呢次有限改動會喺子程序生命週期保護清單成員，但唔會解決既有可寫入映射限制，亦唔會阻止新增目錄內容。完整載入樹隔離同確實版本設定證據仍然係獨立准入要求。設定准入保持 false，實際 Java／伺服器啟動仍不可用。

根目錄建置之後，透過已驗證 .NET 主機執行已建置伺服器租約驗證器，使用 --lifetime-fixture-root 或 --lifetime-negative-fixture-root，並提供全新絕對路徑測試目錄。第一個模式必須傳回 0 同八項通過檢查；負面模式必須傳回 1，同完整樹 DLL 寫入拒絕斷言。兩份收據都要保留來源同二進位身份。兩個命令都唔代表執行環境或伺服器已驗收。

## 確實版本屬性檢視

獨立屬性證據模組只會檢視位元組輸入，唔會啟用原生啟動。證據包裝目前只識別已審核 Java 1.21.9 身份。其他版本會回報檢視不支援，而伺服器版本清單仍然動態更新。呼叫者持有嘅發佈檔案 SHA-256 同屬性 SHA-256 會綁定受檢視位元組，但唔代表已證明位元組點樣產生。

詞法處理依據 [Java 21 Properties API](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/util/Properties.html)：CR、LF 同 CRLF 行、開頭空白同註解、奇數反斜線續行、跳脫分隔符、單一 Unicode 跳脫，同未知跳脫移除反斜線。位元組模式必須明確選擇 Latin1 InputStream 或嚴格 UTF-8 Reader 輸入。BOM 字元會保留為資料，唔會自動偵測。嚴格 Reader 模式唔支援格式錯誤 UTF-8。解碼後重複鍵會被拒絕，即使值相同亦一樣。檢視子集會拒絕尾部跳脫同空續行鏈，唔會估計意思。

限制係複製、雜湊或解碼之前最多 1 MiB；最多 4,096 項；32,768 個自然行；每個邏輯行 65,536 字元。有序項目會保留未知鍵作字串，包括似物件原型名稱嘅鍵。診斷只包含有界原因代碼，唔包含屬性值。檢視唔會記錄或持久儲存位元組及值，呼叫者必須將可能包含嘅憑證視為敏感資料。

成功解析會回報 parsed-unadmitted，設定准入保持 false。缺少證據仍明確列出：確實發佈檔案產生嘅預設值、實際版本載入模式、確實版本網絡消費者，同完整載入樹隔離。缺少屬性唔會變成已驗證預設值。呈現器證據旗標唔會被接受，模組亦冇生產准入接線。八項合成解析檢查只證明詞法檢視同拒絕行為，唔代表已執行 Java 驗證等價，亦唔代表實際伺服器已消費設定。
