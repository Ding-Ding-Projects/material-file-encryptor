# 元素外觀編輯器

渲染程序提供 `mountAppearanceEditor(root, services)`，並將具版本元素樣式儲存喺 `m4e.appearance.v1`。右鍵開啟元素命令；Shift-right-click 直接開編輯器。Shift+F10 開選單，Ctrl+Alt+A 編輯目前焦點元素。非模態編輯器會隨元素捲動同調整大小，尺寸限制喺視口內，關閉時恢復焦點。

主程式須為每個本機搜尋提供 `attachSearch(input, scope)`、屬性鎖用 `onLock(element, {property,state,layer})` 或元素鎖用 `onLock(element)`，並可提供 `translate`、`notify`、`onChange` 回呼同相容 Storage 嘅 `storage`。冇搜尋介面時，欄位停用並說明原因。主程式須載入 `appearance.css`。傳回 API 有 `open`、`apply`、`getState`、`setState`、`reset` 同 `destroy`。

主程式翻譯器接受 `translate(source, options)`，驗證同狀態訊息使用 `{message:true}`。`appearance-copy.js` 匯出 `APPEARANCE_COPY` 同 `APPEARANCE_COPY_KEYS`，包括所有自有固定動作、狀態、屬性標籤同已知診斷嘅廣東話。主程式須將清單加入語言服務，由該服務管理英語／廣東話／雙語、獨立趣味控制同學校模式。動態使用者名稱同準確 CSS 值保持原文，周邊標籤則翻譯。未知平台診斷用已知翻譯操作訊息加準確原始診斷詳情。文字覆蓋測試掃描固定控制同診斷，驗證真正中文，唔接受原文佔位。

## 已實作渲染同儲存

normal、hover、focus-visible、active、selected、disabled、dragged、invalid、loading、success、warning 同 error 狀態各有獨立有序圖層。圖層可改名、隱藏、鎖住屬性編輯、複製同重排。較後可見圖層覆蓋較早屬性；偽狀態經層疊繼承未改動 normal 宣告。編輯器提供文字、間距、尺寸、邊框、陰影、濾鏡、漸變、CSS 遮罩、變換同動態輸入，透過產生嘅限定範圍 CSS 套用至真實元素。渲染器有 CSS.supports 時會拒絕無效 CSS；模型邊界拒絕 URL 同宣告注入。

復原同重做保留五十個記憶體快照。重設可針對屬性、圖層、狀態、元素或全部。命名預設、複製／貼上樣式同 JSON 檔匯入／匯出使用相同有界結構。穩定 ID 使用元素 ID 或結構路徑；移動冇標籤元素可能改變身份。動態記錄應提供永久 `data-appearance-id`。匯出只含元素樣式，絕不包含自訂標誌內容。

連續原生色譜配有十六進位輸入、支援透明度嘅 HEX8、RGB／HSL 讀值同透明合成對比。純轉換工具亦提供 HSV、HWB 同 CMYK。彩虹動畫係只可用於前景／背景顏色嘅結構標記，全域速度 1–10 對應 55–1 秒。動畫由 CSS 執行；減少動態效果時固定色相。調色盤唔會將標記當成顏色字串儲存。

## 圖層群組、選取同狀態預覽

群組可整理最多四層巢狀有序子圖層。隱藏群組會隱藏子圖層。群組屬性喺子層之後套用；呢啲係邏輯樣式群組，唔係獨立離屏點陣表面。調整圖層保留有序、有界模糊、亮度、對比、飽和度、灰階、褐色、反相、色相旋轉同透明度效果。效果可修改、移除同重排，並組成目標真實 CSS filter。

選取工具產生真實 CSS 矩形、橢圓、多邊形同數值 SVG 路徑遮罩。數值座標有鍵盤操作同界限。RGBA 通道增益使用本機 SVG 色彩矩陣；亮度選取產生透明度閾值。色域選取保留軸對齊 RGB 區間內像素，可編輯中心同容差；呢個明確係通道範圍選取，唔係感知色差計算。唔載入遠端濾鏡資源。

每個狀態可明確繼承另一狀態，或唔繼承任何外觀狀態；循環會被拒絕。前／後比較會停用再恢復目標產生嘅外觀規則，唔更改已儲存資料；關閉時一定恢復「之後」畫面。字體快捷功能套用真實底線變體、雙刪除線、頂線、上下標、基線重設、小型大寫、外框、光暈同多重陰影。仍可逐 CSS 屬性輸入精確值。

變更回呼第二參數包含 `kind`、目標 ID、狀態、群組路徑同圖層索引。中繼資料冇圖片資料或憑證，可將主程式受保護歷史綁定至準確編輯範圍。

## 本機標誌轉換

`mountLogoEditor` 接受靜態 PNG、JPEG 同 WebP 簽名；來源最多 4 MiB，解碼後每邊最多 8192 像素、總共一千六百萬像素，並拒絕動畫 PNG／WebP 標記。瀏覽器圖片解碼同 canvas 產生一張 128 × 128 PNG 衍生圖。Contain／cover 同數值焦點控制會影響輸出。失敗時保留原有有效圖。只有衍生圖存於 `m4e.logo.private.v1`，重設會移除；刻意與外觀匯出同歷史分開。轉換會攤平中繼資料同色彩描述檔，介面會說明。

## 已知能力同驗證限制

此實作未達完整進階編輯合約。獨立點陣群組表面、嵌入智慧物件、網格變形、命名顏色翻譯、只追加持久歷史、觸控長按同 Material 元件遷移仍不可用。編輯器會說明能力缺項，唔用無效控制冒充。圖層本機鎖可防修改，但屬性驗證屬主程式鎖定服務責任，唔由此模組提供。原生圖片解碼冇硬性程序記憶體或 CPU 時間額度，像素界限喺解碼後先檢查。聲稱完整惡意圖片安全前，仍須真正隔離解碼強化。

`test/local-appearance.test.js` 驗證模型組合、結構往返、不安全資源拒絕、彩虹標記限制、透明度／對比同標誌簽名界限。佢唔係已建置執行時或畫面擷取證據。鍵盤、視口、本地化、持久重載同視覺互動須喺整合程式驗證。

已安裝字型只喺使用者按 Load installed fonts 後，經主程式 `listFonts()` 或瀏覽器 Local Font Access API 探索；啟動時冇權限提示。色彩輸入支援 HEX、RGB、HSL、D65 Lab／LCH 同 OKLab／OKLCH，均支援透明度；超出 sRGB 顏色會被拒絕，唔暗中裁切。匯入遞迴拒絕不安全原型鍵，並限制元素 ID、數量、圖層同輸入長度。

## 指標工作台同同時狀態樣本

Draw selection 開啟有界 SVG 工作台。指標筆劃最多採樣成 32 個多邊形頂點，再透過既有遮罩渲染。鍵盤可用方向鍵移動游標，Shift 移動十單位，Space 加頂點，Enter 套用，Escape 清除。尺規顯示 0–100% 座標。最多二十條水平／垂直數值輔助線會隨所選圖層儲存；游標喺同軸最近輔助線兩個百分點內吸附。每個新介面使用主程式搜尋介面。

Compare all states 以安全文字樣本同符合目前 CSP 嘅建構式樣式表，同時顯示十二個解算狀態外觀。唔會複製私人欄位值、活躍控制或事件處理器。樣本顯示解算 CSS 屬性；本機產生通道濾鏡資源同動畫色彩標記唔會喺樣本格重現。真實目標仍使用完整渲染器。呢個格係編輯預覽，唔係逐狀態執行時互動證據。

繪圖工作台同本機 PNG 圖片選擇器分開。一般智慧物件格式同網格變形仍不可用；正規化圖片來源流程如下。

## 有界本機圖片來源同變換

圖片圖層選擇器只接受靜態 PNG。解碼前檢查簽名、IHDR 欄位、區塊框架同動畫標記。原始輸入最多 4 MiB，每邊最多 4096 像素、總共八百萬像素。瀏覽器解碼同 canvas 正規化產生攤平中繼資料 PNG，最多 1 MiB。無效輸入保留既有模型；轉換後關閉解碼 bitmap。呢個唔提供獨立程序沙箱、CPU 逾時或 CRC 驗證，以上仍係明確限制。

每個正規化來源不可變。圖層分別儲存平移、縮放、旋轉、仿射斜切、裁切、透明度同混合參數。重設變換唔改原始像素。既有複製、顯示、排序、巢狀群組同復原操作針對呢啲記錄。圖片群組以獨立巢狀 SVG 群組渲染，帶隔離、群組透明度、仿射變換同幾何遮罩。呢個係本機不可變來源流程，唔係一般智慧物件格式或可編輯向量文件。斜切近似平面變形；任意網格變形仍不可用。

圖片覆蓋層用目標視口邊界矩形，捲動或調整大小時更新；唔會重現任意已變換祖先幾何或所有堆疊上下文。目前所選編輯狀態控制圖片預覽；未實作即時偽狀態圖片切換同逐圖片群組通道效果。原有 CSS 樣式渲染器保持獨立。

本機持久資料包含圖片來源，受瀏覽器儲存額度同 8 MiB 外觀模型限制。可攜外觀匯出會遞迴移除圖片來源並標記省略，因此匯出檔唔可還原該像素，但保留變換同其他普通外觀設定。來源永不傳去伺服器。清除外觀會從生效本機設定移除來源；復原歷史只保留喺已掛載編輯器，直至銷毀。

聚焦測試驗證結構輸入界限、不可變來源中繼資料、匯出省略、獨立巢狀群組渲染、變換拒絕、掛載後儲存／重設／清理，同解碼資源關閉。呢啲係元件檢查，唔係真實瀏覽器像素或隔離解碼證據。
