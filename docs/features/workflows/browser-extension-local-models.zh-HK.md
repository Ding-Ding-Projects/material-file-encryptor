# 瀏覽器擴充功能本機模型

[瀏覽器擴充功能工作區](browser-extension-workspace.md)嘅「模型」分頁（Alt+8）可以將擴充功能連接去同一部電腦上面運行嘅模型伺服器（Ollama 類型）。分頁會列出同管理已安裝模型，亦可以同其中一個模型對話；回覆會一邊寫一邊串流顯示，並以易讀嘅豐富文字呈現。呢個功能唔經已配對嘅桌面程式，內容亦唔會傳去任何其他電腦。

## 連線同權限

安裝擴充功能時唔會要求任何主機存取權。清單只喺 `optional_host_permissions` 列出 `http://127.0.0.1/*`，而頁面政策除咗點心分頁已經列明嘅公開目錄主機之外，只多容許連接 `http://127.0.0.1:*`。撳「連線」時，瀏覽器會因應你呢次點擊，要求呢一項權限。如果權限被拒絕，畫面會講明，埠同之前嘅狀態維持不變，亦唔會發出任何要求。

「埠」欄位接受 1024 至 65535 嘅整數，預設 11434。其他輸入喺權限提示出現之前已經被拒絕。位址一律砌成 `http://127.0.0.1:` 加埠，所以擴充功能冇可能指去其他主機、其他協定或者路徑。要求唔會跟隨重新導向，唔帶 cookie 或憑證，亦唔傳送來源網址。

權限批准後，分頁會讀取伺服器版本、已安裝模型同目前載入咗入記憶體嘅模型。如果連唔到伺服器，分頁會講明伺服器冇喺嗰個埠運行，請你先啟動。「重新讀取」會再讀一次同樣三項資料，背景唔會輪詢。

## 已安裝模型、拉取同刪除

每個已安裝模型都會連大小一齊列出，伺服器報告已載入嘅會標示為運行中。模型標籤規則同桌面程式一樣：可以用字母、數字、點、連字號、底線同斜線，最多一個冒號加標籤，唔可以有連續嘅點或斜線，最長 200 個字元，而且唔支援雲端模型。違規嘅標籤喺傳送之前已被拒絕，伺服器回覆入面嘅雲端項目亦會被略過。

「拉取」輸入模型標籤，然後按伺服器報告嘅已完成同總位元組數顯示進度條；伺服器未提供總數時，就顯示不定進度條。「取消」會即時停止下載。伺服器可能保留已下載嘅部分，之後再拉取可以繼續。同一時間只可以拉取一個模型。

刪除前一定會先確認。對話框會寫出確切標籤，而「取消」係預設動作，對話框打開時標記為取得焦點。喺對話框撳「刪除模型」之前乜都唔會刪，刪除之後會重新讀取清單。

## 對話

揀一個已安裝模型，寫好訊息再撳「傳送」。每次新訊息都會連同到目前為止嘅整段對話傳去伺服器，回覆會逐段串流入嚟。「停止」會提早結束回覆，並保留已經收到嘅部分。如果回覆未收到任何內容就失敗，你寫嘅訊息會放返入欄位。一段對話最多 128 則訊息，每則最多 65,536 個字元；回覆去到呢個長度就會被停止。

對話只存在於該頁面嘅記憶體入面，永遠唔會寫入瀏覽器儲存空間，亦唔會匯出，頁面關閉就消失。「清除對話」可以更早清空。「模型」分頁唯一會儲存嘅，係同其他分頁一樣記住開咗邊個分頁。

## 豐富文字同複製

回覆會顯示成段落、標題、項目符號同編號清單、行內程式碼、圍欄程式碼區塊、粗體、斜體同連結。內容絕對唔會由標記字串砌成：回覆先被解析成純粹嘅標記樹，頁面再自己建立每個元素並設定文字，所以回覆入面嘅 HTML、script 標籤同事件屬性都只會當普通文字顯示。只有 `http` 同 `https` 位址會變成連結，帶有內嵌憑證嘅位址就唔會。連結會喺新分頁打開，冇 opener 亦冇來源網址。其他協定嘅位址，例如 script 或 data 位址，只會留作純文字。未關閉嘅程式碼圍欄（串流途中會出現）會顯示成程式碼直到文字結尾。

每則模型回覆都有「複製回覆」，會複製模型寫嘅純文字；每個程式碼區塊都有「複製程式碼」，只複製嗰個區塊。一行短短嘅狀態訊息會確認已複製，唔會打斷操作。如果瀏覽器拒絕剪貼簿存取，狀態訊息會講明冇複製任何內容。

面板同訊息用同工作區其他部分一樣嘅淡入效果。瀏覽器要求減少動態，或者開咗減少刺激設定，動態就會關閉。所有標籤都有英文、廣東話或者雙語，跟隨工作區揀嘅語言。

## 失敗情況

- 伺服器冇運行、喺另一個埠，或者權限被拒絕：分頁會講明，並將需要連線嘅按鈕保持停用。
- 伺服器回覆錯誤狀態、意外格式、格式錯誤嘅行，或者超過 1 MiB 嘅行：要求會以簡單訊息結束，已收到嘅部分回覆仍然可見。
- 串流喺伺服器報告完成之前結束：分頁會報告串流提早結束，而唔係顯示一則完成咗嘅回覆。
- 拉取或對話超過時限（拉取一小時、對話十分鐘），或者回應超過 16 MiB：要求會被停止。

## 安全備註

權限範圍窄、屬可選、而且只喺你要求時先申請；不過同一部電腦上面任何程式都可以監聽迴環埠，所以擴充功能會信任你所揀嘅埠上面回應嘅任何程式。回覆一律當作不受信任嘅文字，永遠唔會被執行或者當標記解讀。伺服器自己嘅錯誤文字唔會顯示，只會顯示固定訊息。拉取模型會下載由伺服器決定嘅大型檔案，所以標籤應該係你認得嘅。

## 驗證

呢個功能係用自動化測試同進程內假伺服器驗證。測試涵蓋位址同埠規則、模型標籤驗證、要求欄位檢查、斷行串流、大小限制、取消、時限、錯誤狀態、串流提早結束、權限被拒絕路徑、豐富文字解析器、安全連結規則、複製動作同封裝政策。未有對真正安裝嘅 Ollama、真正嘅瀏覽器權限提示或者真正嘅剪貼簿做過檢查，所以依賴呢啲嘅行為，包括個別 Ollama 安裝嘅來源設定，仍然未驗證。
