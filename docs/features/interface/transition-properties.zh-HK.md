# 具型別過渡屬性數值

動畫同過渡工作區提供已註冊嘅 Material Design 3 屬性檢查器。明確遷移之前，版本一保留共用屬性清單同共用起止語意。版本二儲存有次序同固定識別碼嘅屬性列，每列有獨立起止值。原有外觀修改仍然係唯一設定、鎖定、回復同歷史流程。

## 版本同遷移界線

未修改嘅版本一資料唔會升級。逐屬性編輯會用一次原有操作將所屬動態模型升至版本二，保留屬性次序同舊起止值。只識版本一嘅舊讀取器會拒絕版本二，唔會暗中用共用值顯示。驗證同來回轉換保留未知可攜列中繼資料。重複識別碼、重複屬性、無效識別、可執行 CSS、網址同原型鍵會被拒絕。

舊全部屬性規則會保留至明確展開。展開只快照實際目標計算樣式屬性目錄，唔代表每個屬性可以插值，亦唔會自動加入將來顯示引擎屬性。唔會任意截取最近屬性或者固定數量。

## 執行環境同能力事實

同一共用解析器提供播放、減少動態效果更新、靜態結束比較同還原。起止兩端都會檢查，計算起止值會逐屬性獨立取樣。不支援嘅列保留可攜資料，顯示明確不可用原因，唔會進入已接納動畫影格。CSS 語法接受唔代表已證明插值，尤其未註冊自訂屬性。逐屬性 allow-discrete 會保留，但呢個 Web Animations 介面未能預覽。規則長度、延遲同緩動仍然共用；逐屬性時間、完整時間軸同動態路徑編輯仍未完成。

## 讀取器清單

動態模型驗證兩個版本，由權威版本二列推導現有屬性投影。動態編輯器委派到呢個檢查器，執行環境每個起止消費流程都用同一解析器。外觀呼叫端用已驗證屬性投影決定樣式優先次序，並將完整動態模型交畀執行環境註冊表。外觀序列化、本機修訂、復原重做、預設同匯入保留完整模型。本機時間表比對器選擇完整已驗證預設，包括版本。關鍵影格檢查器只讀動畫軌道，保留外圍動態版本。冇新增原生動態讀取器。

## 控制項說明

<a id="migrate"></a>
### 逐屬性編輯數值

明確將規則升至版本二，保留屬性次序同共用起始數值。

<a id="expand"></a>
### 展開實際顯示引擎屬性

將舊 all 換成呢個目標顯示引擎目錄嘅明確快照，再逐屬性獨立編輯。

<a id="select"></a>
### 選擇屬性

揀要編輯嘅屬性列，唔會修改已儲存動態。

<a id="property"></a>
### 屬性名稱

揀顯示引擎屬性或者輸入安全自訂屬性，語法唔代表已證明插值。

<a id="add"></a>
### 新增屬性

完整驗證之後新增獨立識別嘅屬性列，起止都用計算值。

<a id="remove"></a>
### 移除屬性

移除呢個屬性，保留其餘列，最少要留一列。

<a id="earlier"></a>
### 將屬性移前

改屬性編寫次序，唔會改起止值或者規則時間。

<a id="later"></a>
### 將屬性移後

將呢列移到下一列之後，保留固定識別碼。

<a id="from"></a>
### 起始值

設定呢個屬性嘅起始 CSS 值或者目標計算值，起止兩端會獨立檢查。

<a id="to"></a>
### 結束值

設定呢個屬性嘅結束 CSS 值或者目標計算值，唔會重用另一屬性數值。

<a id="number"></a>
### 起止數字草稿

輸入有限起止數字草稿，按套用之前唔會儲存修改。

<a id="unit"></a>
### 起止單位

揀 number、px、%、em、rem 或者 deg，屬性必須接受結果 CSS。

<a id="apply"></a>
### 套用起止值

透過原有動態修改流程套用所選起止數字草稿一次。

<a id="clear"></a>
### 清除起止草稿

清除未儲存數字草稿，留空唔會暗中當零。

<a id="behavior"></a>
### 離散行為

逐屬性保留 normal 或者 allow-discrete，介面未支援嘅預覽會明確顯示不可用。

<a id="reset"></a>
### 重設屬性數值

只將呢列重設為計算起止值同 normal 行為，保留識別碼同可攜中繼資料。

## 驗證界線

原始碼流程測試涵蓋舊版本相容、明確遷移、獨立起止值、嚴格檢查、原有拒絕、回復重試、鎖定、預設、時間表、減少動態效果、比較同移除消費流程嘅負面測試。原生 API 參數只係原始碼流程證據，唔係畫面插值證明。實際計時錄影、鍵盤同螢幕閱讀器操作，以及完整視窗、語言、主題同顯示比例矩陣仍待驗證。
