# 儲存空間維護

解鎖磁碟後，從工作區導覽開啟儲存空間維護。「重新整理儲存狀態」會讀取原生引擎的實際診斷，分別顯示目前檔案引用的分段、僅由歷史版本保留的分段、暫存檔案、排隊檔案及正在寫入的檔案。數量及位元組總數描述實體加密儲存空間，並非明文檔案長度。

實體分段目標以 MiB 輸入。預設 80 MiB 等於 83,886,080 位元組，上限為 90,000,000 位元組。「整理目前檔案」會排入可取消的原生工作，並儲存要求的目標。正在寫入的檔案可能延遲整理，請先完成寫入或關閉檔案。檔案內容及歷史引用仍受引擎的持久性規則保護。

每項整理工作顯示狀態、階段及已處理的位元組。未知總數使用不定進度。取消按鈕只提出取消要求，不代表立即還原。請重新整理以確認最終結果。

目前引用及僅供歷史使用的數量會分開顯示。整理後，歷史版本仍可能保留舊分段。整理不會填充較短的分段、重寫全部歷史，亦不保證總儲存空間立即減少。此面板沒有刪除歷史或捷徑清理功能。

橋接驗證會拒絕未支援的欄位、路徑跳脫及過大的目標。桌面程式必須已解鎖並可接受工作。退出或準備更新期間被拒絕的要求不會啟動新工作。此面板不會安裝更新或重新啟動電腦。

針對性的合成測試涵蓋位元組換算、橋接驗證及進度語義。整合時會另行記錄實際操作及版面證據，原始碼測試並不能證明已掛載的流程。
