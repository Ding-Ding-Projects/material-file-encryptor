# 公開路徑驗收界線

呢份係基礎清單，唔係完成報告。每條路徑都承接全部 104 項標準功能責任。掛載共享控制、來源測試通過、歷史畫面或者安裝程式成功，都唔代表瀏覽器驗收完成。進階外觀同圖片編輯器、完整設定導覽、完整匯出格式同進階歷史仍然未完成。

## 路徑責任

首頁、文件庫、分類索引、全文文章、維基索引、個別維基文章同畫面圖庫都直接掛載公開文件介面。瀏覽器工作區有自己嘅介面。偏好設定、本機存取、語言、外觀、時間表、專注、私人歷史、搜尋建構器、指令面板、通知、內容選單同確認對話框，都係需要獨立驗收嘅內層介面。網站負責文件、訪客設定同已核實下載。原生磁碟管理屬於已安裝應用程式。明確配對嘅本機工具只可使用准許嘅中介端點。

配套機器清單列明每條生成路徑同每個標準識別碼。全部瀏覽器判定仍然未核實。程序同發佈責任要由實際路線提供證據；列入清單唔代表瀏覽器要製造安裝程式。

## 最小實際驗收流程

1. 用根目錄入口建置，固定候選版本同暫存清單，互動前比較實際送出嘅 HTML、指令碼、樣式、背景工作同來源資料位元組。
2. 用隔離隱藏瀏覽器開啟確切暫存首頁。檢查初始版本同建置資料、關閉嘅指令面板同通知、真正分頁同群組、鍵盤焦點、內容操作同還原。先驗正常英文淺色同最窄雙語深色，再完成所需語言、主題、尺寸同顯示比例矩陣。
3. 開啟全部清單路徑。核實文章同維基全文、內部連結、錨點同資產。每類路徑同每個獨特內層介面都要操作共享控制。用正規表示式建構器搜尋正文同設定，包括無效模式同取消搜尋。
4. 登記合成測試設定檔，拒絕錯誤密碼、正確解鎖、鎖定同重新載入。核實加密憑證同獨立密碼歷史。修改一個設定，只可產生一筆歷史，再用真正介面還原。設定檔鎖定時，歷史操作要提供誠實解鎖路徑或者拒絕並保持資料不變。
5. 驗證認證前後載入中性用詞檔案、取代、保存、清除、無效輸入、鎖定還原同只限本機。加密未完成時喺另一分頁重設設定檔；舊分頁唔可以寫入孤立快取。
6. 獨立調整兩種語言風格，確認預設 5。由廣東話同雙語狀態經憑證流程啟用受保護模式，確認隱藏控制經導覽同重新載入仍然隱藏，再拒絕錯誤停用憑證並接受正確憑證。匯入、重設同歷史還原唔可以免除憑證要求。
7. 離開再經瀏覽器快取返回，控制仍然可用，但認證同未完成確認要取消。實際操作確切確認文字、兩個按鍵、滑桿、緊急退出同中止。檢查最窄尺寸溢出、焦點次序、縮放同無障礙名稱，保留綁定來源、暫存雜湊同私隱檢查嘅真實畫面。
8. 分開記錄來源測試、暫存瀏覽器、已安裝原生程式同正式網站發佈。正式驗收另外需要實際首頁、全部路徑同資產、文章同維基完整清單，以及儲存嘅儲存庫首頁網址讀回。

## 證據限制

此處冇宣稱瀏覽器畫面或者正式部署完成。來源測試只涵蓋指定組合同行為。設定同編輯器審查另外保留桌面同網站欄位。呢個功能冇新增 HTTP API，毋須 Postman 集合。

## 更新聲明清單

發佈目錄改動後執行 `node scripts/refresh-public-route-contracts.mjs`；`--check` 只檢查差異，唔會寫入。目前清單有 105 個功能類別及 187 條路徑。更新工具拒絕重複聲明，亦拒絕直接覆寫已有驗收狀態或瀏覽器證據，呢啲需要明確整合。額外聲明的巢狀畫面會保留，工具永不製造驗收證據。六項清單及更新檢查通過，包括負面案例；實際瀏覽器及部署驗收仍然分開。
