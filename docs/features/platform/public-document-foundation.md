# Public document controls

The home page, documentation library, articles, category indexes, wiki and capture gallery mount their own shared Material controls. These controls navigate public content and visitor preferences. They do not open vaults, mount drives or invoke native application operations. The connected browser workspace is a separate surface.

## Navigation and search

Home sections have persistent tabs with close, restore, pin, reorder and group actions. Each document owns a separate browser-storage namespace, so one article cannot replace another document's tab choices. The command palette opens with Ctrl+Shift+F and indexes content destinations and exact preference controls. Tab context actions include their working keyboard shortcuts.

Content search and preference search each mount their own adjacent full regular-expression workbench. Plain text is the default. Expressions run in the shared isolated worker with bounded pattern, sample and execution time. Invalid or timed-out expressions report their state at the field. Preference results focus the actual setting rather than applying guessed values. Search patterns are not sent to a server.

## Preferences and privacy

English and Cantonese playfulness are independent integer values from 1 through 5, both defaulting to 5. Either language can be reset independently. The old success/search category values are not reinterpreted as language preferences; migration retains the language and emoji choices and initializes both newly defined language values to 5. Messages retain their facts at every level, including errors and warnings.

The notification centre stores visitor-owned messages in its document namespace and supports filtering, read state, dismissal and redacted JSON/CSV export. The front screen reads the staged version and build time from site-provenance.json; missing provenance remains unavailable. Build time is captured by the staging producer, not synthesized at page launch.

The shell can consume verified shared School settings and suppress restricted settings, palette entries and translated presentation while preserving prior choices. A static browser cannot directly read the desktop's protected shared record. Visitor personalization and access adapters provide the browser-local settings and authentication boundary; native cross-application propagation requires a separately established bridge. The public shell does not treat selecting a vocabulary file as authentication.

A validated pending wording file remains available for retry if authenticated encryption fails, and the failure is shown without applying partial wording. Authentication and replacement operations have separate ownership. Clear uses the same browser write lock as encrypted persistence; authentication waits for a queued clear before restoring saved wording.

## Verification

Focused tests cover defaults and migration, independent language levels, serious-mode messages, document-state isolation, required foundation registration and generated route depths. A deliberate source-boundary removal makes the composition check fail. Real built-page interaction, narrow-layout checks, screenshots and live deployment readback remain separate verification requirements.

## README diagrams and reviewed public evidence

The publication catalogue explicitly includes `README.md`. Its three existing flowcharts are converted at staging into accessible local SVG, preserving the declared nodes, arrows and source text. Only the bounded README subset of `flowchart LR` or `flowchart TD`, quoted node labels and directed arrows is supported. Unsupported syntax fails as `UNSUPPORTED_README_FLOWCHART_SYNTAX`; this is not general Mermaid support. Readable labels stay at their natural size inside named keyboard-focusable scroll regions, including narrow screens. Browser pixels, overflow and interaction still require actual rendering evidence.

Exactly two reviewed JSON files are published from the tracked public source: `docs/evidence/main-performance-20261012.json` and `docs/evidence/hosted-update-1344-20261012.json`. A frozen allowlist binds their normalized content hashes and exact routes. Changed, oversized or unreviewed content is rejected. Neighboring evidence files and private outputs are never enumerated or copied. Internal article links resolve to these delivered files. Performance, older-controller metadata, downloaded-package bytes and installed acceptance keep separate verdicts.
