# 私人歷史控制項

共用 Private local history 面板使用已註冊 Material 外框按鈕執行操作，以外框文字欄位輸入文字、密碼同保留日數，並用 Material 核取方塊選擇記錄。桌面同瀏覽器個人化透過原有歷史管理服務共用同一面板。

## 原有操作同權限

設定、解鎖、鎖定、恢復、標籤、比較、匯出、保留期同修剪仍經原有管理回呼執行。指引操作等候直接操作使用嘅同一回呼承諾。停用、取消、已移除或已銷毀嘅操作唔可以開始新回呼。成功設定或解鎖會清除密碼欄位；操作被拒絕時保留輸入方便修正，唔會聲稱完成。指引同匯出唔會加入憑證。

記錄選擇保留記錄 ID 同最近兩個選項。比較必須有兩個 ID。修剪仍需要原有破壞性操作確認，同已解鎖而仍然存在嘅面板。控制項轉換冇修改加密、憑證儲存或者歷史管理權限。

## 搜尋、驗證同未完成控制項

搜尋保留主程式搜尋服務同原有輸入事件查詢。文字同日期篩選保留原有查詢語意。清除會等候原有輸入處理，被拒絕時恢復舊值並將焦點交回欄位。較新重新整理、鎖定或銷毀之後，遲到查詢結果唔會重新填入記錄。

日期篩選仍係瀏覽器原生日期輸入，明確標示 Material 轉換未受支援。主程式未取代搜尋佔位欄位時仍使用原生欄位。下載連結保留為實作功能。呢個單位唔會轉換外觀、標誌或者公開偏好設定對話框。

## 驗證界線

專項掛載消費端檢查涵蓋控制項清單、原有非同步回呼、取消同生命週期限制、密碼清除、選擇身分、查詢拒絕後恢復同焦點。最小 DOM 測試環境唔代表供應套件 shadow DOM 行為、鍵盤無障礙、版面、實際字形或者完整 Material Design 3 一致性。正式建置、真實畫面同獨立審查仍然需要完成。
