# 試算表表格轉換

轉換器可以透過 CSV、TSV、JSON，同互相轉換嘅方式匯入及匯出單工作表 XLSX 同 ODS 表格。輸出明確使用字串儲存格，保留開頭零、Unicode、空白字元、空白儲存格，同包含引號分隔符號嘅內容。CSV 分隔符號、換行格式同類似公式文字控制仍然可用。

呢個係表格轉換流程，唔係活頁簿編輯器。請確認已披露嘅格式、中繼資料、原有值類型同活頁簿結構損失。儲存嘅數字、日期、時間同布林值會匯出為字串，唔會套用數字格式。真實公式儲存格、多工作表、隱藏 XLSX 列／工作表、合併儲存格、外部關聯、巨集、內嵌物件同不支援儲存格結構會被拒絕。類似公式嘅字串儲存格按選定拒絕、轉義或保留規則處理；轉換器唔會計算任何公式。

輸入同輸出限制為 8 MiB、10,000 列、256 欄同 100,000 個儲存格。XML 解析前會執行 ZIP CRC、路徑、連結、展開同項目限制。XML 深度同節點數量有上限，並拒絕 DTD 同自訂實體。操作經現有已驗證 AppContainer 工作者執行，記憶體限制為 256 MiB，時間限制為 30 秒。佇列原子發佈之前，會重新開啟輸出，並同預期字串表格比較。

針對性測試涵蓋來回轉換、空白字元、共用容器偵測、CSV 選項、公式拒絕、外部連結、多工作表、巨大參照、XML 實體同重複限制。原生測試亦透過真實 AppContainer 轉換兩種格式並讀返結果。呢啲證據唔代表外部辦公室套件嘅視覺保真度已獲驗證。
