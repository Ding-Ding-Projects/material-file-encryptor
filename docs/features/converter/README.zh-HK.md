# 本機檔案轉換器

轉換器離線執行，將結果寫成使用者批准嘅新輸出。八分類目錄會清楚列出不可用轉換器同原因。內置執行環境轉換器可以格式化 JSON、正規化 UTF-8 文字、將原始位元組編碼為 Base64 或十六進位、列出／解壓／重新封裝受支援 ZIP，同喺 CSV、TSV、JSON 之間轉換字串表格。PDF 支援需要主程序提供隨套件附帶嘅 `pdf-lib` 1.17.1 證明；喺 PATH 安裝工具唔會啟用轉換器。

## 工作流程同整合

`createConverterService({stateDirectory, resolveGrant, bundledProof, sandboxProvider})` 只供主程序使用。`resolveGrant(id, mode)` 解析不透明、使用者批准嘅來源或目的地能力授權。唔好傳入渲染程序路徑或者接受任意 ID。只透過經驗證 IPC 公開 catalog、inspect、enqueue、list 同 control。啟動時呼叫 run，結束時呼叫 close。`mountConverter(root,{services,translate})` 需要 services.converter 提供以上方法，以及 pickSources、pickDestination 同 confirmOverwrite。

每項佇列工作最多 32 個來源，總輸入預算 64 MiB、輸出預算 128 MiB，同 30 秒工作者期限。佇列本身冇總項目數上限：獨立持久紀錄由儲存空間串流讀取，歷史每頁最多 50 項。每次只執行一項。中斷嘅執行紀錄會變成暫停，必須明確恢復並重新驗證來源。授權必須安全跨重啟保留，否則恢復工作會安全失敗。JSON 格式化、中繼資料變更同文字正規化，可能按各轉換器披露改變表示形式。預覽文字限於 2 KiB。

除非主程序提供可信、具有 verifiedOsIsolation=true 同 launch 方法嘅 sandboxProvider，否則禁止執行。原生提供者由 createWindowsSandboxProvider 建立，需要啟動器、現存 DLL／runtimeconfig／deps 配套檔，同獨立 Node 執行檔嘅套件資訊清單雜湊。佢會先做真實轉換探測，先宣告隔離可用。內置受限程序輔助程式啟動真實子程序，使用 Node 權限限制，禁止檔案系統寫入、網絡、建立程序或工作者、原生擴充，並限制受管理記憶體同期限。佢只接收有上限位元組緩衝區，唔接收來源路徑。佢會探測上述能力，拒絕無法禁止網絡嘅舊執行環境。Node 權限係縱深防禦，唔係防止受入侵執行環境嘅作業系統安全邊界。原生啟動器建立冇網絡能力嘅新 AppContainer，驗證子程序權杖，將暫停子程序加入限制記憶體嘅單程序 job，完成檢查先恢復執行。接受成功紀錄之前，必須移除隔離設定檔同 job。單元測試提供者只模擬整合合約，唔構成作業系統隔離證據。主程序保留檔案權限。輸出暫存使用同目錄臨時檔，同不取代現有檔案嘅硬連結，除非已明確確認取代。每次寫入之前比較來源路徑。Split 要求明確 destinationDirectoryId，並以目錄模式解析。每個生成名稱都會檢查，發佈前預檢全部目標路徑，禁止取代資料夾輸出。發佈期間競爭寫入仍然可以令後續輸出失敗；結果會明確列出已完成而保留嘅輸出，但唔會暴露部分檔案。來源資料絕不修改。

PDF 轉換器記錄精確操作，拒絕不透明加密或已簽署文件。發佈前會重新開啟同驗證輸出位元組。圖片、音訊、影片、7z／RAR 同 XLSX／ODS 轉碼，喺內置轉換器同套件證據存在之前，仍然明確停用。

## 驗證

執行 `node --test test/converter-*.test.js`。檢查涵蓋真實位元組轉換同 PDF 操作。套件介面、鍵盤、本地化文字、檔案系統能力持久化同作業系統隔離，都需要整合驗證，先可以聲稱發行完成。

## 剩餘作業系統邊界

受限子程序只用選定絕對執行環境路徑，絕不搜尋 PATH。主程序必須提供隨套件附帶嘅作業系統沙箱啟動器，驗證其身分、資源規則、無網絡權杖，同允許讀取程式碼嘅路徑。C# 啟動器來源喺 native/。主程序負責建置同封裝佢及獨立 Node 執行檔，再傳入資訊清單雜湊。如果設定或真實啟動探測失敗，正式轉換器保持停用。來源讀取同輸出發佈由可信父程序透過批准授權執行。取消狀態轉移會序列化：重新驗證來源期間取消，唔會被過期執行紀錄取代；發佈亦係一個有限臨界區。

原生暫存配置將唯讀內容目錄同可寫工作目錄分開。只有選定來源位元組會複製入工作目錄。工作者寫入編號輸出檔同綁定 nonce 嘅結果資訊清單；父程序驗證啟動器紀錄、設定檔刪除、權杖能力數量、結果雜湊、有上限輸出清單同檔案長度，先將位元組交返佇列。每次結果完成後，父程序刪除自己臨時暫存目錄。取消使用有限訊號檔請求，讓原生啟動器正常終止 job 同刪除設定檔。

### 原生驗證同限制

經主機建置入口建置原生專案，再執行其 native/smoke.ps1 驗證同轉換器 Windows 整合測試。啟動器唔會將使用者來源路徑放入工作者協定。新設定檔有零個能力 SID；恢復程序之前會檢查真實子程序權杖。Job 只容許一個程序，程序記憶體上限 256 MiB，關閉時終止子程序，並強制 30 秒實際時間期限。工作目錄每 100 ms 檢查一次，限制為 256 MiB 同 2,000 項；呢個係終止監察，唔係檔案系統配額。取消亦經此監察處理。工作者內容使用執行環境嘅 preserve-symlinks 旗標，避免模組載入器嘗試穿過被拒絕父目錄；暫存樹本身拒絕重新解析點。

## 結束協調

pending() 串流讀取完整持久清單，回傳排隊或執行中項目嘅數字總數，唔計暫停工作。cancelAll() 令未完成准入失效，等有限讀取完成，取消所有頁面嘅排隊／執行紀錄，通知活躍工作者，再等原生清理同持久終結紀錄。佢回傳 {cancelled, remaining}。暫停工作保留畀日後使用。close() 使用同一取消屏障。發佈同取消共用每項紀錄鎖，所以已完成原子發佈會保持完成，唔會改寫成已取消。
