# 本機模型

## 連線及復原

喺「本機模型」揀「檢查執行環境」。介面只會經受信任嘅主程序連接 `http://127.0.0.1:11434`。版本回應成功只代表 API 可連線，唔代表所有模型都適用。連線失敗時，無法單靠呢個結果分辨未安裝定服務未啟動。需要時安裝官方桌面版本，或者用作業系統啟動器開啟已安裝嘅 Ollama，再檢查一次。此功能唔會自動安裝或啟動服務。

## 模型目錄及下載

重新整理會讀取官方目錄連結嘅所有系列、每個系列嘅標籤頁同分頁，保存來源、雜湊、時間同數量。官方 HTML 冇獨立總數，因此完整性只涵蓋已觀察到嘅官方連結。缺頁、格式變更或離線時，保留上次完整快取。已安裝同運行中嘅本機模型會一齊顯示，唔會因為官方目錄冇列出就隱藏。

可按名稱搜尋，或者用有限度正規表示式，並按狀態、功能、系列、量化同硬件適用程度篩選。每次最多顯示 200 項，收窄搜尋可見其他結果。

下載清單只係本機模型下載，唔涉及付款。先檢查標籤、已知大小、預計額外儲存空間同可用空間，再確認網絡傳輸。可同時下載一至三項、取消同重試。任何一項失敗都唔會將整批標成成功，亦唔會刪除原有模型。

## 硬件、對話同個人設定

記憶體、架構同可用空間使用實際讀值；未驗證嘅 GPU、顯示記憶體同驅動資料會顯示未知，唔會由模型名稱估算。模型適用程度需要完整大小、參數、量化同上下文記憶體資料。

選擇已安裝模型後，可以輸入系統指示、設定有限範圍參數、發送訊息、停止或重新產生回應。歷史只儲存喺本機，可選取、改名及經確認刪除。圖片只限已驗證支援視覺嘅模型，每次最多四張，每張 1 MiB。匯出會移除可辨識憑證、環境變數值同私人路徑，唔會包含圖片原始資料；自動遮蓋唔可能辨識所有秘密，分享前必須自行檢查。

內置設定可開啟本機對話同模型資料檢查。外部設定需要主程序提供可執行檔選擇器、允許清單、啟動同就緒驗證，唔接受自由輸入命令或環境變數值。啟動前保存設定快照，驗證失敗時還原。外部設定、啟動狀態同快照會持久儲存於本機；載入、啟動同還原時，會重新驗證真實路徑、允許清單同參數格式。中斷嘅啟動唔會自動重試。

## 驗證界線

合成測試涵蓋 API 邊界、串流完成、分頁、快取、本機清單、硬件判定、還原同遮蓋。呢啲測試唔代表已下載模型、已啟動服務、已驗證 GPU 或已拍攝實際介面。主程序整合、全部語言文案、視覺矩陣、瀏覽器驗證橋接同硬件探測仍需要整合驗證。
